# /design-bank — 아이디어 → 설계 → 박제

## 역할
아이디어 세션의 절차를 고정한다. 설계 **원칙**은 CLAUDE.md가 정본이고 이 파일은
**절차만** 담는다(이중 진실 방지) — 원칙을 여기 다시 쓰지 말 것.

시중 스킬 조사(obra/superpowers `brainstorming`) 산출: 규모 3분류·섹션별 승인·
자기 검토를 개념만 이식했다. 플러그인 통째 설치는 배제 — worktree·subagent·TDD
강제가 우리 규약(머지 단일 창구·게이트)과 정면 충돌하고, 스펙 파일 방식은 #1077
박제와 이중 진실이 된다.

## 요청
$ARGUMENTS
(비어 있으면 직전 대화의 아이디어를 대상으로 삼는다)

## 0. 규모 선언 — 먼저, 소리 내어

| 등급 | 산출물 | 예 |
|---|---|---|
| **탐침** | 실측만 하고 보고. 설계 없음 | "이거 이미 있나?" |
| **국소** | 실측 + 목업 + 계약. 표·다안 비교 생략 | 버전 배지(~120줄) |
| **구조** | 전체 형식(아래 2·3 전부) | 약점 진단·링크 반입 |

**등급을 먼저 말하고 시작한다.** 중간에 바뀌면 즉시 알리고 다시 선언한다.

> 왜: J(버전 배지 ~120줄)를 A(약점 진단)와 같은 무게의 형식으로 다뤄 과설계했다.

## 1. 실측 먼저 (모든 등급 공통 · 건너뛰기 금지)

주장 **전에** grep. "없다"는 **찾아본 뒤에만** 쓴다.

## 2. 진행 — 구조 등급은 섹션마다 멈춘다

```
① 진단(측정치 표) → ② 접근 2~3안 + 권고 → ③ 상세 설계 → ④ 계약
```

각 단계에서 승인을 기다린다. 애매하면 **한 번에 한 질문**, 가능하면 객관식.

> 왜: I(페이서)에서 통짜 설계를 냈다가 "▶ 버튼 빼라"로 되돌린 비용이 정확히 이것.

## 3. 필수 동봉 (원칙 정본은 CLAUDE.md — 여기서는 목록만)

- 선례·오픈소스 표(채택 / 부분 채택 / 배제 + 근거) — 배제도 근거와 함께 남긴다
- 3문 체크 · 계약(심을 것) · 위험 · 하드리밋 점검
- UI 변경이면 **텍스트 목업 우선**

## 4. 박제 직전 자기 검토 (1회)

- 내 주장 중 **실측으로 확인 안 된 것**을 열거하고, 확인하거나 "미검증"이라 표시
- 이미 있는 부품을 새로 만들자고 하지 않았는지
- 의도적 단절을 부채로 오인하지 않았는지

> 왜: 한 세션에서 자기 진단을 4번 정정했다(약점 진단 없다→`confusedQueue` 존재 /
> 목표 저장소 없다→`dday_date` 존재 / 연속 듣기 0→`ListenControls` 배선됨 /
> 문장 채집 미구현→`source_sentence`→cloze 가동 중). 우연이 아니라 절차로 만든다.

## 5. 구현 라운드의 계약 — 깨뜨려 확인 1회 (v2-L 확정)

새 계약을 심었으면 **일부러 깨뜨려 FAIL을 1회 확인**하고 커밋한다. 계약당 30초다.

- 앵커 슬라이스는 `src/lib/__tests__/helpers/sliceBetween.js`만 쓴다.
  raw `slice(indexOf(`는 앵커가 사라지면 빈 문자열을 검사해 **부정 단언이 전량
  자동 통과**한다(공허 통과). `contractHygiene.test.js`가 이를 금지한다.
- 변조 후 복원은 **역치환**으로. 미커밋 파일에 `git checkout`을 쓰면 그 라운드
  작업분까지 날아간다(실측된 사고).
- 계약은 **배선 보증**이고 동작 보증은 e2e다 — 경계는 `docs/ui-conventions.md` §5.

## 6. 박제

구현까지 끝났으면 보드(`docs/ai-tasks.md`) done 엔트리를 그 PR에 동봉한다.

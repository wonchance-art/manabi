# 아오조라 txt 서식 견본 (FORMAT SAMPLE)

이 폴더의 `format-sample-*.txt`는 **실제 작품이 아니다.** 작업 세션(2026-10-12 KST)의 네트워크 정책이
aozora.gr.jp와 aozorabunko 저장소를 막아 실물을 받을 수 없었다. 그래서 manabi가 직접 지은 일본어 문장으로
青空文庫 txt(ルビ付き, UTF-8 변환본)의 **배치만** 실물대로 따라 쓴 견본이다. 실존 작품의 문장을 옮기거나
기억으로 재현한 줄은 없다. 제목·저자·底本·입력·교정 값도 모두 가공의 값이다.

따라 쓴 배치:
- 머리: 작품명 / 저자명
- 대시 줄 두 개 사이의 【テキスト中に現れる記号について】 기호 설명 블록(판권이 아니다)
- 본문: 한 줄 = 한 문단, `｜기준《읽기》`·`기준《읽기》` 루비, `［＃…］` 주석, `［＃「一」は中見出し］` 見出し, `※［＃…］` 외자
- 판권: 말미의 `底本：`부터, 들여쓴 연속 줄, `入力：`·`校正：`, 작성일, `青空文庫作成ファイル：`

**교체 예정**: 네트워크가 열리면 실제 작품 3편(설계 §5 P0 후보)의 txt로 이 견본을 교체하거나 옆에 추가하고,
파서 계약(`aozoraParser.test.js`)을 실물로 다시 고정한다.

기본 술어문12

  • A 是 BA는 B이다 (명사 술어)

    주어 + 是 + 명사

    是는 명사를 잇는 '~이다'. 형용사 앞에는 是를 쓰지 않아요 (×我是高).

    我是学生。wǒ shì xuésheng저는 학생이에요.

    他是中国人。tā shì Zhōngguó rén그는 중국인이에요.

  • 주어 + 很 + 형용사A는 ~하다

    주어 + (很) + 형용사 (是 없음)

    형용사 술어 앞엔 보통 很을 붙여요. 여기서 很은 '매우'보다 어조를 고르는 역할.

    今天很热。jīntiān hěn rè오늘은 더워요.

    她很漂亮。tā hěn piàoliang그녀는 예뻐요.

  • 주어 + 동사 + 목적어A가 B를 ~하다

    주어 + 동사 + 목적어 (SVO 어순)

    중국어 어순은 SVO. 한국어 SOV와 달라 목적어가 동사 뒤에 와요.

    我喝茶。wǒ hē chá저는 차를 마셔요.

    他看书。tā kàn shū그는 책을 봐요.

명사문 — です·だ 계열6

  • 〜です~입니다

    명사/な형용사 + です

    동사 뒤에는 です를 겹치지 않음 (×行きますです)

    わたしは 学生がくせいです。저는 학생입니다.

    母ははは 先生せんせいです。어머니는 선생님입니다.

  • 〜では ありません~이/가 아닙니다

    명사 + では(じゃ) ありません

    회화에서는 じゃ ありません이 보통

    わたしは 先生せんせいでは ありません。저는 선생님이 아닙니다.

    これは 水みずでは ありません。이것은 물이 아닙니다.

  • 〜でした~였습니다

    명사 + でした

    きのうは 雨あめでした。어제는 비였습니다.

    むかし、ここは 学校がっこうでした。옛날에 여기는 학교였습니다.

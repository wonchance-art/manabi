선례 — 「내 언어」를 어떻게 다루나

앱방식판정우리 쪽 근거
Duolingo「I speak」 = 기준 언어. 이것이 화면 언어도 정하고, 고를 수 있는 코스 목록이 기준 언어에 따라 달라짐. 기준 언어를 바꾸면 다른 기준 언어의 진도는 숨겨짐부분 채택「내 언어 → 목록이 달라짐」은 그대로 채택(중국어면 한국어만). 진도 숨김은 배제 — 우리는 계정 하나에 학습 기록 하나(FSRS·review_events 공유)
Babbel화면 언어(보통 모국어)와 배울 언어를 따로 둠. 코스가 모국어에 맞춰 만들어짐채택우리 등록부도 화면(uiLocale)과 설명(explanationLocale)을 이미 나눠 둠. 온보딩은 둘을 같은 값으로 시작하고, 나누는 건 자료 화면 설정에서
Busuu가입 때 「I speak」 설정, 언어별 유창도와 함께 여러 개, 설정에서 언제든 변경부분 채택언제든 변경은 채택. 여러 모국어·유창도는 배제 — 교환·첨삭 커뮤니티용 정보라 우리 순환에 꽂힐 정거장이 없음
HelloTalk가입 때 모국어·배울 언어 선택, 모국어는 나중에 못 바꾼다고 경고배제상대 매칭 때문에 잠그는 것. 우리는 잠글 이유가 없음 — 화면 표시 설정일 뿐
LingQ프로필의 「Native Language」가 뜻풀이 사전 언어를 정함채택내 언어 = 설명 언어 기본값. 우리 explanationLocale과 같은 역할

수용 기준

  1. 모달을 처음 열면 어떤 언어도, 어떤 수준도 선택돼 있지 않다.
  2. 언어 0개면 「다음」이 비활성이고 이유 문구가 보인다. 고른 언어마다 답이 없으면 「시작하기」가 비활성이다.
  3. 중국어 → 일본어 순으로 고르면 learning_language=['Chinese','Japanese']. 「주 언어로」로 바꾸면 순서가 바뀐다. 주 언어를 해제하면 다음으로 고른 언어가 주 언어가 된다.
  4. 매핑 표대로 저장된다(예: 중국어 「기초는 알아요」 → learning_level_chinese='H2 초급'). 고르지 않은 언어의 수준 열은 바뀌지 않는다.
  5. 닉네임을 비워도 저장된다(기존 값 유지). 이메일 가입자는 가입 때 이름이 미리 채워져 있다.
  6. 저장 실패 시 정해진 문구만 보이고 고른 답이 남아 있다. 서버 오류 원문은 화면에 나오지 않는다.
  7. 모달이 닫히면 배움·/study가 주 언어로 열린다.
  8. (D-O4 승인 시) coldStart인 /study에서 프로필 수준이 있으면 q1이 확인형이고, 「다른 수준 고르기」로 바꾸면 프로필 수준도 바뀐다. 수준이 없으면 기존 3택.
  9. 키보드만으로 끝까지 진행된다: 언어 카드는 체크박스, 3택·급수 칩은 라디오 그룹(화살표 이동), 단계가 바뀌면 제목으로 초점 이동. 390px에서 가로 스크롤 없음, 터치 대상 44px 이상.
  10. 「내 언어」는 기기 언어로 미리 맞춰진다(canonicalViewerLocale, 못 맞추면 한국어). 바꾸면 모달 문구와 배울 언어 목록이 즉시 바뀌고, 이미 고른 배울 언어는 새 목록에 없으면 해제된다.
  11. 내 언어가 简体中文·繁體中文이면 배울 언어는 한국어 하나(「准备中/準備中」)이고 미리 체크돼 있으며, 수준 단계 없이 「开始/開始」로 끝난다. 저장 값: learning_language=['Korean'], viewer_language:v1={uiLocale, explanationLocale}=고른 값.
  12. 'Korean'이 주 언어인 계정은 배움·/study·작문 어디에서도 일본어로 열리지 않는다 — 준비 중 안내를 보인다. 계약 테스트로 고정.
  13. 한국어 사용자의 흐름·저장 값은 1판과 같다(내 언어 줄이 하나 늘 뿐).
  14. 라이트·다크 모두 v2 토큰으로 칠한다(그라데이션 머리띠 제거). uiConventions.test.js 통과.

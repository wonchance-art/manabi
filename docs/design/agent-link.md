- 상태: **설계 초안 · 오너 승인 대기** (2026-11-02 KST). 새 제품 범위라 학습 개선 지속 승인 밖 — 이 문서 승인 뒤 단계별로 착수한다.
- 출발점: #1077 [STATS-MAP-001 · AGENT-LINK-001 기록](https://github.com/wonchance-art/manabi/issues/1077#issuecomment-6553548961) · 통계 지도 아티팩트 07 · 08절.
- 오너 요구(보존): 프롬프트 문장만이 아니라 **결과가 어떤 프레임 · 형식으로 나오기를 바라는지까지** 설계한다.

## 0. 한 줄
manabi는 「AI 대화문을 바로 해석하고 단어장에 넣는」 앱이다. 개인 에이전트(OpenAI dots · Meta Muse · Claude)를 그 **입구 하나 더**로 쓰고,
에이전트가 학습 상태를 **화면과 같은 숫자로** 읽어 먼저 챙기게 한다.

## 1. 바뀐 사실 — 단계 순서를 다시 짠 이유
| 사실 | 근거 | 설계에 주는 영향 |
|---|---|---|

| ChatGPT는 원격 MCP 서버만 붙인다(「connectors」→「apps」, 2025-12) | DEV Community 2026-05 | 연결 통로는 원격 MCP + OAuth 하나로 dots · ChatGPT · Claude를 함께 덮는다 |

## 2. 단계
| 단계 | 무엇 | 새 기반 | 승인 |
|---|---|---|---|
| **0. 형식 + 붙여넣기** | ① 출력 형식 계약 ③ 프롬프트 묶음 + 「프롬프트 복사」 단추 · 에이전트와 나눈 대화 · 에이전트가 쓴 글을 **붙여넣어 들여오기**(빠른 분석 → 자료 저장, 출처 「에이전트」) | 없음(기존 빠른 분석 · 내 자료 · 탭 사전) | 이 문서 승인 |
| **1. 읽기 전용 MCP** | `get_today` · `get_summary` · `get_nudges` · `get_text_ingredients` — dots 초기 정책(읽기 전용)과 맞음 | `/api/mcp` 라우트 · OAuth(동의 · 철회 화면) · 요약 계약 v1 | 별도 승인(운영 인증 설정 · 약관) |
| **2. 쓰기 도구** | `send_to_manabi`(kind: conversation \| text) — 쓰기를 허용하는 에이전트(Claude 커넥터 등)부터, dots가 쓰기를 열면 확대 | 쓰기 범위(scope) · 한도 | 별도 승인 |

## 3. ① 출력 형식 계약 — 에이전트가 돌려줄 글 · 대화의 모양
manabi가 **추가 처리 없이** 해석 · 저장할 수 있는 모양. 프롬프트가 이 모양을 요구하고, 들여오기는 이 모양을 먼저 알아본다(아니면 일반 글로 받는다).

```text
# 제목: 주말 약속 (N4)
@level: N4
@target: 約束, 予定, 映画, 一緒に
---
A: 週末、何か予定ある？
B: 映画を見る約束があるんだ。一緒に行かない？
A: いいね！
---
@notes: 約束 = 약속 · 予定 = 예정
```

| 칸 | 규칙 | manabi에서 쓰는 곳 |
|---|---|---|
| `# 제목:` · `@level:` | 한 줄씩 | 자료 제목 · 수준 칩 |
| `@target:` | 쉼표로 목표 단어 | 본문에서 강조 · 「이 글에서 아는 말」 · 다시 만난 말 |
| 본문(`---` 사이) | 화자 줄은 `이름: 문장`, 글은 문단 | 대화 → 말한 사람별 줄 · 글 → 문단 |
| `@notes:` | 선택 | 뜻 줄(저장하지 않음, 참고 표시만) |

## 4. ② 보이는 프레임 — 같은 결과가 놓일 자리
| 자리 | 모습(텍스트 목업) |
|---|---|
| 에이전트 대화 안(1단계 이후 · MCP Apps) | `[manabi] 오늘 복습 34개 · 오늘 밤 흐려질 말 12개 → 복습실 열기` — 숫자 하나 + 행동 하나 + 링크 |
| manabi 뷰어 | 들여온 대화가 대화 모드와 같은 말한 사람별 줄로 · 머리에 「에이전트에서 들여옴 · N4」 · 목표 단어 강조 |
| 서재 카드 | 「주말 약속 · 대화 · 에이전트 · 아는 말 82%」 |
| 이번 주 창 | 담은 곳에 「에이전트」 칸이 생김(출처 표시가 있으므로) |

## 5. ③ 프롬프트 묶음 (0단계 · 「복사」 단추)
1. **오늘 단어로 글** — 「아래 단어로 {수준} 일본어 짧은 글을 [형식 계약]대로 써 줘: {오늘 복습 단어}」
2. **이 단어로 대화 상대** — 「{단어}를 자연스럽게 쓰는 대화를 나랑 해 줘. 끝나면 [형식 계약]으로 정리해 줘」
3. **방금 대화 정리** — 「방금 우리 대화를 [형식 계약]으로 정리해 줘. 내가 틀린 문장은 @notes에」
- 단어 · 수준은 manabi가 채워 복사한다(사용자는 붙여넣기만). 말투 규약: 죄책감 프레임 금지 · 「밀림」 · 「실패」 금지(망각 예보와 같음).

## 6. 요약 계약 v1 (1단계)
- `buildLearningSummary(rows, now)` — 화면이 쓰는 순수 모듈(weeklyReport · trueRetention · memoryHealth · weaknessProfile · forecast · learnReviewCount)을 서버에서 그대로 돌린다. SQL 집계 없음(이중 진실 금지 유지).
- 계약 테스트: **현황 화면 숫자 = 요약 숫자**(지표 사전 `metrics/registry` 이름 · 하루 경계 `learning_day_04_kst` 명시).
- 범위(scope): `summary`(숫자만) · `words`(단어 목록) · `write`(2단계). 답안 원문(detail)은 어느 범위에도 넣지 않는다.

## 7. 동의 · 보안 · 문서
- 연결은 사용자가 manabi 설정에서 켜고, 언제든 끊는다(토큰 즉시 폐기). 연결 목록 · 마지막 사용 시각을 보여 준다.
- 에이전트는 상시형이라 자주 묻는다 → 요약은 짧은 서버 캐시 · 계정당 호출 한도.
- **문서 개정(1단계 전 필수):** 개인정보 처리방침 §4에 「사용자가 연결한 에이전트」 줄(사용자 지시로 전달, 사업자별 방침 따름) · 약관 §3 「자동화된 방법으로 남용」에 「본인이 연결한 에이전트를 통한 본인 데이터 조회 · 전송은 남용이 아님」 예외.
  처리 위탁 · 국외 이전 표는 2026-11-02 KST에 실제와 맞췄다(이 문서와 같은 PR).

## 9. 선례 · 오픈소스
| 선례 | 판단 | 근거 |
|---|---|---|
| MCP + OAuth 2.1(원격 서버) | 채택 | ChatGPT · Claude · dots가 함께 붙는 유일한 길 |
| `mcp-handler`(Vercel, Apache-2.0) | 채택 후보 | Next.js 라우트 하나 · OAuth 보호 리소스 메타데이터 · 토큰 검사 내장 |
| Supabase OAuth 서버 | 부분 채택(검증 필요) | 기존 계정 그대로 인증 공급자 — 운영 설정 필요, 0단계에서 실제 지원 범위 확인 |
| Anki MCP 도구 구성 · anki_storytime 단어 고르기 | 부분 채택 | 「오늘 단어로 글」 도구 구성 참고 |
| 서버 집계 RPC · 차트 라이브러리 | 배제 | 이중 진실 · 번들 비용 |
| 이메일 다이제스트 | 보류 | 상시형 에이전트가 같은 자리를 더 잘 채움 |

## 10. 나침반 3문
- **정거장**: 뷰어 입구(들여오기) · 본문 귀환(오늘 단어로 글 → 다시 만난 말) · 받침(요약 읽기).
- **재사용**: 빠른 분석 · 대화 분석 · 내 자료 · 탭 사전 · materialFit · 지표 사전 · 순수 통계 모듈. 새 분석기 · 새 집계 없음.
- **이음새**: 들여온 대화는 출처 「에이전트」로 표시해 대화 모드의 교정 · 하루 한도 · 다시 꺼내기 셈과 섞지 않는다.

3. 1단계(MCP)는 0단계 사용 반응을 본 뒤 별도 승인으로.

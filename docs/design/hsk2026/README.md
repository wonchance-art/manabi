# HSK 2026 급수 목록 (설계 정본 자료)

중국어 「한자」 탭(HANZI-TAB-AL-001)과 레벨 화면 중국어 목록(LEVEL-LIST-AJ-001 보완)의 **급수 기준**이다.
오너 결정 2026-10-13 KST: 급수 기준은 HSK 2026.

## 출처
- 《中文水平考试 HSK 考试大纲》(Syllabus for the Chinese Proficiency Test), 中外语言交流合作中心 发布, **2025-11 发布 · 2026-07 实施**. 쪽마다 「汉考国际」 워터마크.
- 공식 배포처: 中文考试服务网 www.chinesetest.cn → HSK3.0 → 考试大纲.
- 이 목록을 뽑은 파일: 오너 구글 드라이브 `新版HSK考试大纲1219.pdf`, 4,636,209바이트, 406쪽,
  sha256 `ec74ce0439e837bbb15154be13e747ae798903b2fd3a331629df6c3b45504941`.
- **PDF 원본은 저장소에 싣지 않는다**(저작물). 목록만 뽑아 출처와 함께 둔다. 원본이 필요하면 위 배포처나 오너 드라이브에서 받는다.

## 파일
| 파일 | 내용 |
|---|---|
| `chars.json` | 汉字大纲. `levels` = 급수별 **认读字**(문서 순서 그대로, 한 문자열) · `writing` = 급수별 **书写字** |
| `words.json` | 词汇大纲 11,000개. 한 줄에 한 항목 |
| `diff-2021-2026.json` | 앱이 지금 쓰는 2021 기준(`src/lib/data/zhHskLevel.json`)과의 차이 |

### `words.json` 항목
`{seq, level, word, pinyin, pos, level_raw, pdf_page}` + 있을 때만 `extra_levels` · `headword` · `homograph` · `pinyin_alts`.
- **`level_raw`에 괄호 급수**(`1（4）`, `3（4）（7-9）`) 102개: `level` = 앞 급수, `extra_levels` = 괄호 급수. 품사도 괄호로 짝을 이룬다(半 「数、（副）」) — 괄호 급수는 그 뜻 · 품사가 그 급수에서 더해진다는 뜻으로 읽었다(해석).
- **동형어 번호**(本1 · 本2, 为1 · 为2 …) 82개: `headword` + `homograph`. 번호 없이 소리가 다른 같은 글자 표제어도 있다(还 hái / huán, 得 ×3).
- 병음 두 가지: 谁 shéi / shuí, 熟 shú / shóu → `pinyin_alts`.
- 품사 빈칸 495개(不客气 · 打电话 등 굳은 말) — 원문이 비어 있다.
- 2021 목록의 儿 표기(玩儿 · 一下儿)는 2026에서 대부분 儿 없는 표기다.

## 2021 → 2026 차이(요약)
- **글자:** 148자 추가 · 30자 빠짐(嫦 · 娥 · 俄 · 斯 · 尼 · 伊 … 고유명사 음역용). 2021 글자 급수는 「그 글자가 든 2021 단어의 가장 낮은 급수」로 셌다(2,970자 — 2021 공식 글자표 3,000자와 다름, 근사).
- **1급 글자 246자:** 220자는 2021에도 1급, 26자는 2021에 더 높은 급수였다(便 · 公 · 猫 · 苹 · 第 …). **2021 1급 글자 중 55자(着 · 走 · 过 · 就 · 跟 · 最 …)가 2026 2급으로 갔다.**
- **단어**(같은 표기 기준, 동형어 번호 무시): 같은 급수 5,669 · 어려운 급수로 2,820 · 쉬운 급수로 1,193 · 새 단어 1,214 · 빠진 단어 1,253(北边 · 车票 · 吃饭처럼 투명한 합성어가 많다).

## 뽑은 방법
PyMuPDF로 쪽마다 글자를 읽고 회전된 워터마크(「汉考国际」)를 걸렀다. 쪽 범위: 词汇大纲 인쇄 76–351쪽, 认读字 353–373쪽, 书写字 374–381쪽(PDF 쪽 = 인쇄 쪽 + 3). 번호가 끊기거나 겹치는 곳 0, CJK 밖 글자 0을 확인했다.

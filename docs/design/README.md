# docs/design — 확정 목업 · 화면 벽 규칙 정본

설계 세션이 확정한 화면 목업과 화면 벽(모든 화면을 펼쳐 두고 검수하는 판) 판정 규칙을
저장소에 둔다. Claude와 ChatGPT/Codex가 같은 파일을 읽고 바로 쓰기 위한 자리다.

## 왜 저장소에 두나
- 설계 원본(claude.ai 아티팩트)은 **비공개**라 Codex Cloud에서 열 수 없다. 인계문이 가리키는
  목업과 판정 규칙을 양쪽 모델이 같은 경로로 읽어야 한다.
- 아티팩트는 이 세션 밖에서 바뀌거나 사라질 수 있다. 확정본은 커밋으로 남긴다.
- 근거: 오너 결정 D-X1(2026-10-12 KST, 「권장대로 승인」) — 설계 세션은 이 폴더만
  자기 브랜치(`claude/*`) PR로 고친다. 그 밖의 경로는 건드리지 않는다.

## 소유 · 변경
- **소유:** 설계 세션(Claude). 개발 세션 · Codex는 읽기만 한다.
- **고칠 점이 보이면:** #1337(인계 · 회신) 또는 #1077(설계 기록)에 적는다. 이 폴더를 직접 고치지 않는다.
- **병합:** `docs/design/**`만 바꾸고 필수 CI가 통과한 PR은 설계 세션이 검증한 head로 직접 squash 병합한다
  (오너 상시 승인 D-X5, 2026-10-12 KST). 다른 경로가 하나라도 섞이면 이 승인 밖이다.
- **정본 순서:** 이 폴더의 파일 > 아티팩트 사본(`mirror`). 둘이 다르면 이 폴더가 맞다.
- 시각 표기는 KST다.

## 구성
| 경로 | 내용 |
|---|---|
| [`wall-rules.md`](wall-rules.md) | 화면 벽 AI 판정 규칙 정본 — 판정 종류 · 객관 검사 · 자동 승인 조건(교차 모델) · 자동 승인 금지 목록 · PR 코멘트 형식 |
| [`registry.json`](registry.json) | 설계 등록부 — 설계마다 코드 · 단계 · 목업 원본 · 프레임 · 연결 장면 · 인계 링크 |
| `mocks/<id>/<id>.html` | 확정 목업 원본. 파일 하나로 열린다(외부 의존은 Google Fonts뿐) |
| `mocks/<id>/<id>.<frame>.jpg` | 목업에서 뽑은 비교용 프레임. 화면 벽 「예정」 타일과 「목업과 일치」 판정에 쓴다 |

프레임 이름의 끝 글자는 화면 종류다: `.d` 데스크톱 그림, `.m` 휴대폰 그림. 끝 글자가 없으면 목업 속
장면 하나다. 프레임은 목업 안의 그림을 잘라 낸 것이라 실제 캡처(1280 · 390)와 픽셀 크기가 다르다.
그래서 목업 대비는 픽셀이 아니라 배치 · 위계 · 요소 · 문구 단위로 본다.

(두 곳에 적으면 갈린다). 저장소에 목업 원본이 있는 설계:

| id | 코드 | 목업 원본 |
|---|---|---|
| ak | LEARN-HOME-AK-001 — 배움 · 서재 · 산책 메뉴 + 배움 대시보드 + 현황 | [mocks/ak/ak.html](mocks/ak/ak.html) |
| rev | REV-SCOPE R1-A · R1-B — 복습 범위 · 개수 · 진입점 / 세션 · 카드 · 학습 단계 | [mocks/rev/rev.html](mocks/rev/rev.html) |
| onb | ONB-001 — 첫 방문 온보딩 + 내 언어 + 중국어권 한국어(준비 중) | [mocks/onb/onb.html](mocks/onb/onb.html) |
| ad | AD-R3 · AD-R4 — 뷰어 정돈 2차 | [mocks/ad/ad.html](mocks/ad/ad.html) (화면 캡처 내장, 약 1.6MB) |

| conv | v2-Z — 대화 모드 | [mocks/conv/conv.html](mocks/conv/conv.html) |

brand(아이콘 · 브랜드)는 Design 타입 보드라 파일 하나로 열리지 않아 아티팩트에만 둔다. mail(인증 메일)은 앱 화면이 아니라 화면 벽 밖이다.

### registry.json 항목
| 필드 | 뜻 |
|---|---|
| `id` · `code` · `title` | 설계 이름. `code`는 인계문(#1337)의 작업 코드 |
| `stage` | 진행 단계. 설계 세션이 인계 · 병합 때 고친다 |
| `source` | 목업 원본 경로(없으면 `null`) |
| `mirror` | 같은 목업의 claude.ai 아티팩트 사본(비공개 — Codex는 못 연다) |
| `handoff` | 인계 코멘트 링크 |
| `scenes` | 이 설계로 바뀔 화면 벽 장면 id |
| `frames` | 지금 화면과 대조할 목업 프레임 |
| `planned` | 아직 화면이 없는 확정 설계(화면 벽 「예정」 타일) |

## 목업 공통 결정
- **언어 표시는 글자로 한다**(「일본어」 · 「중국어」, 오너 결정 D-X6 2026-10-12 KST). 국기는 언어와 같지 않고, 繁體를 쓰는
  학습자에게 민감할 수 있다. 목업의 언어 칩은 모두 글자다.

## 목업 읽는 법 (개발 세션)
- HTML 원본을 브라우저로 열면 목업 전체(설명 · 결정 · 화면 크기별 그림)가 보인다.
- 인계문(#1337)의 수용 기준과 문구가 우선이다. 목업은 배치 · 위계 · 상태를 보여 주는 그림이다.
- 문구는 인계문과 글자까지 맞춘다. 다르게 써야 하면 PR에 이유를 적는다 — 화면 벽은 이 경우
  자동 승인하지 않고 오너에게 올린다([`wall-rules.md`](wall-rules.md) §6).

# RFC: 실자료(㉮㉯) 연결 — 소스·라이선스·파이프라인 v1

- **지위**: 설계 RFC(오너 일괄 승인 2026-07-26 큐의 마지막 설계 몫). 구현은 실행 큐 순서로.
- **목적**: 원칙 v1 P5의 ㉮(실재 검증)·㉯(실자료 각색) 비중 확대 — "가짜 기상 세계" 리스크를 문장 단위 출처로 해소하고, 실음원을 단계적으로 연결한다.
- **전제**: 개인 사용(브랜드 정책 v1과 동일 프레임 — 배포·수익화 전환 시 라이선스 전면 재검토 플래그). 실화폐 지출 금지(무료 소스·무료 API만).

## 1. 소스 후보 평가

| 소스 | 자료 | 라이선스 | 판정 |
|---|---|---|---|
| **Tatoeba** | 프랑스어 예문 수십만 + 일부 원어민 오디오 | 문장 = CC-BY 2.0 FR(저작자 표기) / **오디오 = 기여자별 상이(CC BY-NC 다수)** | **1순위** — 문장은 안전, 오디오는 라이선스 필터 필수(NC 제외 기본) |
| Mozilla Common Voice | 검증된 낭독 클립(문장 단위) | CC0 | 2순위 — 오디오 자유도 최고, 문장 풀은 잡다(레벨 매칭 필요) |
| Wikimedia Commons | 단어 발음 오디오(Lingua Libre 등) | CC-BY-SA 다수 | 어휘 카드용 보조 |
| 기기 TTS(현행) | 전 문장 즉시 | 로컬 합성(라이선스 무관) | **기본값 유지** — 실음원은 '있으면 교체' 레이어 |

## 2. 등급 정의 (P5 재확인)

- **㉮ 실재 검증**: 문장이 외부 실자료에 그대로 존재 — 출처 ID·라이선스·저작자 보존.
- **㉯ 실자료 각색**: 실자료 원문에서 어휘·인명만 치환 — 원문 ID + 변경 내역 명시.
- **㉰ 자체 저작**: 현행 기본값. 목표는 신규 예문의 ㉮㉯ 비중을 늘리는 것(대화 전체의 실자료화는 비목표 — 교육 설계상 자체 저작 대화가 정당한 영역).

## 3. 데이터 계약 (스키마 — P11(e)와 함께 도입)

예문·대화 라인에 선택 필드 `src`:

```js
{ fr: "Il n'y a plus de croissants.",
  src: { provider: "tatoeba", id: 1234567, license: "CC BY 2.0 FR", by: "사용자명", grade: "A" } }
```

- `grade`: "A"(㉮ 그대로) / "B"(㉯ 각색 — `basedOn` id 필수) / 필드 부재 = ㉰.
- contentOverrides 허용 키 추가·lint 검사(src 있으면 필수 하위 필드 검증)는 P11(e) 구현과 같은 PR.
- 표기 의무: 챕터 하단 "출처" 블록에 provider·저작자 자동 집계(렌더러 1곳 수정).

## 4. 수집 파이프라인 (결정성 우선)

1. **스냅샷 수집**: `scripts/fetch-tatoeba-fr.mjs` — 기준표 문형별 검색어(예: "n'y a plus", "si tu veux")로 Tatoeba API 조회 → 후보 JSON을 `scripts/data/tatoeba-fr-<문형>.json`으로 **커밋**(재현 가능·API 재호출 없이 검수).
2. **검수·등재**: Claude가 후보에서 레벨 적합(P3)·자연성 통과 문장만 선별해 src 필드로 등재(정본 저작).
3. **오디오 매칭**: 등재 문장 중 오디오 보유분만 다운로드 후보로 표시 — **라이선스 CC0/CC-BY만**, NC·SA는 플래그 보류(owner-gate). 저장은 public/audio/ 정적 파일(용량 상한 오너 확인).
4. 검증: lint가 스냅샷 JSON과 src.id 대조(등재 문장이 스냅샷에 실재하는지).

## 5. 적용 순서 (실행 큐)

| 순번 | 몫 | 담당 |
|---|---|---|
| 1 | 수집 스크립트 + 첫 스냅샷(fr A1·A2 문형 10종 × 후보 20) | codex 발주 가능 |
| 2 | src 스키마 + P11(e) lint + 출처 블록 렌더 | Claude(시스템 소폭) |
| 3 | fr A1~A2 예문 파일럿 대조 — 기존 예문 중 Tatoeba 실재 확인분 ㉮ 소급 표기 | Claude 정본 |
| 4 | 오디오 CC0/CC-BY 다운로드·교체 레이어(TTS 폴백 유지) | **owner-gate**(용량·수익화 재검토) |

## 6. 비목표

- 대화 전문의 실자료 대체(교육 설계 훼손), 유료 API·상용 코퍼스, 스트리밍 임베드 의존(오프라인 불가), DB 스키마 변경.

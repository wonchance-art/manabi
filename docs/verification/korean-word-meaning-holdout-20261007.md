# KO-MEANING-HOLDOUT-ZH-001 — 한국어 기본형 뜻(zh) 미사용 표본

작성: 2026-10-07 KST, Claude 세션. 생성 모델(Gemini)과 다른 모델이 만든 초안이다. 사람 감수 전에는 기대 답 자체도 확정이 아니다.
대상: #1346의 `korean-word-meaning-v2`. 이 PR부터 새 경로는 zh-CN·zh-TW에만 적용되고, 설명 언어 ko는 보류 중이다.

## 왜 필요한가

기존 66건 중 프롬프트 수정에 쓰지 않은 미사용 표본은 N01~N06 × 3언어 = 18건뿐이었다. 언어당 6건으로는 통과율을 품질 보증으로 볼 수 없다. 이 표본은 기존 기본형을 하나도 쓰지 않은 새 사례 30개 × 2언어 = 60건이다.

- 각 행에는 허용 예시, 사람이 판정할 검토 표현, 금지 오답과 그 이유가 들어 있다. 한국어기초사전 대역은 독립 근거로 함께 적었다.

## 자동 판정 규칙 (`scripts/eval/koreanMeaningHoldout.mjs`)

| 결과 | 조건 |
|---|---|
| FAIL | 금지 오답이 대응어로 나옴. 한 글자는 대응어 단위로, 두 글자 이상은 부분 문자열로도 잡는다. 또는 같은 사례의 다른 언어 표기만 나옴(글자체 오류). |
| PASS | 첫 대응어가 허용 예시에 있고 FAIL 조건이 없음 |
| REVIEW | 그 밖의 모든 답. **사람이 판정해 기록하기 전에는 통과로 세지 않는다.** |
| BLOCKED | 기본형 불일치 등으로 저장이 막힘. 오답 저장은 아니지만 사용성 손실이다. |
| ERROR | 호출·해석 실패. 재실행 대상이다. |

한계: 목록에 없는 간체/번체 혼용은 자동으로 잡지 못하고 REVIEW로 간다. 그래서 사람 판정 때 글자체도 함께 본다.

## 출시 기준 (언어별 따로)

- 치명 범주(A·E)의 FAIL은 0건이어야 한다. 하나라도 있으면 그 언어는 출시를 보류한다.
- 전체 FAIL은 1건 이하, BLOCKED는 3건(10%) 이하여야 한다.
- REVIEW는 전부 사람이 판정해 기록해야 한다.
- **표본 소모 규칙:** 이 결과를 보고 프롬프트나 후처리를 고치면 이 표본은 소모된다. 고친 뒤에는 새 표본으로 다시 평가한다. 결과를 보고 기대 답을 완화하는 것도 금지한다.

## 실행 방법 (생성 키가 있는 환경 — 오너 PC 또는 M09)

```sh
git fetch origin claude/korean-word-meaning && git checkout claude/korean-word-meaning
nvm use            # Node 24
npm ci
node scripts/eval/run-korean-meaning-holdout.mjs --dry-run      # 표본 검증(호출 0)
GEMINI_API_KEY=… node scripts/eval/run-korean-meaning-holdout.mjs
```

- 키는 실행하는 셸의 환경 변수로만 넣는다. 채팅이나 파일에 붙이지 않는다. 스크립트는 키를 출력하거나 기록하지 않는다.
- 운영과 같은 프롬프트 함수, `callLLM('standard')`, JSON 응답, temperature 0을 쓴다. 폴백이 쓰였으면 그 모델이 결과에 남는다.
- 60회를 호출하고, 기본 간격은 1.2초로 약 2~3분 걸린다.
- 결과는 OS 임시 폴더에 `results.md`와 `results.json`으로 남는다. 키와 개인정보가 없으므로 그대로 공유해도 된다.

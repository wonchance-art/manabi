# N5 관리자 로그인 진입·발행 준비 확인

2026-09-27 KST · PR #1324 후속 · 시작 head 2d7708bb5ffeb34cbe4c797d3d707fb80e009110.

## 발견과 수정

실제 Preview에서 로그아웃 상태로 `/admin/books/japanese-n5`에 들어가면 `/auth`로 이동하면서 목적지가 사라졌다. 로그인 폼은 `from`이 없을 때 `/home`으로 이동하므로 관리자가 다시 편집 화면을 찾아야 했다.

관리자 인증 미들웨어가 기존 `authEntryHref`를 사용하도록 연결했다. 로그인 화면의 `from`에 원래 관리자 경로와 조회 조건을 넣는다. 예를 들어 `/admin/textbooks?lang=Japanese&section=grammar`의 선택 조건도 유지한다. 로그인 후에는 기존 관리자 역할 검사를 다시 거친다. 일반 회원의 관리자 진입 거부, 네 언어 구교재 보관함의 경로/404 계약은 유지한다.

서버 요청에 전달되지 않는 URL fragment는 미들웨어가 보존한다고 주장하지 않는다. 교재 예문 링크의 판본·문단 복귀는 앞선 클라이언트 `authEntryHref` 연결이 담당한다.

| 기존 구현 | 판단 | 이유 |
|---|---|---|
| `authEntryHref`·`authReturnPath` | 재사용 | 로그인 화면·callback이 이미 같은 내부 주소 계약을 사용한다 |
| 기존 `middleware.test.js`·N5 발행 동선 E2E | 보완 | 실제 발견 경로와 권한/이전 판본 보존을 기존 검사에 추가한다 |
| 별도 로그인 저장소·리다이렉트 라이브러리 | 도입하지 않음 | URL 전달 한 곳의 누락이며 새로운 상태/의존성이 필요 없다 |

## 실제 계정 경계

최초 관찰한 Preview는 fjgm9bqp3 / 2d7708bb다. Codex에 정상 관리자 로그인 화면을 열어 두었으며, 현재 실제 계정 로그인은 대기 중이다. 공개 페이지·합성 계정 검수를 실제 저장 초안 대조 또는 OAuth 공급자 로그인 완료로 계산하지 않는다. 기존 초안·공개 포인터·개인 자료를 변경하지 않았다.

실제 계정 검수는 최신 후보/이전 판본을 오가도 저장 초안이 보존되는지, 검수용 교재와 두 메뉴/문화 글이 같은 판본으로 돌아오는지 확인한다. 공개 발행, 원고 교체/저장, 권한 확대, DB/env/alias, 병합, PDF·새 음성은 이번 범위에 포함하지 않는다.

## 결과 리뷰·다음 방향

사용자 동선을 직접 연 결과로 로그인 진입의 누락을 발견했다. 기존 공통 부품을 사용하여 목적지를 유지하고, 관리 권한은 원래의 서버 검사를 그대로 거친다. 자동 검수는 정상 계정의 저장 데이터를 검증하지 않으므로 실제 관리자 초안 대조가 다음 우선순위다. 인증이 없을 때 임시 자격 증명·권한 확대·개인 세션 복사로 검수를 대신하지 않는다.

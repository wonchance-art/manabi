## 기대와 실제

- 홈을 ‘오늘’과 실제 읽던 위치 중심으로 정리했다. 이어 읽기·교재 선택·복습·추천·다른 학습·보조 자료 이어 읽기는 유지하고, 장식 영문/슬로건/반복 위치 소개를 줄였다. 복습할 표현이 없는 상태와 저장한 표현이 없는 상태를 구분한다. 전체 저장 수를 오늘 복습량으로 제시하지 않는다.
- 교재 목록의 제목을 ‘교재’로 두고 하단의 다른 메뉴 홍보를 제거했다. 일본어 시작/이어 읽기, 언어 선택, 준비 중 표시, 선택 언어의 공개 읽을거리, 관리자 진입, 불러오기 실패/재시도는 유지한다.
- 표지는 ‘목차’와 실제 도구 이름으로 안내한다. 같은 첫 과로 가는 중복 버튼을 제거하되 과 중간에서 이어 읽기와 과 처음부터 시작하기가 다를 때는 둘 다 남긴다. 읽기 완료 수는 한 곳에 표시하고, 판본/학습 범위는 ‘교재 안내’, 브라우저 저장 범위는 계속 보인다. 주 화면에서 키보드로 안내를 펼쳐 확인했다.
- 발견의 본문 제목/소개/출처/갱신일/언어는 보존한다. 지역/주제/검색/초기화/더 보기/언어별 읽을거리와 문화 읽기를 남기고, 장식 제목·반복 언어명·앱 안 링크마다 붙던 화살표·자료 가져오기 홍보 하단을 제거했다. 빈 검색의 원인/다음 행동은 남긴다. 외부/새 탭 표시와 읽기 복귀 화살표는 이번에 변경하지 않는다.
- 비로그인 서재는 계정 보관의 이유와 로그인/읽을거리만 안내한다. 로그인 후 자료 추가/선택/폴더/휴지통/복원/실패/개인 범위는 그대로다. 기존 상세 목록은 ‘자료 상세 보기’, `/study/library`는 ‘지난 이야기’, `/vocab`은 실제 도착 화면인 ‘복습’으로 연결한다. 초기 명칭 초안에 있던 ‘내보내기’는 실제 화면에 해당 기능이 없어 구현 전에 제외했다.

기존 컴포넌트·네이티브 details·라우트·검색/복귀 상태를 재사용했다. 새 패키지·기록 체계·메뉴/저장 모델을 만들지 않았다. 내 서재에서 추가/복원/재시도, 교재에서 담은 표현과 참고 자료에 접근할 수 있다. 색/서체/책 표지는 기존 디자인을 유지한다.

## 출시 조건과 발행 전후 검수

출시 조건을 다음으로 고정한다. 일반 개선 아이디어를 뒤늦게 필수 조건에 계속 추가하지 않는다.

1. 공개할 범위의 **알려진 오답·명백한 의미 오류**가 남아 있지 않다.
2. 읽기 → 문제 풀이 → 답안 보존/재접속 → 설명·원문 복귀의 핵심 동선이 막히지 않는다.
3. 기존 판본·답안·표현 출처·개인 뜻·FSRS 일정·자료 권한을 손상시키지 않는다.
4. 최종 출시 후보의 필수 검사와 실제 실행 버전·배포 확인이 통과한다.
5. 이전 공개판으로 복원할 수 있고, 발행 직후 핵심 학습 연결 재검수를 마친다.

| 시점 | 확인 내용과 증거 |
|---|---|
| 발행 전 | 알려진 원고 오류, 실제 계정의 후보 읽기·풀이·재접속·모바일/키보드, 기존 저장·권한·판본 계약, 배포된 파일/버전, 초안 충돌·공개 포인터·복원 준비. 미실행을 성공으로 기록하지 않는다. |
| 발행 직후 | 새 공개판에서 실제 표현 저장 → 복습 목록 → 정확한 판본/원문 복귀, 기존 기록·공개 접근의 보존. 문제 시 기본 공개판 복원과 후속 조치. |
| 사용하면서 | 설명이 어려워 멈춘 곳, 오답의 원인이 학습 부족인지 문항 모호성인지, 다음 날 이어 공부하기, 저장한 표현 찾기/원문 복귀. 실제 관찰로 후속 우선순위를 정한다. |

현재 미발행 후보는 개인 표현 저장을 제한한다. 따라서 그 상태에서 실제 새 판본의 표현 저장까지 완주하도록 요구하지 않는다.
발행 전에는 기존 실제 발행판 동작과 로컬 판본/저장 계약을 구분해 검증하고, 새 판본의 실제 저장은 발행 직후 확인한다.
검수를 위해 공유 DB의 공개 포인터를 임시로 바꾸지 않는다. **운영에 새 파일 배포·확인 → 발행 → 운영 사후 검수** 순서다.
운영 및 계속 사용 중인 QA 주소가 새 공개판을 제공할 수 있는지도 확인해, 공유 DB만 앞서가는 상태를 만들지 않는다.

새 판본에 문제가 있으면 기본 공개 포인터를 이전 발행판으로 복원한다. 새 판본 파일·발행 기록과 그 판본에서 만든 학습 기록은 삭제하지 않는다.
코드 복원까지 필요하면 모든 발행 판본과 저장 계약을 지원하는 호환 배포를 사용한다. 단순히 오래된 코드로 되돌리는 것을 복구로 간주하지 않는다.
브라우저 답안은 판본별이며 서버 단어/SRS와 다르다. 기존 학습자의 구판 접근·이어보기를 보존하고 무단 답안 이식/판본 강제 전환을 하지 않는다.

2. 정상 교사/학생의 분리된 계정으로 설명판 저장·재접속 → 수업 표현 → 학생 원본 → 뜻/독음 → 직접 단어 저장 → 복습·같은 출처 복귀를 검수한다. 개인 노트 후보 누적·선택 저장·재접속도 확인한다. 기존 수업을 임의 시험 데이터로 쓰지 않는다.
3. 물리 iPad/Pencil·소프트 키보드·회전·교실 네트워크는 자동 WebKit 결과와 구별해 기록한다. 필수 조건을 통과시키기 위해 미실행을 성공으로 바꾸지 않는다.
4. 승인된 통합 범위의 출시 검수 충족 후 #1321의 최신 head를 지정해 main에 병합한다. 자동 운영 배포의 실제 merge SHA·환경·배포 ID·핵심 동선을 확인한다. 기존 공개 N5는 그동안7f를 유지한다.
5. 새 N5 공개는 별도 발행 범위에서 진행한다. 운영과 계속 사용하는 고정 QA에12d 파일이 모두 있는지 먼저 확인하고, 최신 초안/공개 version을 대조한 뒤 공개 포인터를 전환한다.

## 복구 조건

운영 main과 이전 고정 QA 코드에는12d 파일이 없다. 따라서 미리보기에서 공유 DB의 공개 포인터를 먼저12d로 바꾸면 운영 교재가 열리지 않을 수 있다. **웹 배포가 먼저, 교재 발행이 나중**이다.

새 판본 발행 후 내용 문제가 생기면 새 코드를 유지하고 공개 포인터를7f로 복원한다.12d 발행 기록·출력 파일과 그 판본에 저장한 표현의 출처는 계속 제공한다. 코드까지 되돌려야 한다면 모든 발행 판본과 새 저장 계약을 지원하는 호환 배포가 필요하다. 과거 운영 배포로 무조건 rollback하거나 DB/Storage를 삭제하는 방식은 쓰지 않는다.

#1316~#1320·#1322·#1323은 이미 #1321에 포함되어 있다. 원래 PR들을 main에 개별 중복 병합하지 않으며, 운영 통합 사후 검수까지 원래 브랜치를 보존한다.

## 결과 리뷰와 다음 방향

누적 코드의 통합은 완료됐다. 검수한 제품 소스와 병합 결과가 같으며 실제 사용자 데이터는 그대로다. 지금 남은 것은 기능 추가가 아니라 서로 다른 실제 역할의 최종 연결 검수다. 코드 통합 완료, 운영 출시, 교재 발행을 각각 보고한다. PDF 조판·새 음성·독립 일본어 감수·학습 효과는 이번 통합 완료 판정에 합산하지 않는다.

## 발견한 문제와 교정

일반 과의 기본 `checks` 139문항을 질문·선택지·정답·해설 단위로 내부 대조했다.
39과의 별도 학습 페이지와 추가 종합 문제까지 이번에 새로 전수 감수했다는 의미는 아니다.

| 문항 | 기존 문제 | 교정과 학습 근거 |
|---|---|---|
| 25과 확인 2 | `すわないでください`를 ‘앉지 말아 주세요’라고 해설 | 선택지를 `すわらないでください`로 수정하고 `すわる→すわって / すわらない`를 함께 설명. 같은 과의 て형 요청/ない형 요청, `入る→入らない` 설명으로 풀 수 있다. |
| 33과 확인 1 | `明るく、ひろいです`도 성립하는데 `く`를 오답 처리 | 오답을 `いで`로 바꾸고 `明るい→明るくて`와 `しずか→しずかで`를 대조. 같은 과 문형 1의 い/な형용사 연결 규칙을 평가한다. `く` 연결을 틀렸다고 가르치지 않는다. |

25과는 ‘앉아 달라는 요청’이라는 문제 의도가 그대로이고 정답도 그대로다.
33과는 한 문항에서 서술체의 차이를 함정으로 삼지 않고 배운 활용 규칙을 구별한다.
초급 해설에 새로운 중급 문법 설명을 길게 추가하지 않았다.

### 언어 근거와 판단 한계

- [도쿄외국어대 동사의 세 종류](https://www.coelang.tufs.ac.jp/mt/ja/gmod/courses/c02/lesson21/step2/explanation/039.html): 1그룹의 어말 u→a+ない, -aru의 그룹 분류. 이를 `すわる`에 적용하면 `すわらない`다.
- [도쿄외국어대 Vないでください](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/060.html): `すわない`는 `すう`의 ない형임을 명시한다. ‘앉다’의 부정형과 구별해야 한다.
- [津留崎由紀子, 형용사의 중지형을 사용한 복문](https://repository.ninjal.ac.jp/record/2116/files/kk_ngkgk_013_01.pdf), 『日本語科学』13(2003), 7–32: ク/クテ 중지형과 병렬 관계를 다룬다. 검색으로 제공된 초록을 확인했으며 PDF 직접 열기는 429로 실패했다. 이 근거와 문장 대조를 바탕으로 `く`를 유일한 오답으로 삼지 않는 편집 판단을 했다.
- [도쿄외국어대 형용사의 보통형](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/040.html): い형용사 て형 `くて`, な형용사 `で`의 기본 활용을 확인했다.

이는 작성 에이전트의 근거 대조이며 독립 일본어 감수·시험 전범위 충족·학습 효과 인증이 아니다.

## 변경·보존 경계

기존 `build-n5-copy-review.py`에 **문항 전체 이전 값 확인 → 오답/해설 동시 교정** 경로를 추가했다.
`n5-check-review.json`이 두 문항의 질문/선택지/정답/해설과 변경 이유를 묶어 기록한다.
일반 문자열 교정 경로의 선택지·정답 변경 금지는 그대로다.

- 원고 전체 이전 값과 해당 화면의 fieldset/해설 이전 값이 다르면 생성 실패.
- 정답, 정답 선택지 위치, 질문, 문항 ID, 선택지 수를 바꿀 수 없다.
- 빈 선택지·중복 선택지·같은 문항의 중복 개정·불완전한 문항 묶음을 거절한다.
- 새 판본은 별도 답안 공간을 쓴다. 기존 판본 답안·어휘·FSRS·출처를 이동하거나 덮지 않는다.
- 42과/499페이지/1,144출처, 나머지 문항·화면·모든 입력 키와 예문 상자, JS/CSS/상속 미디어 보존.
- 새 bundle SHA-256: `f5431fd1fbdb7ead0eb03cfc472099d3a37f57009a5406c6b59f29dc382e5c6c`.
- 생성기 계약에서 bundle/HTML/JS/CSS를 두 번 생성하여 보관본과 byte-identical 확인.
- 공개판은 7f, 관리자 검토 후보에만 8f 추가. 12d도 계속 선택 가능.

| 재사용 검토 | 판단 |
|---|---|
| 기존 불변 판본 생성기·출처 추출·답안 저장 | 채택. 기존 체계를 유지하면서 명시적인 문항 교정 경로만 추가 |
| 기존 출판 흐름 계약 | 최신 후보를 8f로 갱신. 초안 보존·발행/복원·출처/SRS 보존 조건은 유지 |
| 외부 문제은행·새 라이브러리/채점기 | 불필요. 자체 원고 두 문항의 정확성 문제이므로 의존성 추가 없음 |

## 로드맵 대조와 다음 방향

이번 결과는 N5 판본의 평가 정확성 보강이다. 웹 운영 출시가 끝났거나 새 판본이 발행된 것은 아니다.
운영 출시 검수의 의존 조건이 남아 있어 독립적으로 가능한 교재 품질 작업을 진행했다.
같은 이유로 문항을 계속 늘리거나 새 시안을 만드는 방향으로 확대하지 않는다.

다음 최우선은 정상 Preview 로그인 뒤 **개인 노트 복구·교사 판 저장/재사용·별도 학생 직접 학습 연결**을 실제 계정으로 확인하는 것이다.
접근 조건 해소 후 원본/개인 기록을 보존하며 학습→저장→재접속→출처 복귀를 확인해야 완료다.
이후 운영 웹 전환, 새 교재 파일 존재 확인, N5 새 판본 발행을 각각 구분한다.
독립 일본어 감수와 물리 iPad/Pencil 확인도 미완료다.

범위 밖: 운영 병합/승격, 공개 교재 포인터, DB·환경·Auth 설정, PDF, 새 음성.

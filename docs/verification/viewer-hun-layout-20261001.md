# 긴 한글 훈음 가독성 수정 — 2026-10-01

## 요청과 경계

남은 작업 안내 뒤 오너의 “좋아 작업 진행해”에 따라 긴 훈음 충돌을 첫 단위로 구현한다.
기준 운영 main1ea952aeb0c9f8782018a8ad13bf7056f5078dd5, 제품 cc44fb7156462af2e1e5719de0d35976468dd0df.
제외 범위/상태, 대만·일본 자형/표현은 별도 설계로 유지한다.
신규 Preview/운영 병합·배포·원고/판본·DB/env/권한 변경 승인이 아니다.

## 기대와 구현

자료 → 중국어 단어 카드 → 한자/훈음 → 뜻 → 기존 네 등급/발음 동선을 유지한다.
한자 대조 토글과 기존 지연 로드 테이블을 재사용한다. 한자와 라벨을 dt/dd로 짝지으며
훈음은 문서 흐름에서 공간을 예약한다. 긴 라벨은 자르거나 축소하지 않고 줄바꿈한다.
병음 부재/혼종/반복 글자에도 표제어 순서와 기존 두음 병기/음만 있는 값을 보존한다.
같은 한자가 두 번 있어도 각각의 짝을 남긴다. 빈 자료를 꾸며 내거나 AI를 추가 호출하지 않는다.
본문과 일본어 요미, 글자 정보 키보드 동작, 개인 뜻/FSRS/출처 계약은 그대로다.

## 재현과 선례

실제 사전의 连弩를 기존 index.css+reader-controls.css로 렌더했다.
390px 브라우저/300px 카드에서 인접 라벨 가로 겹침101.117px, 긴 라벨 왼쪽좌표 -38.820px.
내용 폭을 갖는 absolute/nowrap 배치가 이웃 라벨과 카드 왼쪽으로 넘쳤다.
로컬 합성 마크업과 기기 폴백 폰트 증거이며 실제 사용자 자료/운영 계정 검수가 아니다.
기존 자료·listHanjaHunEum·Grid 부품을 재사용했다. 외부 패키지·폰트·사전 조달은 없다.
일반 Grid/문서 흐름을 부분 채택하고 한글 훈음을 일본어 요미의 글자별 절대 루비로
간주하는 배치는 배제했다. 일본어 요미의 JLReq 계약은 유지한다.

2026-09-01의 ‘세로 증가0/루비 대칭’ 검사는 이번 채택 설계의 ‘온전한 짝/줄바꿈/무겹침’
검사로 대체한다. 통과만을 위해 허용 오차를 키우거나 요미·병음 검사/접근성 검사를 제거하지 않는다.

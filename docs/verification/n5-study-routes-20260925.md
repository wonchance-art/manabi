## 발견한 반례와 조정

- 기존 출력의 예문은 왼쪽 4px 테두리였지만 앱 공통 디자인은 1px 상자다. 최초 자동검사의
  3px 이상 조건이 잘못됐다. 실제 화면에서 상자/바탕/줄 구분을 확인하고 승인된 앱 디자인은
  바꾸지 않았다. 박스가 없어졌다고 결론 내리거나 테두리를 임의로 굵게 만들지 않았다.
- 합성 프로필에 당일 접속 시각이 없어 기존 출석 갱신이 반복됐다. 합성 데이터를 보완했다.
  정상적인 원본 읽기 기록 1건과 후보 미리보기의 서버 무저장을 구분해 검사했다.
- 개발 포트 8892는 다른 세션이 사용 중이어서 그 프로세스를 건드리지 않고 48991/48992로
  이동했다. 메모리 부족도 코드 결함 수정으로 주장하지 않는다.
- 내용 분리만으로 42과의 전체 분량이 줄어든 것은 아니다. 단계 시작·마침점이 읽기를
  나눌 수 있게 만들었고, 실제 완주 시간/정답률 개선은 아직 관찰하지 않았다.

## 발행 경계와 다음 방향

기존 `index.json.current`와 DB 발행/초안/판본 행을 바꾸지 않았다. 신규 후보는 명시적
판본 주소와 관리자 권한으로 검토한다. 기존 답안/진도를 새 판본으로 자동 이관하지 않는다.
옛 교재에서 담은 표현과 서체·기존 음성 참조를 위해 원본 판본은 계속 포함해야 한다.

다음 우선 작업은 **32·39과 누적 복습 및 읽기 문항의 의미 감사**다. 앞 과를 실제로 다시
떠올리게 하는지, 보기 두 개가 동시에 자연스럽지 않은지, 필요한 표현을 먼저 배웠는지
확인하고 필요한 것만 보완한다. PDF·새 음성·실제 학습자 완료 시간 조사는 별도 범위다.

원격 PR/CI/미리보기와 최종 closeout은 이 문서의 후속 기록 및 #150 exact-head 인계가 정본이다.

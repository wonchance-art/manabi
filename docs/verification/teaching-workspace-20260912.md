# 설명판 수업 동선 개선 — 2026-09-12

## 목적과 범위

교사는 교재를 옆에 둔 채 표현을 바로 입력·검색하고 판에 놓아 설명한다. 선택한 표현/필기를 학생에게 크게 보여준 뒤 같은 배치로 돌아온다. 운영 main `0a071374cbd5577da7361c64196e666667466f32`에서 별도 작업 공간과 `codex/teaching-workspace-20260912` 브랜치를 만들었다. 원래 iCloud 작업 폴더의 미완료 변경은 건드리지 않았다.

오너가 승인한 텍스트 구성: 공통 팀/과/화면 모드 상단 바 → 펜·선택·지우개·글자·화살표·레이저 → 설명판과 교재 → 표현 입력/페이지/저장 상태. 이번 범위는 화면/도구 통합, 과 이동 상태, 빠른 표현, 보여주기다. DB·환경 변경, 서버 동기화, 손글씨 인식/AI, 교재별 재사용 묶음은 포함하지 않는다. 월드 본생성/PNG 결정성 규칙은 이 웹 작업에 적용되지 않는다.

## 변경과 보존 계약

- 공통 상단 바: 팀 홈/과 선택, 설명판·함께·교재, 보여주기, 입력, 수업 기록, 닫기. 개인/학생 화면은 기존 흐름을 사용한다.
- 설명판과 교재 사이 분할 손잡이: 포인터와 키보드 조작. 작은 화면은 위아래로 배치한다. 보조 교재에서 중복 수업 메뉴와 개인 통계를 감추고 읽기 도구/본문을 우선한다.
- 문구만 입력하고 Enter 또는 바로 놓기로 즉시 삽입한다. 읽기/뜻은 필요할 때 펼친다. 교재·이미 로드된 본인 단어·현재 날짜 판의 표현을 검색한다. 사전 조회와 일본어 가나 후보는 기존 경로를 재사용한다. 검색과 조회는 수업 기록을 게시하지 않는다.
- 원래 카드/필기 요소의 사본으로 별도 Excalidraw 보기 화면을 연다. 읽기·뜻 숨기기, 레이저, 확대는 원래 판의 좌표·카메라·저장 데이터에 쓰지 않는다. 닫으면 초점과 원래 편집 화면으로 돌아온다.
- 상단/하단 이웃 과 링크와 과 목록이 모두 `board=1` 상태를 보존한다. 닫거나 기존 수업 기록으로 이동하면 URL 상태도 제거한다. 사용자·팀·날짜별 세션 설정으로 비율/화면 모드/입력 초안을 복원한다.
- 원래 판 저장은 IndexedDB와 기존 충돌본/백업 계약을 유지한다. 같은 탭의 이전 과 저장을 기다린 뒤 다음 과에서 같은 판을 읽는다. 다른 탭의 충돌 비교는 유지한다.
- 학생에게 남기는 표현은 기존 명시적 추가 버튼과 대기열/RPC만 사용한다. 교재 원문·출처·개인 복습·학생 권한을 변경하지 않는다.

## 검수 기록

- 변경 범위 52개 계약 테스트 통과. `npm test -- --maxWorkers=2`: 388파일/4,191개 통과(최종 JS 보완 후 61.44초). 마지막 키보드 CSS 보완 후 UI/작업 공간 계약 26개도 재통과했다.
- JSX 포함 ESLint 통과. 미리보기 표시 초기화 경고를 실제 브라우저에서 발견해 mount 이후 API 호출로 수정했다.
- 개발 서버 하단 Next.js 배지가 판 번호 버튼과 겹쳤다. 운영 CSS에 우회 규칙을 넣지 않고 프로덕션 빌드로 최종 검수한다.
- 실제 휴대폰 스크린샷에서 위아래 패널 겹침을 발견해 외부 컨테이너를 기준으로 재배치했다. 가로 넘침뿐 아니라 패널 경계/폭도 검사한다. 선택하지 않은 카드가 리사이즈 뒤 화면 밖으로 빠지던 문제도 카메라 맞춤으로 보완했다.
- Excalidraw의 모바일 실행 취소/다시 실행은 네이티브 하단 도구 안에 있어 메뉴 간소화 때 함께 숨겨졌다. 해당 네이티브 버튼은 다시 노출하고 가시성/캔버스 여백을 검사한다.
- 화면 키보드는 기존 `useReaderLayout`의 visualViewport 상태를 재사용한다. 키보드가 열릴 때 판 도구/하단 관리 기능을 접고 빠른 입력을 유지한다. 휴대폰에서는 입력 중 보조 교재를 잠시 접고, 닫으면 같은 교재로 돌아온다. 가상 visualViewport 축소 검수와 물리 iOS 키보드 검수는 구분한다.
- `npm test`가 정한 전체 웹 검사 범위를 사용한다. 별도 월드 테스트는 저장소에 포함되지 않는 OSM 스냅샷을 요구하므로 이번 웹 변경의 실행 범위가 아니다.
- 최종 `npm run lint`, JSX 명시 ESLint, `git diff --check` 통과. `npm run build`: 475페이지 생성 완료, 종료 코드 0. 로컬 기본 2GiB 힙 빌드는 메모리 한도로 실패했으나 빌드 프로세스에만 4GiB 힙을 제공해 통과했다. 프로젝트 환경 설정/엔진은 변경하지 않는다. 기존 lessonAdapters/lessonModel의 익명 기본 내보내기 경고 2건은 이 범위 밖이다.
- 최종 프로덕션 빌드의 `e2e/teaching-board.e2e.mjs`: Chromium 마우스/터치 각각 18개 흐름 통과, 콘솔·런타임 오류 0. 실제 React와 IndexedDB, 폐기용 PGlite의 기존 수업 RPC, 합성 HTTP 자료를 사용했다. 교재 출처·카드/필기·그룹·undo/redo·표시용 사본 불변·Esc 초점 복귀·명시적 수업 기록·과 이동/초안/분할 비율·로컬 검색·수정 취소·충돌 복구·가나 후보/IME·백업을 검수했다.
- 화면 크기: 1440×1000, 1024×768, 768×1024, 390×844, 846×634(121% 브라우저 확대에 대응). 휴대폰 패널 겹침/가로 넘침/undo·redo/내용 가시성을 검사하고 스크린샷을 직접 검토했다. visualViewport 축소로 키보드를 모사해 입력 버튼 가림과 교재 복귀를 확인했다.
- 최종 미리보기 주소·원격 CI와 head SHA는 PR/#150에 기록한다. 운영 병합·별칭 변경은 이번 제출에 포함하지 않는다.

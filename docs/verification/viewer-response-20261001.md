## 반례와 남은 한계

- 원격 저장과 로컬 큐가 모두 실패하면 평가를 복원해야 한다. 원격 실패지만 큐가 성공한 경우는
  실패로 되돌리지 않고 기존 동기화 계약을 유지한다.
- 문맥 연결 실패는 카드 저장 실패와 구분한다. 기존 `이 문맥 추가`로 다시 시도할 수 있고
  안전 조건을 확인한 취소만 제공한다. 새 단어 등급 1은 확인 후 바로 복습 대상일 수 있다.
- 기기 음성 목록이 아직 없거나 해당 언어 음성이 없으면 서버 경로의 첫 재생 지연이 남는다.
  사용자가 선택한 원격 Web Speech 음성 자체의 네트워크 지연도 가능하다.
- 합성 브라우저 검수는 저장 실패·경합·서버 요청 제거의 근거다. 실제 계정/기기에서의
  가청 지연과 음질 검수 또는 운영 반영 완료를 대신하지 않는다.
- DB 트랜잭션/오프라인 큐 구조와 다른 페이지의 저장·음성 경로를 확대 개편하지 않는다.
- 기존 `logReviewEvents`는 fire-and-forget이라 이벤트 INSERT만 실패한 경우는 정본의 SRS 실패/큐
  경로를 검증하지 못한다. 이 기존 이벤트 기록의 실패 전달 문제를 이번 성능 수정에서 바꾸거나
  전체 저장을 원자적으로 만들었다고 주장하지 않는다. 별도 학습 기록 보존 점검 후보로 남긴다.

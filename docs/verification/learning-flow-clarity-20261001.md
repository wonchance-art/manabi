- 직접 연 교재에서는 실제 진입하지 않은 ‘내 서재’ 뒤로가기를 표시하지 않는다. 진입 맥락이 있으면 표지/과/목차 링크에 전달하고 공개 목록에서 온 경우 ‘발견’으로 명명한다. 외부 주소는 기존 허용 목록 밖으로 나가지 않는다.

개인 뜻·표현 ID·FSRS·판본·답안·읽기 저장·출처 URL 계약, 수업 복사와 권한, 자료/원고 내용은 변경하지 않는다. 교재 읽기 완료/답안은 언어 능력·시험 합격으로 계산하지 않는다. 새 보고서·과정·시험·월드·PDF/음성 구현은 제외한다.

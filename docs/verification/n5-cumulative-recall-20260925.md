## 결과 리뷰와 다음 방향

32과의 새 학습/누적 복습과39과의 다음 날/앞 과 복습 경계가 분명해졌다.

실제 학습 시간·JLPT 충분성을 검증한 것은 아니다. 안내는 더 붙이기 전에 기존 문구와
중복되는지 실제 화면에서 확인하고, 기존 원고/출판 형태가 다른 과도 함께 검사한다.

다음은 기존 전권 감사의 남은 항목인 **한자 첫 노출·읽기 도움·자력 회상 연결**을 우선한다.

확인된 문제만 교정한다. 운영 발행 전 실계정 확인·독립 감수·물리 기기는 별도 조건으로 남긴다.

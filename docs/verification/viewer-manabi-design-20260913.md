# 뷰어 디자인 일관성 및 설명판의 단어 창 — 2026-09-13

오너 요청: “뷰어 쪽에 디자인 개선해봐. 웹 메인 페이지 기준 일관적으로.” 앞선 단어 창 점검에서 설명판이 기존 뜻 패널을 숨겨 놓은 문제도 확인했다. 교재 읽기→뜻 확인→개인 단어 저장/설명판으로 가져오기 순환을 보완한다.

기준은 승인된 실제 `/home` 화면과 기존 `web-shell.css`다. 메인 화면에서 따뜻한 종이색, 짙은 잉크색, 얇은 구분선, 작은 모서리, 언어별 포인트를 확인했다. 본문 조판/학습 상태 색을 브랜드색으로 덮지 않는다.

## 적용한 화면 구성

- 상단: 서재 복귀와 과 이동 / 듣기·Aa·학습·관리. 무거운 버튼 외곽을 줄이고 최소 터치 영역을 유지한다.
- 제목: 작은 reading room·언어/레벨 줄 → 자료 제목 → 원래 모음집/북마크 기능과 학습 정보 → 밝은 본문.
- 뜻 카드: 기존 단어/문장 탭, 표제어와 핵심 뜻, 일본어 참고/접힌 상세, 기존 새 단어 저장을 유지한다.
- 설명판 함께 보기: 같은 뜻 카드를 교재 쪽에 열고 [판에 놓기]·[크게 보기]를 제공한다. 중복된 숨은 단어 카드를 만들지 않는다. 판 삽입은 개인 복습이나 학생 수업 기록 게시와 별개다.
- 휴대폰: 뜻 카드를 읽는 동안 교재를 우선 표시한다. 설명판 컴포넌트/상태는 유지해 카드가 닫히면 원래 판으로 돌아간다.

# 교사 설명판 — 1차 구현과 검수 (2026-09-12 KST)

수업 교재를 떠나지 않고 교재 안팎의 표현을 꺼내 필기·화살표와 함께 설명할 수 있는 실제 통합 구현이다. 오너가 승인한 설명판 설계 v1.1의 캔버스 적합성 검증 범위다. 기존 개인 뷰어·학생 사본·FSRS·교재 원문은 수정하지 않는다.

## 사용 흐름

1. 팀 수업의 교재를 열고 **설명판**을 누른다. 기존 `/viewer/:id?class=:team&day=:day` 주소에 `&board=1`로 바로 열 수도 있다.
2. 옆 교재에서 단어·표현을 선택하고 **판에 놓기**. 원문·읽기·뜻과 출처를 함께 가져온다.
3. 교재 밖의 말은 **표현 추가**에 입력한다. 기존 공용 사전에서 뜻을 찾거나 직접 적는다. 일본어 가나는 표기 후보를 보고 선생님이 선택한다. 동음이의어를 자동 확정하지 않는다.
4. 표현 위에 필기·선·화살표를 그리고 이동·크기 변경·회전한다. 여러 요소를 선택해 **함께 묶기**. 읽기·뜻을 가리거나 카드 내용을 수정할 수 있다.
5. **교재 접기 / 교재 크게**로 설명과 읽기 비중을 바꾼다. 교재 과가 바뀌어도 같은 팀·날짜의 판은 이어진다.
6. 보여주기만 하면 학생 기록은 바뀌지 않는다. 학생에게 남길 표현에만 **오늘 표현에 추가**를 누른다. 기존 수업 저장 대기열과 원자적 RPC를 이용한다.
7. 페이지별 판서와 화면 위치를 이 기기에 자동 보관한다. **백업**으로 JSON을 내려받거나 가져올 수 있다. 복원은 기존 판을 보존하고 새 판으로 덧붙인다.

## 범위와 데이터 계약

- 진입과 도구는 기존 `canTeachClass`의 교사/자료 소유권 확인 뒤에만 제공한다. URL에 `board=1`을 임의로 붙이는 것으로 권한이 생기지 않는다.
- Excalidraw는 교사가 설명판을 열 때만 동적으로 읽는다. 기존 개인·학생 뷰어의 주 경로에 캔버스를 상시 마운트하지 않는다.
- IndexedDB 키는 사용자·팀·수업 날짜로 분리한다. 교재 ID를 키에 넣지 않아 과를 옮겨도 판서가 이어진다. 서버 동기화를 구현한 것으로 표시하지 않는다.
- 저장은 같은 트랜잭션에서 revision을 비교한다. 다른 탭의 최신 저장을 덮어쓰지 않으며 충돌본은 별도로 보관하고 백업 메뉴에서 다시 가져올 수 있다. 단순 열람은 새 저장으로 취급하지 않는다.
- 페이지·요소·용량 상한 및 백업 구조를 검증한다. 외부 iframe/이미지 삽입은 이 차수에서 받지 않는다.
- 표현은 출처 스냅샷을 보관한다. 원문을 수정하면 교재 출처로 잘못 기록하지 않도록 수동 표현으로 분리한다. 수업 기록에 추가할 때는 현재 교재에서 출처를 다시 검증한다.
- 네트워크나 사전 조회가 실패해도 직접 입력하여 판에 놓을 수 있다. 새로 조회한 결과가 선생님의 후속 편집을 덮어쓰지 않도록 요청·편집 버전을 확인한다.
- 운영 DB, 환경 변수, 배포 별칭, 학생 자료 권한 변경 및 운영 병합은 하지 않는다.

## 검증

`e2e/teaching-board.e2e.mjs`는 실제 React 화면, 격리된 HTTP 인증/자료 응답, 임시 PostgreSQL(PGlite), 실제 브라우저 IndexedDB를 사용한다. 운영 수업 자료를 변경하지 않는다.

- Chromium 마우스 및 터치 환경 각각 12개 흐름 통과, JavaScript 런타임/React 경고 0. 가짜 Supabase 호스트의 Realtime WebSocket 실패는 검수 환경의 예상된 제외 항목이다.
- 교재 표현 출처, 카드 위 실제 필기, 실행 취소/재실행, 묶음 이동, 새로고침 후 좌표/필기 복원.
- 수동 표현 표시와 명시적 수업 기록 추가 구분, 뜻 가리기, 여러 판, 다른 과로 이동.
- 1440×1000 / 1024×768 / 768×1024 / 390×844. 본문과 교재 접근, 가로 넘침 검수.
- 두 탭 충돌 시 최신 판 보존 및 충돌본 재사용, JSON 백업/복원과 잘못된 파일 거부.
- 가나 후보 선택, IME 확정 중 성급한 제출 방지, 개인 뷰어 미노출 확인.
- 모델/API 계약 테스트 12개: 출처 보존·분리, 네이티브 요소, 그룹 복제, 회전/크기, 저장 형식, 좌표, 긴 글, 인증, 가나 모호성.
- 전체 Vitest를 빌드 종료 후 독립 실행하여 **386파일 / 4,182개 통과**. 중간 동시 실행의 기존 `studiesRefs` 훅 시간 초과는 독립 전체 실행에서 해소됐다. 임의로 타임아웃이나 테스트를 완화하지 않았다.
- 로컬 `npm run build`의 사전 검사·컴파일·타입 검사·페이지 생성 통과(309초, 최대 RSS 약 1.82GiB). 기존 커리큘럼 경고 11개와 기존 익명 기본 내보내기 경고 2개는 변경하지 않았다. 마지막 표시 보완이 포함된 최종 head의 CI/미리보기 결과는 CODEX_DONE에 기록한다.

재현:

```sh
QA_BASE=http://127.0.0.1:3110 \
QA_PGLITE_MODULE=/path/to/pglite/dist/index.js \
node e2e/teaching-board.e2e.mjs
# 터치 실행: QA_TOUCH=1, 다른 결과 경로: QA_OUT=/tmp/manabi-board-touch
```

기존 `e2e:build`와 같은 테스트용 공개 환경 설정으로 앱을 실행한다. 테스트 하니스에 실계정 자격 증명은 들어 있지 않다. 기본 브라우저 경로는 macOS Chrome이며 `QA_CHROME`으로 변경할 수 있다.

## 후속 검증과 다음 차수

- 물리 iPad/Apple Pencil의 필압·손바닥 오인식·장시간 필기·두 손가락 제스처는 실기기 검수가 필요하다. Chromium의 터치 에뮬레이션을 실물 검수로 간주하지 않는다.
- 현재 판은 이 기기에만 저장된다. 다른 기기, 브라우저 데이터 삭제 이후를 위해 백업이 필요하다. 서버 동기화·버전 복원은 후속 범위다.
- 손글씨 자체를 문자로 인식하는 기능, AI/외부 사전 연결, 개인 표현 검색은 아직 구현하지 않았다. 이 차수는 키보드 가나 입력과 기존 공용 사전 조회를 제공한다.
- 설명 묶음을 교재의 특정 위치에 재사용 가능한 템플릿으로 연결하고, 학생에게 전달할 내용 선택과 분리하는 단계가 다음이다. 기존 텍스트 주의점과 기존 학생 기록은 그대로 유지된다.

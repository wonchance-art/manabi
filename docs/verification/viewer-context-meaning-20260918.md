# 뷰어 문맥 뜻 선택 — 2026-09-18

## 문제와 결과

중국어 `东道主`는 같은 명사라도 대접하는 사람과 행사 주최 측을 가리킬 수 있다. 기존 분석은 같은 품사의 첫 사전 뜻을 고르므로 접대 문맥에 `주최국`이 남았다. 이번 변경은 분석을 무조건 덮어쓰지 않고, 단어창에서 학습자가 뜻을 비교하고 확정하는 흐름을 추가한다.

단어 → **다른 뜻 확인** → 사전 후보 비교 → 필요할 때 **이 문장의 뜻 확인** → AI 후보와 문맥 근거 확인 → **이 자료에만 저장**. 하단 개인 단어 저장/복습 평가는 그대로다. 사전 후보와 AI 후보를 구분하며 뜻을 고른 것만으로 저장하지 않는다. 일본어 대응어 조회는 저장된 뜻을 기준으로 새로 분리한다. 조회 결과가 도착해도 동작 버튼을 유지해 키보드 초점이 사라지지 않는다.

## 범위와 데이터 경계

- 중국어 본문 토큰의 개인 자료 소유자에게 자료 한정 저장을 제공한다. 다른 사람의 자료에서는 뜻 후보 비교만 가능하다. 수업의 별도 교사 편집기는 기존 흐름을 유지한다.
- 기존 토큰 교정/RPC 및 교정 기록 경로를 사용한다. 소유권과 현재 뜻을 확인하며, legacy UPDATE는 반영된 행이 없는 경우 실패로 처리한다.
- 사전 후보는 선택된 뜻과 명시된 품사만, AI 후보는 뜻만 전달한다. 독음·본문·출처·개인 단어·복습 일정·공유 사전에는 자동 반영하지 않는다.
- `/api/explain`의 명시적 후보 분기는 기존 인증/요청 제한을 사용한다. 모델 조회만으로 교정 기록을 포함한 DB 쓰기를 하지 않는다. 기존 문맥 해설 API 응답과 수업 해설은 유지한다.
- 계정·자료·토큰·표제어·표면형·현재 뜻·품사·전체 문장으로 후보 캐시를 분리한다. 자동 조회/재연결/무효화 재조회가 없고 선택 전환 시 진행 중 요청을 취소한다. 불확실하거나 형식이 맞지 않는 출력은 확정 후보로 내보내지 않는다.
- DB/Storage 스키마, 운영 환경 변수, 운영 배포와 main 병합은 변경하지 않는다.

## 검증 및 증거 구분

- 단위/API: 같은 품사의 다른 뜻, 필드 제한, 계정 변경, 전체 문맥 캐시, 불확실/잘못된 응답, 인증/입력 거부, 조회 시 DB 무기록, 기존 설명 API/일본어 회귀를 검증한다.
- 합성 브라우저: Chromium/WebKit에서 후보 조회가 수동임을 확인한다. 저장 실패 후 선택 유지, 성공 후 접힘/초점 복귀, 늦은 응답 취소, 계정/품사/뜻/문장 분리, 조회 버튼 초점 유지, 재시도/보류, 읽기 전용/로그아웃, 390/1180px 넘침을 검증한다. 실제 컴포넌트와 API 형식의 모의 응답을 사용하며 실제 DB 저장/외부 모델 품질의 증거로 간주하지 않는다.
- reader 프로필은 6단계, release 프로필은 12단계로 확장했다. 신규 시나리오도 필수 CI에 포함한다. JS/JSX ESLint는 `--ext .js,.jsx`로 검사한다.
- 화면을 직접 열어 390px Safari 캡처의 여백·현재 뜻/후보 구별·버튼 대비를 확인했고 언어 색상을 따르도록 저장 버튼을 보완했다.
- 최초 전체 테스트는 변경하지 않은 콘텐츠 대량 로딩 두 곳에서 시간 초과가 발생했다. 테스트 내용을 바꾸지 않고 동시 실행 수를 2로 낮춘 재검수에서 429파일/4,581개 PASS, 기존 1 SKIP을 확인했다. 관련 34개와 변경 JS/JSX ESLint도 통과했다. 최종 결과/정확한 head/CI/배포는 #150 인계 및 로컬 closeout에 기록한다.

## 남은 확인과 다음 방향

실계정 브라우저가 연결되지 않아 실제 공급자의 새 문맥 후보 → 자료 한정 저장 → 재접속 → 일본어 대응 흐름은 이 문서 시점에 미검수다. 정상 로그인된 자체 작성 검수 자료로 재개하며, 원본·개인 단어/SRS·공유 사전 불변까지 확인해야 한다. 기계적 스키마 검증은 번역의 정확성을 증명하지 않는다.

기존 legacy 자료의 전체 JSON UPDATE 경로는 다른 창의 동시 수정과 경합할 여지가 남아 있다. source-passage RPC의 비교 저장과 같은 수준으로 legacy 경로를 옮기는 일은 DB 변경을 포함하는 별도 제안이다. 이번 변경의 `expectedMeaning` 확인을 서버 동시성 보장으로 표현하지 않는다.

우선순위는 (1) 이번 기능의 실계정 의미/저장 검수, (2) 교사·학생 원본 직접 학습 흐름의 실제 권한 검수, (3) 이중언어 감수와 물리 iPad/Pencil이다. 의미 품질은 접대/행사/동형어 등 독립 표본별로 평가하며 임의 정확도 백분율을 제시하지 않는다.

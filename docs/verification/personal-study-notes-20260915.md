# 개인 학습 노트 → 단어 정리

2026-09-15 KST. 사용자 요청: 수업을 가르칠 때뿐 아니라 참여하면서 적은 노트를 바탕으로 개인 단어를 한 번에 정리한다. 승인한 설계의 개인 보관·글자/표현 정리와 선택 영역의 손글씨 인식을 구현했다.

## 적용

- `/materials/add`의 ‘필기 노트로 작성’, 읽기 뷰어의 학습 메뉴에서 개인 노트 생성. `/notes/new`, `/notes/{id}`.
- 기존 Excalidraw 설명판을 공통 캔버스로 추출. 개인 노트는 교사·팀 권한 없이 사용하며 수업 기록에 자동 게시하지 않는다.
- 여러 표현, 자유 필기, 글자 도구, 페이지, 표시 토글, 기존 내 단어 검색을 유지한다.
- ‘단어 정리’는 입력된 표현 요소와 글상자 여러 줄을 모은다. `표현 → 뜻` 형식을 인식하고 원래 위치·필기는 보존한다.
- 원래 필기와 후보를 함께 보면서 표기·읽기·뜻·기본형을 수정한다. 저장된 가나 색인과 사전에서 한자 후보를 찾고 사용자가 선택한다.
- 검토한 항목만 기존 어휘 저장 API로 보낸다. 뜻 충돌은 명시적으로 확인하며 성공·기존 연결·실패 결과를 나눠 표시하고 실패분을 재시도한다.
- 단어 출처에서 해당 개인 노트·페이지·요소로 돌아간다. 모바일의 원래 필기 동작은 정리 패널을 닫고 캔버스를 보여준다.

## 저장·권한

새 테이블, 운영 DB 변경, 환경 변수 변경은 없다.

- 기존 `reading_materials`의 소유자 전용 `visibility=private`, `direction=write` 행을 사용한다. `processed_json.metadata.studyNote`에 캔버스와 정리 목록을 보관한다. 생성 재시도는 기존 importAttempt 고유 색인을 재사용한다.
- API는 로그인과 소유자·비공개 상태를 명시적으로 검사한다. 캔버스 형식, 노트 용량, 후보 개수·언어·식별자를 검사한다. 일반 자료를 노트로 덮어쓰지 않는다.
- 서버 수정은 이전 revision을 조건으로 비교 후 갱신한다. 요청 응답이 사라지면 서버 내용을 다시 읽어 JSONB 키 순서와 무관하게 같은 내용인지 확인한다.
- 기기 초안은 기존 IndexedDB의 계정+노트 식별자 및 원자적 revision 비교를 재사용한다. 충돌 시 다른 기기 내용을 덮어쓰지 않고 내 초안을 JSON 백업하거나 새 개인 노트로 보관한다.
- 기존 어휘의 뜻·복습 일정·학습 등급은 수정하지 않는다. 서버는 클라이언트 단어 본문 대신 자기 노트의 검토 완료 후보를 다시 읽어 출처와 저장 내용을 결정한다.
- 기존 고급 보관 도구에서 개인 학습 노트의 공개 전환 버튼을 제외했다.
- 원래 교재는 기존 접근 검사를 통과한 읽기 자료만 연결한다. 학생·팀 자료 권한을 새로 부여하지 않는다.

## 선택한 손글씨 인식

2026-09-15 오너가 공개 push/draft PR/미리보기와 선택한 필기의 Google Gemini 전송을 명시적으로 승인했다. PR #1313에서 함께 검토한다. 이전 자동 승인 검토의 두 거절 사유는 이 승인으로 해소되었다.

- 선택 도구로 필기를 감싼 뒤 선택한 요소 메뉴 → 선택한 필기 인식 → 이미지 확인 → 이 부분 인식하기. 미리보기만 열거나 닫으면 전송하지 않는다.
- Excalidraw `exportToBlob`을 재사용하여 선택한 요소만 PNG로 만든다. 링크/표현 메타데이터·외부 파일·embedded scene을 제외한다. 선택 밖의 글자·다른 페이지·연결 교재는 보내지 않는다. 원본 획과 좌표를 수정하지 않는다.
- API는 로그인/개인 노트 소유권/비공개 상태/서버 revision/선택 요소 SHA-256을 검사한다. PNG 1.5MB·1600px·500개 선택 요소·20개 결과 상한과 인스턴스 단위 사용자당 분당 6회 제한을 적용한다.
- 기존 서버 LLM 계층과 Gemini 설정을 재사용한다. `groq:false`로 다른 공급자 자동 전환을 막는다. 프롬프트는 필기를 데이터로 취급하며, 이미지 외에 노트 제목·원문·교재는 입력하지 않는다. 이미지 자체는 노트 DB나 로그에 남기지 않는다.
- 인식 원문(가나 포함), 읽기, 한자/뜻 후보를 분리한다. 뜻은 사용자가 후보를 고르거나 입력하기 전까지 비워 두고, 검토 완료 상태도 자동 설정하지 않는다.
- 같은 선택 영역 재인식은 기존 후보의 고친 표기·뜻·제외·저장 결과를 유지한다. API 호출 중 다른 기기 revision 변경, 늦게 도착한 취소 응답은 적용하지 않는다. 실패와 빈 응답은 재시도/직접 입력 경로를 제공한다.
- 수업 설명판은 기존 동작을 유지한다. 이번 인식 진입점은 교사/학생 모두 자기 계정으로 만드는 **개인 학습 노트**다.

참고한 기존 API: [Excalidraw 선택 요소 PNG export](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/utils/export), [Gemini 이미지 입력](https://ai.google.dev/gemini-api/docs/image-understanding). 새로운 편집기나 OCR 의존성은 추가하지 않았다.

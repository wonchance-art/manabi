## 브라우저와 저장

`e2e/teaching-word-canvas.e2e.mjs`는 실제 React 화면에 합성 교사·교재를 연결하고, 수업 기록은 폐기 가능한 PGlite 데이터베이스의 기존 SQL RPC로 저장한다. 실제 개인 자료·운영 수업·FSRS를 변경하지 않는다. 사전/AI 응답은 성공·복수 뜻·지연·실패를 재현하도록 고정한다.

검수 동선:

1. 교재 뜻 창: 독음 위 / 글자별 훈음 아래 / 뜻 오른쪽, 교재 출처를 유지한 판 배치.
2. 네 표현과 필기가 같은 판에 공존. 판에 놓기만으로 학생 기록을 만들지 않음.
3. 다중 선택에서 카드/글자만·표시 변경, 가로 정렬·여백 줄이기. 단어별 뜻·출처와 필기를 보존.
4. 새로고침 후 장면 복원. 보여주기의 임시 가리기가 저장 원본에 영향을 주지 않음.
5. 다음 과로 이동한 뒤 이전 과에서 가져온 단어를 원래 자료 권한으로 확인하고 수업에 저장.
6. 여러 뜻 중 선택, 계속 추가, 입력 수정 후 늦게 도착한 조회 무시, 조회 실패 후 수동 입력.
7. 선택한 표현의 명시적 일괄 저장. 같은 표기의 다른 뜻 두 개 모두 저장하고 화면 안 오늘 표현 목록에서 확인.
8. 1440×1000, 1024×768, 768×1024, 390×844. 가로 넘침과 하단 주요 버튼 가시성 검사, 직접 이미지 검수.

Chromium과 Safari 계열 WebKit + 터치: 각각 12개 흐름 통과, 브라우저 오류 0. 마지막 CSS 보완은 입력 메뉴 중 선택 버튼이 하단 동작과 겹치지 않도록 숨기는 변경이며 최종 배포에서 추가 확인한다.

검수 중 보완한 문제:

- 다중 표시 설정에 첫 단어의 전체 객체가 전달되어 다른 단어의 의미 메타데이터까지 덮어쓰던 문제를 표시 필드만 갱신하도록 수정했다.
- 글자별 훈음의 괄호 표기가 어색하게 나뉘던 줄바꿈을 개선했다.
- 모바일 알림이 하단 동작을 가리던 문제를 메뉴 안 알림과 고정 하단 동작으로 수정했다.
- WebKit의 원격 SVG 좌표 측정은 루트 경계를 반환할 수 있어, 실제 글리프의 DOM client rect와 캡처를 함께 검증한다.

## 추가로 발견하고 수정한 문제

1. **Safari 터치 후 초점 복귀:** 버튼을 탭해도 `document.activeElement`가 그 버튼이 되지 않아 발표 화면을 닫으면 초점이 사라졌다. 실제 열기 버튼을 전달해 Escape와 복귀 버튼 모두 같은 위치로 돌아간다.
2. **필기 도중 화면 이동:** 선택 도구 줄이 사라지면서 종이 높이가 바뀌고 자동 맞춤이 실행되어 수평 선이 꺾였다. 캔버스 포인터가 내려가 있는 동안 자동 맞춤을 멈춘다. 포인터 해제·취소·창 초점 이탈을 처리하며 이후 화면 크기 변경과 전체 보기는 유지한다.
3. **좁은 화면의 원문 가림:** 도구와 뜻 창 사이 공간이 부족하면 위치 보정이 생략됐다. 일반 크기의 수업 뜻 창은 선택한 단어 한 줄을 남기도록 높이를 제한하고, 위아래 여백도 공간에 맞춘다. Enter/Space로 선택한 경우에도 원문 위치를 맞춘다. 사용자가 확대한 패널과 실제로 단어가 들어가지 않는 공간에서는 불필요하게 스크롤하지 않는다.

원문·분석·뜻·판본·복습 일정·공유 권한·DB 스키마·환경 변수는 변경하지 않는다.

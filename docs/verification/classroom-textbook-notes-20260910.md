# 교재 안 설명·주의점·학생 수업 돌아보기

승인한 설계를 #1300 (`12817f1436fdaf6d8b142edc5eda4a35df5f4c1d`) 위의 독립 브랜치에 적용한다. 기존 수업·교재 데이터, 개인 교정, FSRS, 월드 파일은 변경하지 않는다. 원본 iCloud 작업 공간의 변경도 그대로 둔다.

## 적용

- 기존 뷰어를 유지한 채 큰 설명 화면을 연다. 단어·독음·핵심 뜻, 뜻 가리기, 돌아가기를 제공한다. Fullscreen API에 의존하지 않으며 키보드 초점과 스크롤을 복원한다.
- 직접 찾은 표현은 보여주기와 기록을 구분한다. `보여주고 기록`만 날짜별 수업 노트에 추가한다. 기존 개인 단어 저장은 유지한다.
- 교재 주의점은 `textbook_annotations`에 별도로 저장한다. 원본 교재 ID와 정확한 인용·앞뒤 문맥·문자 위치로 연결한다. 단어 토큰 ID가 재생성돼도 문맥으로 해석하고, 모호하면 연결을 보류한다.
- 설명 누적, 수정 이력, 보관·복원, 원문 변경 후 명시적 위치 재연결을 지원한다. 주의점 저장·읽기·표시로 날짜별 수업 노트가 생성되거나 바뀌지 않는다.
- 같은 읽기 방문에서 자동 알림을 반복하지 않는다. 자동 알림은 기존 패널에서 열고 초점을 옮기지 않는다. 다음 방문에는 다시 나타난다.
- 주의점 저장 요청은 각각 고유 ID로 IndexedDB에 보관한다. 응답 유실·재시도는 같은 UUID로 확인하고, 동시 수정은 기존 설명을 덮지 않고 충돌로 알린다.
- 소유자만 공통 주의점을 수정한다. 읽기는 기존 자료 RLS를 확인하고, 비공개 수업 원본은 현재 수업 접근 토큰을 재검증한다. 학생 사본은 검증된 `class_material_copies` 매핑을 사용하며, 임의 `source_ref`를 원본 권한으로 신뢰하지 않는다.
- 비로그인 기기 사본은 받는 시점의 주의점을 함께 저장하고 로컬 뷰어에서는 네트워크 없이 읽는다. 온라인에서 수업 페이지를 거쳐 다시 열면 최신 설명을 받는다.
- 학생 팀 화면은 교재를 먼저 연다. 개인 이어 읽기와 선생님의 날짜별 수업 범위는 별개다. 날짜별 범위는 교재 ID를 누적하고 취소할 수 있다.
- `수업 돌아보기`는 표현·뜻·독음·날짜 검색과 교재 밖 표현 필터, 원문 링크를 제공한다. 기존 가벼운 팀 index에 원문을 싣지 않고, 인증된 별도 history API에서 20개 노트 단위로 제공한다. 과거 출처 미상 기록을 교재 밖 표현으로 추정하지 않는다.

## 검증

- PostgreSQL(PGlite): 18개 검사 통과. 권한, 동일 요청 재시도, 동시 수정 충돌, 추가 설명 보존, 날짜별 범위, 원문·수업 노트 불변 확인.
- 실제 React 브라우저: 11개 시나리오 통과. 1024×768, 768×1024, 390×844에서 확대·복귀 각 10회; 저장 응답 유실과 재시도, 다음 방문 자동 표시, 같은 방문 접기 유지, 보여주기/기록 분리.
- 단위/API: 앵커 위치, 권한 경계, 수업 기록 분류·검색 검사 추가. 전체 378파일·4,112개 테스트 통과. 학생 수업 기록 화면 7시나리오, 기존 학생 사본·개인 교정·FSRS 보존 10시나리오도 통과했다.
- 로컬 Next.js 운영 빌드 통과(Node 24, 힙 4096MiB). 기본 2GiB 힙은 기존 전체 번들 컴파일 중 메모리 부족으로 중단되어 명령의 힙 설정만 조정했다.
- 실행 커밋 `021c48d0771b5fbc5ca9680ff1e9335ff31e9010`의 [CI 34452183676](https://github.com/wonchance-art/manabi/actions/runs/34452183676) 성공. lint 오류 0(기존 교재 코드 경고 2), 로컬 learning-flow 9/9 통과, 이 검사에서 JS 힙 최대 27,179,382바이트.
- 최초 원격 CI에서 학습 테스트의 교재 주의점 API 응답이 누락된 것을 확인해 합성 응답을 추가했다. 실제 API 오류를 숨기거나 테스트를 건너뛰지 않고 최종 CI가 통과했다.
- Vercel 실행 번들에서도 교사 11개·학생 7개 시나리오 통과. `QA_LOGIN=1`로 합성 계정의 로그인 화면을 거치며 실제 계정·운영 행에 쓰지 않는다. 로컬 전용 `sb-e2e-auth-token` 쿠키만 넣는 실행은 배포 도메인에서 인증되지 않아 중단됐고, 배포용 로그인으로 재검증했다.
- 배포된 실제 React 화면을 직접 검토했다. 교사 1024×768·768×1024·390×844에서 단어 확대/뜻 가리기/원래 위치 복귀, 학생 1440·768·390px에서 기록 검색/원문 이동/기록 탭 복귀를 확인했다. 합성 데이터 화면과 실제 계정 검수를 구분한다.

실제 Supabase 마이그레이션 워크플로 `34451419713` 성공. 원격 롤백 검사 10개 통과, 원본 교재·개인 단어 지문 불변, 임시 자료·주의점·수업 범위 잔존 0 확인. 적용 버전 `20260910070535`.

## 미리보기 환경 검수

- 최초 미리보기 `manabi-ksgj3grty-wonchance-arts-projects.vercel.app`의 `/api/version`이 실행 커밋과 일치했다. 비로그인 교재 주의점 조회는 403으로 차단됐다.
- 수업 기록 API에서 503 `not_configured`를 확인했다. 기존 수업 입장·기록 API가 공유하는 `SHARE_LINK_SECRET`이 Preview 환경에 빠져 있었다.
- 오너의 별도 승인 후 암호학적 난수를 메모리에서 생성해 Vercel Preview에만 민감 환경 변수로 추가했다. 비밀 값은 명령 인수·파일·로그·Git에 남기지 않았다. 운영 환경과 기존 미리보기 alias는 변경하지 않는다.
- 최종 [미리보기](https://manabi-6v9dwp8dg-wonchance-arts-projects.vercel.app/class): `dpl_EepffgD4ckoGrW2AqXSCj6Lr6Qcw` READY. `/api/version`의 실행 커밋·배포 ID 일치, `/class` HTTP 200. 비로그인 팀 index·history·material API는 503 대신 정상적인 401 권한 거부, 비공개 교재 주의점 API는 403을 확인했다.
- 실제 선생님 계정은 새 도메인에서 로그인 대기 중이다. 실제 교재에서의 확대·복귀·주의점 편집 화면 확인을 합성 데이터 검사로 대체했다고 보고하지 않는다. 실자료에 검수용 주의점이나 수업 표현을 쓰지 않았다.

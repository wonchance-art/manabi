## 오판을 피하기 위해 다시 확인한 곳

- 기본 `patterns`만 보고 선행 설명이 없다고 판단하지 않았다. 17–18과의 활용표, 19과 도구 설명, 20과 이동 설명, 23과 연결 연습을 실제 순서에 포함했다.
- 모든 새 단어에 별도 용어상자가 있어야 한다고 가정하지 않았다. 앞에서 뜻이 함께 제시된 예문으로 의미를 확인할 수 있는 `あさ/ごはん`, 22과 설명문에서 직접 풀이한 `だいじょうぶです`는 중복 추가하지 않았다.
- 정답의 단일성은 해당 문맥 안에서 판단했다. 15과 가격과 취향, 19–20과 장소/목적지/수단, 21과 를/가에 해당하는 を/が 대안, 22과 권유/부정의 차이를 확인했다. 자유 작문의 예시는 유일한 답이라고 바꾸지 않는다.
- 13과 읽기 확인, 20과 電車 읽기, 23과 한자 읽기 과제의 실제 HTML에서 정답 독음을 미리 보여 주는 ruby가 없는지 확인했다. 의미 이해 과제에는 기존 읽기 도움을 유지한다. 이 확인은 렌더링 파일 대조이며 이번 차수의 새 실기기 화면 검수가 아니다.
- 페이지 모델의 인쇄용 `*-read-answers` 항목이 웹의 독립 article로 없는 것을 결함으로 세지 않았다. 관련 웹 학습 페이지의 접힌 해설에 정답이 이미 포함되어 있다. PDF 조판은 이번 범위가 아니다.

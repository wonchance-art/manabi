## 적용

- 독립 팀 홈에 팀 제목, 한 개의 수업 시작/이어하기, 교재·수업 기록을 배치했다. 팀 선택으로 돌아가는 버튼을 없애고 웹앱 이동은 홈으로 통일했다.
- 선생님은 해당 팀 안에서 이름·언어·교재·입장 암호를 설정한다. 현재 읽기 위치처럼 다른 필드가 바뀌면 보존하고, 같은 설정에 대한 동시 수정은 덮어쓰지 않고 재확인을 요청한다.
- 수업 시작과 기존 /live 주소는 실제 선택한 교재/첫 과를 바로 연다. 연결된 교재가 없으면 같은 도구로 표현을 입력한다.
- 교재 상단의 표현 찾기·오늘 표현·마무리에서 같은 도구 패널의 내용을 전환한다. 단어 옆에서 수업용 뜻을 수정하고 크게 보기 또는 오늘 표현에 추가한다. 확대 자체는 기록하지 않는다.
- 교재 설명 추가·수정·누적·보관/복원, 날짜별 표현, 개인 단어/FSRS는 별개로 보존한다. 수업용 뜻이 원본 사전을 자동으로 덮지 않는다.
- 실제 팀과 자료 소유권으로 교사 도구를 허용한다. 교재 설명 API에서도 팀 소유권·교재 소속을 확인한다. 학생 사본이 공통 교재 편집 권한을 갖지 않는다.
- 이전 입력판의 기기 초안을 복원할 수 있다. 저장 중 다른 탭이 수정한 초안은 삭제하지 않는다. 과거 수업을 여는 것으로 오늘 이어보기 위치를 갱신하지 않는다.

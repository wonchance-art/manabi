# 추천 자료 바로 읽기 — 2026-09-12

## 요청과 결과

추천을 누를 때 새 자료 입력 폼을 채우던 동작을 없앴다. 수집된 제목·본문·출처를 갖춘 읽기 화면을 먼저 연다. 홈과 서재의 추천, 이전 `/materials/add?suggestion=...` 주소를 함께 처리한다. 이미 공개 분석 자료가 연결된 추천은 기존 뷰어 주소를 유지한다.

- 추천 읽기: `/suggestions/[id]`. 오늘 목록과 별도로 ID를 조회하므로 지난 날짜의 주소도 읽는다.
- 본문: 원문 단락, NHK 브리핑의 기사별 제목, 출처·자료 수집일, 글자 크기 조절. 소스 HTML을 실행하지 않는다.
- 서재 보관: 별도 명시적 버튼. 기존 private composer 저장·고유 인덱스를 재사용한다. 같은 판본의 재추천/재시도/응답 유실은 같은 개인 자료를 찾고 기존 편집 내용을 덮어쓰지 않는다.
- 학습: 보관 후 기존 `/viewer/[id]?study=1`로 연결한다. 원문 읽기에는 분석이 필요 없으며, 단어 도구는 기존 뷰어에서 분석 후 이용한다.
- 미반입 영상: 본문을 복제하거나 작성창을 여는 대신 원본 시청 링크. 홈의 읽을거리에서는 제외한다. 기존 개인 링크 반입 도구는 그대로다.
- 권한: 공용 추천의 material_id는 명시적으로 public이며 분석이 준비된 경우에만 노출한다. 예전 반입 화면이 개인 자료 ID를 공용 추천에 쓰던 코드를 제거했다.

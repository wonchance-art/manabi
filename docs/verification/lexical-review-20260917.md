## 실제 앱 평가 때 구분할 것

`/api/classroom/lookup`은 공통 사전에 있으면 저장된 뜻 목록을 반환하고, 없을 때 AI를 호출한다.
따라서 요청 횟수가 곧 AI 실행 건수는 아니다. UI는 여러 뜻 중 사용자가 고르는 방식이며,
후보가 보였다는 사실을 문맥 없는 자동 확정으로 간주해서도 안 된다.
현재 설명판 직접 검색은 언어·입력을 보내며 문맥을 보내지 않는다. 32개 문맥 평가를
설명판 검색창에 단어만 입력해서 수행했다고 보고하면 안 된다.
중국어→일본어 대응은 기존 `lookupJapaneseReference`의 선택 뜻·품사 경로로 따로 평가한다.

1. 최초 표본은 조회 8건 이내: 중국어 便宜/东道主/手纸/汽车, 일본어 生物/上手/大家/はし.
2. 정상 로그인된 Preview UI에서만 조회하며, 저장 사전/AI 표시와 원응답을 구별한다.
   자동 재시도 0, 개인 교재·노트 전송 0, 단어 저장·채점 0.
3. UI가 제공하는 의미 선택 및 일본어 확인 동작만 사용한다. 토큰 추출·인증 우회·사전 캐시 삭제 없음.
4. 문맥 및 모델/프롬프트 버전이 확보되지 않으면 해당 부분을 미검증으로 둔다.
   독립 감수 전에는 정확도 백분율을 산출하지 않는다.

## 현재 증거

- 40사례 입력 묶음 내 기대 정답 노출 0; 기준 변경 시 응답 반입 거부.
- 신규/기존 어휘 계약 단위 테스트: 2파일, 42개 PASS (합성 검사).
- 실제 공급자 응답: **0건**. 고정 Preview는 로그아웃 상태라 정상 로그인 안내를 열었다.
- `accuracy:null`, 대륙 HSK 독음 기준 미확정, 일본어 번역 후보 감수 대기.
- 실계정 검수와 독립 번역 감수는 구현/준비 완료와 별도로 남긴다.

## 결과

103개 카드의 대표 단어·읽기를 기준으로 38개에 본문 연결을 추가했다. 기존 관련 과는 별도로
표시하며, 나머지65개는 카드 학습과 관련 과 연결을 유지한다. 中/前의 다른 쓰임, 聞く의 활용,
時間의 수량 표현은 이동할 형태와 뜻을 명시했다. 같은 글자만 보고 다른 복합어/독음으로
연결하지 않는다. 한자·가나·한국어/문형 검색과 검색 결과에서 본문→같은 카드 복귀를 고쳤다.
상단 메뉴에 가려지지 않는 이동 위치와 키보드 초점을 확인했다.

## 검수에서 고친 점과 한계

- 단순 글자 감사는 ruby 뒤에 붙는 가나를 분리해 大きい 같은 단어를 놓친다. 링크는 ruby와
  이어지는 가나를 합쳐 읽되 日本의 本을 ほん으로 잘라 인식하지 않는다.
- 처음 화면에서 카드 상단이 고정 메뉴에 가려졌다. scroll margin과 메뉴 아래 도착 검사를
  추가한 최종 빌드를 두 브라우저에서 재검수했다. 가로 넘침 검사만으로 가림을 판정하지 않는다.
- 한자/문형을 검색한다고 표시하면서 어휘 카드만 검색하던 오류를 확인했다. 세 종류 카드,
  빈 결과/초기화, 본문 이동 후 정확한 출발 카드 복귀까지 확인했다.
- 과거 판본·개인 진도/SRS·표현 출처·발행 포인터·DB/env·운영 alias·PDF·새 음성은 변경하지 않았다.
- 실제 계정의 원격 Preview 독서, 물리 iPad, 독립 일본어 감수, 학습 효과, N5 시험 전범위 인증은
  이 합성 검수에 포함되지 않는다. 링크가 없는65개가 모두 본문에 없는 글자라는 뜻도 아니다.
- 기존39과 “다음 날 다시 꺼내기은”은 조사 결합 교정 후보로 별도 기록했다. 현재 과제는 연결 정리이며
  전권 교정 완료를 주장하지 않는다.

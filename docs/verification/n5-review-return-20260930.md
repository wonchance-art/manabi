## 구현 경계

- `/vocab?book=japanese-n5&returnTo=…`에 명시한 범위를 우선한다. 사용자 소유 출처를 모든 판본에서 페이지 단위로 조회하고 기존 단어 ID로 중복 제거한다. 별도 카드/FSRS/DB 스키마를 만들지 않는다.
- 범위의 숫자·목록·출제·완료 통계를 같은 단어 집합에서 유도한다. 전체 복습은 별도 명시적 링크로 이동한다. 언어/덱/급수의 기존 저장 설정은 덮지 않는다. 하루 새 표현 한도는 기존 전체 복습과 공유한다.
- 범위 조회 실패는 빈 범위나 전체 단어장으로 대신하지 않는다. 재시도 전 시작을 막는다. 계정·범위·복귀 위치 변경 시 진행 중 큐/답안/undo를 재사용하지 않는다.
- 원문 링크에만 `reference=1`을 붙인다. 저장된 출처 주소·판본·문단 식별자는 그대로다. 참고 탭에서 읽기 위치와 서버 최근 읽기는 갱신하지 않으며 ‘여기부터 이어읽기’를 명시적으로 선택하면 일반 읽기로 전환한다. 원문은 새 탭으로 열어 원래 복습 카드를 유지한다.
- 교재 답안·과 완료를 복습 일정과 구분해 안내한다. 이 범위의 복습 완료가 별도 이야기 학습의 진도를 완료 처리하지 않는다. N5 복습 화면에 다른 문법/이야기/작문 진입을 섞지 않는다. 전체 복습 화면의 문법 일정 안내는 실제 별도 과정과의 관계로 고친다.

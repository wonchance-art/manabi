# 운영 설명판 실계정 검수와 카드 가림 보정

2026-09-12 KST. 오너가 #1306 운영 병합과 통합 검수를 승인한 뒤 교사 계정으로 전환해 주어 실제 수업 교재를 검수했다.

## 확인과 발견

- 운영 d5909ce8에서 교사 계정 → 수업 팀 → 현재 교재 → 설명판으로 진입했다. 실제 교재의 표제·읽기·뜻을 함께 가져오고, 카드 위 필기 및 실행 취소/재실행을 확인했다.
- 새로고침 후 카드와 필기가 복원됐다. 교재 밖 표현의 사전 조회가 결과 없음으로 끝날 때 직접 읽기/뜻을 적어 표시할 수 있었다. 뜻 가리기/다시 보기, 다른 과 이동 후 동일 설명판 유지와 원래 과 복귀를 확인했다.
- 이 과정에서 학생 수업 기록에 표현을 게시하지 않았으며 화면의 오늘 표현 수는 0을 유지했다. 교재 원문·분석·개인 단어 상태는 편집하지 않았다. 일반 열람 위치와 교사의 현재 과 기록은 기존 동작대로 갱신될 수 있다.
- 브라우저 확대가 적용된 태블릿 가로 화면에서 모바일 선택 도구막대가 카드의 뜻을 가리는 문제가 있었다. 전체 캔버스 크기만으로 화면을 맞추면, 실제로 도구막대 뒤에 가려진 공간도 읽을 수 있는 영역으로 계산한다.

## 수정

- 위 도구막대·아래 도구막대·옆 도구의 실제 크기를 제외한 종이에 카드 전체가 보이도록 카메라 위치와 배율을 맞춘다. 표현 내용과 필기의 원래 좌표는 유지한다.
- 삽입, 내용 편집, 전체 보기와 화면 크기 변경에 적용한다. 이미 충분히 보이는 카드는 움직이지 않고, 자동 맞춤 때문에 사용자가 설정한 배율을 키우지 않는다.
- Excalidraw가 화면 크기 변경 후 데스크톱 도구막대를 모바일 도구막대로 교체하는 시점도 관찰한다. 등장 애니메이션 도중에도 막대의 최종 높이와 여백을 확보한다.
- 새 카메라 조정은 별도 실행 취소 항목을 만들지 않는다. 저장 형식·교사 권한·수업 저장 RPC·서버/환경 설정은 변경하지 않는다.

# 실계정 읽기·의미 검수와 일본어 출력 방어

2026-09-18 KST. 기존 통합 후보 #1321의 정상 로그인 검수를 이어갔다.
기존 Google 세션으로 제품의 로그인 버튼을 사용했다. 인증 토큰·쿠키·환경 파일을
읽거나 합성 계정을 주입하지 않았다. 계정은 일반 학습자 화면이며 교사 검수로 세지 않는다.

## 실제 확인한 흐름

- 고정 QA의 실행 `b94300dec33bf168675fcc5f89ef21f46db1bdf9`에서 시작.
- 새 비공개 검수 자료에 아래 자체 작성 4문장을 저장하고 중국어 선택 유지 확인.
  기존 개인 교재·노트는 분석에 보내지 않았다.
- 원문에서 4개 블록 선택 → 학습 구간 생성/분석 → 단어 패널 → 원문 복귀.
  원문에는 선택 구간 출처 안내와 강조가 표시됐고 본문은 유지됐다.
- 해당 검수 자료의 东道主만 수동 교정. ‘이 단어 전체에 적용’은 끈 상태로 저장했으며
  새로고침한 같은 학습 구간에서 교정이 유지됐다. 공유 사전 변경·단어 저장/채점은 하지 않았다.
- 수업 링크는 팀 암호 입력을 요구한다. 개인 자료 검수를 학생 원본 접근·직접 저장,
  교사 설명판 저장·권한 분리의 검수로 확대하지 않는다.

## 실제 첫 표시 결과

| 자체 문장 | 단어 | 카드 뜻 | 일본어 대응(기존 사전) | 판정 |
|---|---|---|---|---|
| 这本书很便宜。 | 便宜 | 싸다 / pián yi | 安い | 문맥에 맞는 표시 |
| 今天我请客，我来当东道主。 | 东道主 | 주최국 / dōng dào zhǔ | ホスト国 | **문맥에 비해 국가로 좁힌 뜻** |
| 洗手间里没有手纸了。 | 手纸 | 화장지 / shǒu zhǐ | トイレットペーパー | 手紙의 ‘편지’ 경고도 표시 |
| 这辆汽车停在路边。 | 汽车 | 자동차 / qì chē | 自動車 | 汽車의 ‘기차’ 경고도 표시 |

이는 화면으로 확인한 저장 사전/자료 결과이며, 4개 모델 응답을 평가한 것이 아니다.
독립 이중언어 감수나 모델 정확도 백분율을 산출하지 않는다.

东道主의 ‘이 문장에서는?’을 명시적으로 1회 눌렀을 때 접대하는 사람을 설명했다.
이를 카드의 ‘주최국’과 대조했다. [교육부 사전](https://dict.concised.moe.edu.tw/dictView.jsp?ID=9764&la=0&powerMode=0)도
손님을 접대하는 주인을 설명한다. 검수 자료만 ‘손님을 맞이하는 주인’으로 교정했다.

교정 직후 기존 ホスト国은 사라져 뜻별 캐시 분리를 확인했다. 그 상태에서 ‘일본어 대응 찾기’를
명시적으로 1회 누르자 **form에 한국어 ‘주최자’**와 용법 설명 문장이 반환되어 AI 표지와 함께 표시됐다.
이 조회와 문맥 설명을 실제 UI 실행으로 기록하되 공급자 모델명·원격 프롬프트 버전·내부 호출 수는
화면만으로 확인하지 못했다. 추가 자동 재시도나 사전 캐시 삭제는 하지 않았다.

## 이번에 고친 부분

- 일본어 대응의 저장 사전/AI 양쪽에 문자 검증 추가. 한글이 섞였거나 일본어 문자가 없는
  응답을 정상 대응어로 표시하지 않고 기존 실패·수동 재시도 상태로 보낸다.
- 한자만 있는 단어, 가나, `SNSを使う`처럼 로마자가 섞인 일본어는 유지.
  로마자만 있는 대응은 확정하지 않는다. 이는 형식 검증이며 번역의 정확성을 보증하지 않는다.
- 요청 캐시 v3로 이전 검증 전 응답과 분리. 사용자·단어·뜻·품사·자형별 범위와 요청 취소는 유지.
- 용법 설명을 ‘…라는 뜻’으로 단정하던 문구를 ‘일본어 참고’로 변경.
- 실측 한국어 오출력·사전 경유·수동 재시도 회귀 검사를 추가했다.

## 남은 문제와 다음 수정 경계

**문맥 뜻 선택은 아직 해결하지 않았다.** `pickZhMeaning`은 문맥 품사에 맞는 첫 사전 뜻을
고르므로 같은 품사의 다의어를 판별하지 못한다. 공통 사전에 한 뜻만 등록된 경우도 있다.
일본어 조회는 선택된 한국어 뜻을 따르므로 그 오류가 일본어로 이어질 수 있다.

다음 수정은 일반 사전 뜻과 확인한 문맥 뜻의 출처를 구분하고, 명시적으로 요청한 문맥 설명에서
뜻 후보를 검토·선택해 이 자료에만 적용하는 흐름을 우선한다. 설명문 전체를 자동으로 단어 뜻에 넣거나
공유 사전·개인 SRS를 자동 교체하지 않는다. 교사 확정 뜻/개인 교정과 오래된 비동기 응답을 보호해야 한다.
일본어 및 중국어 나머지 표본·독립 감수는 미완료다.

팀 암호 입장 후 학생 원본 → 직접 단어 저장 → 뜻 수정 전달 → 복습/출처 복귀,
교사 계정의 설명판, 물리 iPad/Pencil 검수는 별도로 남는다. 운영 merge·승격·DB·영구 환경 변경 없음.

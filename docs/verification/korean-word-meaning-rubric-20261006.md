# M00-KO-MEANING-030 — 의미 판정표 v1

확정일: 2026-10-06 KST. 모델/프롬프트 수정 및 새 의미 생성 실행 전 고정한 설계 기준이다. 아래 문장은 직접 작성한 QA 예시이며 개인 학습 원문이 아니다. 모든 사례는 아직 미실행이다.

위 문장은 기준 확정 당시 상태다. 실행 후 결과와 실패는 [구현·검수 기록](./korean-word-meaning-20261006.md)에 별도로 기록하며 이 판정 기준을 소급해 완화하지 않는다.

## 공통 판정 규칙

- 저장할 뜻은 해당 문장에서 선택된 기본형의 어휘 의미다. 조사·시제·문장 부정·어미 설명은 문맥 뜻/형태 설명으로 나눈다. 어휘 자체의 부정이나 높임 의미는 보존한다.
- 아래 뜻은 허용 표현의 예시다. 핵심 의미가 같은 자연스러운 표현을 수락하며 exact 문자열 일치를 강제하지 않는다. 한국어 설명에서는 기본형을 그대로 반복한 것만으로 뜻풀이를 마쳤다고 보지 않는다.
- 간체/대만 번체는 각각 자연스러운 글자·용어를 사용한다. 예: 墙/牆, 学校/學校, 读/讀, 给/給, 挂/掛. 공통 글자인 去·雪 등을 억지로 다르게 만들지 않는다.
- 문맥 뜻은 선택된 표현의 문장 속 의미다. 선택 범위 밖의 부정·아직 등이 그 표현에 영향을 주면 보존하되, 무관한 절의 부정을 가져오거나 주어·의도를 새로 만들지 않는다.
- 형태 설명은 실제 나타난 형태와 관련 있는 설명만 허용한다. 어절 경계와 형태소 경계를 혼동하지 않는다. 조사 앞 명사를 동사 어간이라고 부르지 않는다.
- 표의 금지 오류는 ko/zh-CN/zh-TW 모두에 적용한다. 오류 예시를 결과 문자열 금지 목록으로 하드코딩하지 않는다. 예를 들어 `못하다`를 검사하면서 모든 부정 표현을 제거하면 실패다.

## 수락과 기록

명확한16사례×3언어는 올바른 저장 후보48건이 필요하다. 모호하지 않은 문장에서 모두 uncertain을 내는 구현은 안전하더라도 유용성 실패다. 실패/모델 오류/재시도/미판정은 별도 기록하고 없던 결과로 처리하지 않는다. 기본형·어휘 의미·부정·높임 방향의 중대한 오류0건, 글자/locale/형태 설명의 해결되지 않은 오류0건을 요구한다.

결과 행은 `caseId, locale, sourceToken/lemma, promptVersion, model/tier, firstOutput, elapsedMs, lexical/context/morphology/locale 판정, 근거, verdict, 재시도 사유`를 담는다. 시험 세트 전체 통과를 모든 한국어 문장의 품질 보증으로 확대하지 않는다.

아직 새 모델 호출·저장·화면·실계정 검수를 수행하지 않았다. 이 문서는 판정 기준의 확정이며 PASS 보고가 아니다.

## 어휘 생성만 담당하는 후보의 추가 미사용 검수 N01–N06

통합 생성 후보 v4의 문맥·문법 실패를 확인한 뒤, 새 후보의 생성 책임을 `lemma / lemmaStatus / lexicalMeaning`으로 한정했다. 화면의 문맥·문법은 변경하지 않는 기존 `useViewerExplanation` 경로가 계속 담당한다. 이전 통합 생성의 실패는 취소하거나 통과로 바꾸지 않는다. 새 후보의 어휘 의미, 기존 읽기 도움의 보존, 저장/후속 사용을 각각 검수한다. 아래 기준은 새 후보에 대한 모델 호출 전에 작성했으며 D/H 사례와 겹치지 않는다. 기존 D/H는 이제 회귀 사례다.

모든 새 어휘 뜻에서 기본형 일치, 해당 문맥의 어휘 의미, 어휘적 부정/방향/높임, 설명 언어의 자연스러움을 판정한다. 어휘 출력으로 기존 문맥·문법 생성의 정확성을 주장하지 않는다. 신규 후보가 오류를 내면 그대로 실패로 기록한다.

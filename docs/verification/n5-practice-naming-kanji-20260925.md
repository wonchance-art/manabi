## 반례와 검수 수정

- 최초 보존 테스트는 권말 문항까지 세고 과내 309개와 비교해 실패했다. 과내 309/권말 포함321을
  구분하고 양쪽 판본의 전체 문항 객체는 그대로 비교했다. 콘텐츠를 검사 수에 맞춰 고치지 않았다.
- 최초 후리가나 금지 검사는 해설의 정답 독음까지 오류로 취급했다. 문항의 本/休만 도움 없이
  유지하는지 확인하고 접힌 해설의 독음은 보존했다. 첫 노출 감사에서도 해설은 분리한다.
- ruby가 없더라도 표 옆의 가나나 본문 안내가 읽기를 알려줄 수 있다. 자동 후보를 전부 오류로
  바꾸지 않았다. 별도 직접 화면 확인은 자동 레이아웃 검사의 의미 감수와 혼동하지 않는다.
- 색인과 본문은 각각103자지만 공통56자다. 같은 수를 범위 일치로 보고하지 않는다.

## 다음 방향과 남은 경계

우선 후보는 **한자 색인의 학습 연결 정합화**다. 대표 어휘 학습 과와 실제 한자 표기 도입 과를
구분하고, 색인에서 이동한 본문에 해당 표기/읽기 도움이 있는지 확인하는 것을 완료 기준으로 한다.
색인만 있는 글자를 무조건 추가하는 대신 시험 대비 필수 학습과 참고 글자를 근거로 분류해야 한다.

현재 요청의 명칭 변경·한자 첫 노출 감사·근거 있는 6곳 보완은 완료했다. 독립 일본어 의미 감수,
시험 전범위 검증, 실제 학습자/물리 기기, 운영 발행은 이번 합성 검수로 대체하지 않는다.
이전 발행본과 DB·학습 일정·개인 자료·PDF·새 음성·운영 alias는 변경하지 않았다.

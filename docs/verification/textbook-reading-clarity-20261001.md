# 교재 가독성과 참고 도구 정리 — 2026-10-01

## 실행 근거와 경계

오너의 ‘다음 작업 진행하고, 30분간 나의 답 없을 시 다음 작업 자동 진행’ 지시와 기존 `n5-learning-flow-audit-20260930.md`의 최소화 설계/2차 재검토를 따른 두 번째 로컬 구현 단위다. 실행 시작 시 마지막 실제 사용자 요청은 03:03 KST, 이전 실행은 종료된 상태였고 다른 실행과 중복하지 않았다. 자동 메시지는 사용자 응답으로 세지 않았다.

브랜치 `codex/textbook-reading-clarity-20261001`, base는 선행 draft PR #1329의 `23b1e8d403cf86d29734613fae4f196c17df4f43`다. 선행 명칭·복귀 후보를 재작성하거나 병합하지 않는다. 이 후보도 Preview·운영 병합/배포·DB/env·교재 발행·권한 변경의 승인을 받았다는 뜻이 아니다. #1325–1328의 운영 완료와 기존 판본/기록 보존 조건은 유지한다.

완료 경계는 읽기 화면의 가독성·참고 자료 위계를 개선한 로컬 후보와 관련 검수다. 전역 메뉴 재설계, Aa 설정 신설, 과 목차 범주화, Study/Play 과정·시험/보고서, 월드, 문법 접근 권한 P1, PDF/음성 및 원고 보강은 포함하지 않는다.

## 기대와 실제 변경

- 예문/지문 제목을 테두리 안쪽의 일반 헤더로 배치해 선이 끊기지 않게 한다. 필요한 읽기 지시와 radio/fieldset의 이름은 유지한다.
- 바로 인접한 stage와 h2가 완전히 같은 문구일 때만 stage를 화면에서 숨긴다. 발행 원고를 수정하지 않으며, h2는 남긴다.
- 회화의 해석 조작을 제목 옆으로 옮긴다. 넓은 화면의 말하기 두 칸은 같은 열 너비/입력선으로 정렬하고 좁은 화면은 한 열로 둔다. 고정 높이로 긴 질문이나 번역을 자르지 않는다.
- 지문은 하나의 배경 영역, 물음은 배경 밖의 질문과 선택지로 구분한다. 정답·해설은 처음에는 접히며, 펼쳤을 때 같은 안쪽 여백과 구획을 갖는다. 정답·이유를 삭제하거나 선택 전 강제 공개하지 않는다.
- 핵심 `담은 표현`은 직접 보인다. 보조 목적지는 `참고 자료` 한 단계 아래 `어휘·문형·한자 / 이 과의 연결 자료 / 문화 읽기`로 구분한다. 문화 읽기를 과별 개인 연결 목록으로 소개하지 않는다.
- 과별 연결 자료는 열람 링크가 먼저 보이고, 연결/해제는 `연결 관리` 안에 둔다. 나에게만 보임·공개 범위 보존·오류/재시도는 남긴다. 공용 MaterialChapterLinks의 기존 기본 동작은 유지하고 교재만 선택적 browseFirst 모드를 사용한다.
- 하단 목표 반복을 줄이고 `읽기 완료`라고 명명한다. 예문 전체는 `예문 담기`, 선택한 문장은 `표현 담기`로 구별한다. 읽기 체크를 시험 합격이나 언어 능력 성취로 해석하지 않는다.

색/서체는 기존 교재 팔레트와 읽기 스타일을 사용한다. 기존 컴포넌트·native details/dialog를 재사용하며 새 패키지/메뉴 체계를 도입하지 않았다. 출처·예문 뜻·표현 ID·FSRS·판본·브라우저 답안/말하기 초안·개인 자료 권한·연결 API payload는 보존한다.

## 실패와 교정

1. 최초 브라우저 검수에서 닫힌 dialog 안에 개인 연결 목록이 먼저 mount되어 조회되는 반례를 발견했다. 실제 자료 panel일 때만 mount하도록 고쳤고, 닫힌 상태 조회0/관리 전 쓰기0을 회귀 조건으로 남겼다.
2. 닫기 직후의 동기 초점 단언은 native dialog의 비동기 close 이벤트보다 먼저 실행되어 실패했다. 임의 지연 대신 실제 summary 초점 복귀를 기다려 검사했다. 제품에 재시도 루프를 추가하지 않았다.
3. 기존 위치 검사는 미발행 8a 조건을 전제로 한다. 공개 8a 합성 서버에서는 guest401 기대에 실제200이 나왔다. 공개/미발행 로컬 서버를 분리하고 접근 차단 단언을 보존했다. 운영 포인터는 바꾸지 않았다.
4. 기존 검사의 `← 책으로` 선택자는 선행 PR의 실제 `← 책 목차`와 달랐다. 검사 이름만 정합화했다.
5. WebKit은 접힌 details 안의 숨은 링크 텍스트 좌표를 0개로 반환했다. 이를 ‘한 줄이 아닌 오류’로 요구한 측정 결함을 확인했다. 보이는 도구와 summary를 검사하며, 숨은 링크를 화면 줄바꿈으로 판정하지 않는다.
6. 두 엔진 검수는 실제 Safari 계열의 문화 링크 클릭 취소도 드러냈다. 이벤트 순서가 pointerdown → summary의 focusout(relatedTarget MAIN, tabindex=-1)이며 click 전에 메뉴가 닫혔다. 밖을 누르는 동작은 문서 pointerdown으로, 메뉴 밖 키보드 이동은 초점 가능한 Tab 대상에 대한 blur로 구분했다. Escape·밖 누르기·Tab·문화 읽기 왕복을 최종 후보에서 재검수한다. 이 원인 있는 결함을 모델 역량 문제로 분류하지 않았다.

실패 로그를 최종 성공 로그로 덮어쓰지 않는다. `manabi-textbook-clarity-e2e-20261001.log`, `...e2e-final...`, `...position-20261001.log`, `...position-verified...`, `...position-final...`, `...position-complete...`는 각 중간 실패의 근거다.

## 결과 리뷰와 다음 방향

원고를 바꾸지 않고 읽기/답안 확인/표현 담기/참고 왕복을 이어갈 수 있는 후보를 준비했다. 설명과 범위·실패 상태를 남겨 기능을 숨기는 최소화는 피했다. 문구 개수나 테스트 수를 학습 품질·진척 점수로 쓰지 않는다.

다음 우선 후보는 승인된 마지막 단위인 **목록/홈의 같은 목적 중복 안내**다. 실제 이어읽기·교재 선택·자료 추가·표현 찾기라는 주 행동을 보존하고 행동/대상/상태를 추가하지 않는 반복만 묶어서 줄인다. 완료 조건은 신규/재방문/빈 상태/실패·작은 화면에서 핵심 행동과 돌아갈 길이 유지되는 것이다. 이 단위는 독립 로컬 준비가 가능하다.

Preview/실계정은 유효한 해당 후보 배포 승인과 로그인에 의존한다. 선행 #1329의 기존 승인 질문을 반복하거나 미응답을 승인으로 해석하지 않는다. 운영 병합/배포는 별도다. 권한 P1·과정/시험·월드·새 판본보다 이미 승인된 화면 반복 정리를 우선하되, 다음 자동 실행도 최신 실제 사용자 응답·다른 실행·현재 완료 기록을 먼저 확인한다.

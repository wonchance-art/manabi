# manabi 웹 v2 — 복습 화면 후속

오너의 승인된 v2 설계와 「다음 작업 개시」 요청에 따른 구현. 기반은 1차 PR #1281의 `a38c834d6cece9bf31071ed2671a01ab94ffed0c`. 별도 작업 공간과 `codex/web-v2-review-20260906` 브랜치를 사용한다. 기존 iCloud 체크아웃은 수정하지 않았다.

## 적용

- `/vocab`: 오늘 다시 볼 표현과 직접 시작 버튼을 주 행동으로 배치. 문법 복습은 별도 수와 경로로 표시. 통합 학습 `/study`, 저장 목록, 직접 추가·CSV·Anki·방식·덱·새 단어 한도 및 약점 연습을 보존한다.
- 표현 목록을 중간에, 설정을 접히는 하단 영역에 배치. 기존 다섯 메뉴·manabi 서체·종이색과 붉은 모브를 이어 사용한다. 모바일은 동일 DOM 순서의 한 열이다.
- 카드: 회상 안내, 뜻 공개, 원문 예문 박스, 기존 4등급 채점. 추가 문맥은 기존 권한 검증 API에서 가져오고 복습 중에는 문맥 삭제 도구를 숨긴다. 자료 원문은 검증된 식별자로 주소를 만들며, 교재 판본/위치는 기존 문맥 API의 주소를 유지한다.
- 원문 링크는 새 탭을 사용한다. 복습 탭의 카드·답안·큐가 남으며 링크 자체는 채점하지 않는다. 복습 입구로 나갔다 같은 화면에서 이어갈 수도 있다. **페이지 새로고침이나 다른 화면 이동 후 세션 복원은 이번에 추가하지 않았다.**
- 성공한 채점 후 어휘 쿼리를 갱신해 다시 입장할 때 지난 대기 수가 남지 않게 한다. 기존 `recordReviewCompleted`, FSRS 4등급, undo 및 오프라인 전송 큐를 재사용한다.
- 단어가 처음부터 없는 상태, 지금 기한이 된 단어가 없는 상태, 요청 실패를 구분한다. 문법 조회 실패도 0개 완료로 간주하지 않는다. 서버 문법 페이지의 조회 실패에는 재시도 경로를 제공한다.
- 계정 키가 바뀌면 어휘 복습 작업 공간을 다시 마운트해 답·큐·상세·undo를 폐기한다. 이전 계정의 늦은 세션 시작 응답을 무시한다. 브라우저 설정 저장 차단/손상 값은 기본값으로 복구한다.

## 범위와 판단

이 작업은 자료 읽기 → 표현 저장 → 복습 → 원문 복귀 순환의 복습 정거장 개선이다. 새 엔진·복습 일정·DB 테이블을 만들지 않는다. 이미 승인된 화면 설계를 반영하므로 새 UI 라이브러리를 도입하지 않았다. 기존 Next/React Query/VocabularyContexts/FSRS 부품을 재사용하는 것이 이식과 검증 부담이 가장 작다.

문법은 기존 챕터 단위 문항 구성과 자동 채점 동작을 유지하고 읽기 표면·돌아가기·원문 링크를 정리했다. 객관식 정답 자동 채점도 기존 동작을 보존한다. 원문 판본·교재 내용·사용자 자료 권한·표현 저장 의미를 변경하지 않는다. PDF 조판·음성 제작·월드 자산·DB/환경 설정·운영 도메인 승격은 제외한다.

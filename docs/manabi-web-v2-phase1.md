# manabi 웹 v2 · 1차 구현

사용자가 승인한 `manabi-structure-blueprint-v2.md`와 `manabi-reading-room-v2.html`을 실제 Next.js 화면에 적용한다. PDF 조판·음성 제작·교재 원고 개정은 포함하지 않는다.

## 작업 기준과 격리

- 원본 작업 폴더의 미완료 변경을 보존하고 `/private/tmp/manabi-web-v2-phase1-20260906` worktree에서 작업했고, 최종 검수는 원격 브랜치로 복구한 `/private/tmp/manabi-web-v2-resume-20260906`에서 마무리했다.
- 기준 커밋: `ae0e4251b8df66e8fa28229e32809ab49c217944` (PR #1280, 현재 발행 교재를 포함하는 배포 계열).
- 브랜치: `codex/web-v2-phase1-20260906`. PR #1280의 브랜치를 base로 하는 후속 변경이다. 병합·force-push 없음.
- 도시 생성의 SPEC·결정성·geo 파일 소유권 규칙은 도시 작업에 한정한다. 월드 구현·지형·DB 정책을 변경하지 않는다.

## 구현한 흐름

주 메뉴는 오늘(`/home`), 교재(`/lessons`, `/books/*`), 발견(`/discover`, `/studies/*`), 복습(`/vocab`), 내 서재(`/materials`)다. 기존 주소는 유지한다. 검색은 기존 자료 검색으로, 계정은 프로필로 연결한다. 관리자 입구의 기존 권한 조건을 유지한다.

오늘은 실제 발행 교재의 카탈로그와 로컬 읽던 위치를 사용한다. 자료의 미완료 읽기 기록이 더 최근이면 해당 뷰어로 이어진다. 기록을 읽는 동안 로딩 상태를 제공하고, 진입 후 백그라운드 새로고침 때문에 주 버튼의 목적지가 바뀌지 않게 한다. 서버 기록 실패가 로컬 교재 읽기를 막지 않으며, 추천의 실패도 별도로 처리한다.

책장은 네 언어 시리즈의 표지 비율·색상·타이포그래피를 통일한다. 일본어 N5는 실제 42과 교재로 연결하고, 미발행 언어는 준비 상태와 기존 공개 읽을거리를 안내한다. 모바일은 이어 읽기를 표지 목록보다 먼저 보여준다. 책 홈은 판본, 시작/재개, 현재 파트/전체 목차, 찾아보기, 문화 읽기 순서로 구성한다.

발견은 실제 일본 문화 문서, 일본·한국·프랑스 지역학 목록과 발행 교재의 문화 글을 연결한다. 지역학에 외국어 시험 급수를 붙이지 않는다. 복습과 서재는 기존 기능을 계속 사용한다. 프랑스어 자료 입력 선택을 추가하고, 추천 이미지 실패·부재에는 언어별 표지 대체 화면을 제공한다.

## 기록과 권한

- 교재 진도는 `manabi-book-progress:<edition>:<userId|guest>` 키를 그대로 쓴다. `page`와 `completed`는 보존하고 신규 활동에 `updatedAt`을 추가한다.
- 이전 기록의 없는 시각을 만들어내지 않는다. 계정 전환 중 이전 사용자의 로컬 진도를 노출하지 않는다. 저장소 오류와 손상된 JSON을 구분한다.
- 완료 수는 발행 교재의 과 ID와 대조한다. 예전 30과 문법 통과 기록, 서버 자료 읽기, FSRS 복습 일정을 합산하지 않는다.
- 서재의 자료는 현재 로그인 사용자의 `reading_progress`와 접근 가능한 자료 제목으로 조회한다. 완료·삭제·접근 불가 자료는 재개 후보에서 제외한다.
- 글 전체를 보관하는 동작과 선택한 표현을 담는 동작을 합치지 않는다. 기존 본문·판본·원문 출처·표현 저장 API·개인 자료 소유권·복습 스케줄은 그대로다.
- 기존 공부 세션에는 중단 지점을 복원하는 저장 계약이 없어 재개 기록을 만들어내지 않는다. 해당 기능은 후속 설계 대상이다.

- 보관함 목록·이전/다음·어휘·문형·목록 복귀는 관리자 주소로 연결하고 문서 전체를 연다. 기존 보관함의 RSC 부분 전환 멈춤을 이 경계에서 제거했으며, 공통 문법 로더·본문 렌더러를 직접 재사용한다. 새 책의 탐색은 기존 App Router 방식이다. 저장되는 표현의 기존 출처 주소는 유지한다.
- 관리자 문서와 RSC 요청은 서비스 워커의 캐시 조회·저장을 건너뛰어 매번 서버 권한 확인을 거친다. 일반 페이지의 오프라인 정책은 유지한다. 해당 캐시·권한 회귀 검사 13개 통과.
- 보관함의 없는 주소는 권한 확인 후 정본 목차와 대조해 스트리밍 시작 전에 실제 HTTP 404로 응답한다. 네 언어 정상 주소는 보존하고 원고 본문 로더를 Edge에 싣지 않는다.
- 기존 CI 조판 25개·뷰어 크롬 4개·smoke 14개 통과. smoke의 기존 중단 기능 6개 skip은 유지했으며 새 skip은 추가하지 않았다. 동일 최종 코드에서 learning-flow 9개 전체 통과(실행 #34032561191, job #101484702784). 실측 브라우저 JS heap 피크는 22,201,069 bytes(약 21.2MiB, 작문 복원·이어 하기 카드)다. 도시 미니맵 예산은 이번 UI 검사에 적용하지 않는다.
- 초기 로컬 전체 검사는 지역학 데이터 준비의 60초 제한으로 실패했으며, 해당 4개 검사는 단독 재실행에서 통과했다. 이후 GitHub CI 전체 3,733개 실행이 통과했으므로 초기 실패를 전량 성공으로 바꾸어 기록하지 않는다.
- Vercel 8GB 컨테이너에서 SIGKILL/OOM을 실측했다. Next.js 공식 메모리 절감 설정 `experimental.webpackMemoryOptimizations` 적용 후 일반 폰트 경로로 미리보기 빌드가 완료됐다. Node 런타임·Vercel 환경 값은 바꾸지 않았다. [공식 근거](https://nextjs.org/docs/app/guides/memory-usage)
- 기존 ESLint 경고와 Node 20 배포 런타임의 2026-10-01 이후 신규 빌드 중단 경고는 별도 후속이다. 이번 변경에서 engines 정책을 바꾸지 않았다.

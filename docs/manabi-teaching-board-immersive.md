# 설명판 전체 화면·아이콘 메뉴

2026-09-14 · `codex/teaching-board-immersive-20260914`

## 목표와 화면 구성

설명판을 열면 캔버스가 화면 전체를 사용한다. 웹앱 공통 헤더, 상시 입력줄, 하단 보관·페이지 줄이 차지하던 공간을 판으로 돌려준다. 기본으로 작은 아이콘 막대만 판 안에 떠 있고, 누른 기능의 메뉴 하나가 열린다. 메뉴를 열어도 캔버스 크기와 필기 좌표가 변하지 않는다.

| 아이콘 | 클릭했을 때 | 보존하는 기능 |
| --- | --- | --- |
| 메뉴 | 수업·보관 | 웹앱 홈, 팀 홈, 오늘 기록, 화면 맞춤, 백업·가져오기·충돌본, 설명판 닫기 |
| 현재 필기 도구 | 필기 메뉴 | 선택·펜·지우개·글자·화살표·레이저, 색·굵기·도형·이동, 실행 취소·다시 실행 |
| ＋ | 표현 입력 | 즉시 놓기, 교재/내 단어/최근 판 검색, 사전, 독음·뜻, 일본어 가나 후보 |
| 책 | 교재와 화면 | 설명판 전체/교재와 함께/교재 전체, 해당 수업 교재 과 선택 |
| 페이지 | 판 목록 | 현재 판 표시, 기존 판 이동, 새 판 |
| 발표 화면 | 학생에게 보여주기 | 선택/전체 확대, 임시 독음·뜻 가리기, 레이저, 설명판 복귀 |

선택한 요소가 있을 때만 오른쪽 아래에 편집 아이콘이 나타난다. 해당 메뉴에서 내용·독음·뜻, 그룹, 명시적 오늘 표현 추가를 처리한다. 학생 수업 기록은 판에서 표시했다는 이유만으로 자동 생성하지 않는다.

## 동작과 접근성

- 화면·입력 크기를 줄이는 고정 상하단 줄을 제거하고 44px 이상의 아이콘 누름 영역을 둔다.
- 아이콘에 접근성 이름과 도구 설명을 제공하고 현재 메뉴/도구의 선택 상태를 표시한다.
- 같은 아이콘으로 닫기, 바깥 클릭으로 닫기, Escape로 닫기. 키보드 종료 시 연 아이콘으로 초점을 돌린다. 아이콘 막대는 방향키와 Home/End도 지원한다.
- 입력 메뉴를 접거나 다른 메뉴로 이동해도 작성 중인 표현을 유지한다. 기존 표현 수정과 새 표현 초안은 구분한다.
- 새 작업 공간은 설명판 전체 화면에서 시작한다. 이미 저장된 분할/교재 보기·분할 비율·입력 초안은 그대로 복원한다.
- 수업 기록과 저장 실패 재시도도 판 안에서 연다. 기록 수정/분석 실패/범위 확인 기능은 기존 수업 로직을 재사용한다.
- 스마트폰에서는 교재와 함께 보기를 위아래로 배치한다. 입력 시 줄어드는 화면 높이와 안전 여백을 적용한다.
- 보여주기 화면도 전체 판 위에 작은 아이콘을 띄운다. 발표용 임시 가리기·레이저는 원래 판을 바꾸지 않는다.

## 구현 경계

- Excalidraw 0.18.1 고정 버전 유지. 캔버스·필기·선택·그룹·텍스트·history는 기존 엔진을 사용한다.
- `BoardHistory`는 엔진이 실제로 렌더한 undo/redo 버튼의 동작과 disabled 상태를 전달한다. 엔진에 공개 undo/redo 메서드가 없어 고정 버전의 `button-undo`/`button-redo` 선택자를 좁게 사용한다. 브라우저 회귀 검사에서 실제 잉크의 취소·복구를 검증해야 한다. 패키지 업그레이드 시 확인할 경계다.
- 원문, 저장 형식, 개인 권한, 서버 수업 기록, FSRS, PDF, 음성, 운영 DB/환경은 변경하지 않는다. 서버 동기화·필기 인식은 추가하지 않는다.
- 기존 로컬 후속 `8c37142a53e0fbbee85b1a5e1e6091452cb76266`의 단어 확대 창 초점 복귀 보완도 포함한다.
- 원본 iCloud 작업 공간과 다른 PR의 변경은 보존한다. 별도 clone에서 진행한다.

## 검증 상태

- 단위 검사: 389파일 / 4,195개 통과. 신규 작업 공간 기본값과 기존 설정/초안 보존을 포함한다.
- 변경 JSX를 명시적으로 포함한 ESLint 통과. 기존 설정의 JSX 자동 제외 경고를 통과로 계산하지 않았다.
- 설명판/수업 연결의 로컬 JavaScript 모듈 36개 번들 검사, CSS 2개 구문 검사 통과.
- 브라우저 검사: 실제 React 화면 + 합성 계정/API + 임시 PostgreSQL을 사용하는 기존 검사에 새 메뉴 동선을 연결했다. 운영 개인 자료에는 쓰지 않는다. 실행 결과는 아래 후속 기록에 갱신한다.
- 최종 Next 빌드, Chromium/WebKit 실제 화면, 배포 버전과 운영 확인은 아직 완료로 선언하지 않는다.

## 진행 기록

초기에는 자동 승인 검토 서버의 모델 용량 오류로 외부 조회와 브라우저 검수가 차단됐다. 로컬 구현·검사를 먼저 진행했다. 접근 복구 후 최신 main `e29d41a7a7650e20e8984c2086d2b8b49f52b379`와 열린 PR을 다시 확인하고 이슈 #150에 범위를 기록했다. 샌드박스 내부 빌드는 컴파일 중 진전 없이 대기해 중단했으며, 복구된 로컬 서버에서 실제 화면 검수를 진행한다.

물리 iPad/Apple Pencil의 압력·팜 리젝션·회전과 실제 소프트웨어 입력기 검수는 브라우저 크기·터치 모사와 구별한다.

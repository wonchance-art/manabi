**갭 큐 4 (전부 기존 챕터 보강 — 신규 챕터 0)**
1. 着 지속 → h2-03(在 진행)에 "진행 vs 지속" 섹션 — 대비 학습 최적 위치
2. 别 금지 → h1-06(부정 不/没)에 섹션
3. 就/才 대비 → h2-12(시간 표현)에 섹션
4. 再/又 구별 → h3-13(빈도 부사)에 섹션

**검수 3**: 呢(h1-05) · 因为…所以(h3-08) · 地 조기 노출(h3권) — Z2에서 실물 판정.

## 2. zh 특수 설계 (fr 템플릿의 현지화)

- **딕테이션**: 병음 입력(성조 관대) 채점 기본 + 한자 입력 accepts 병기 — IME 부담을 낮추되 한자 학습자도 수용
- **성조 듣기**: zh 고유 드릴 — 같은 음절 성조 4종 구분(listen + choice), fr의 해독 훈련에 대응하는 "귀 훈련" 축
- **listen 문항**: 장면 대사 TTS(zh-CN) 재사용 — fr 방식 그대로
- **비중복 (f)·레벨 간 (g) 게이트**: zh 디렉터리로 일반화(Z3 착수 시 동반)
- **어휘 (d)**: 한자·병음 토크나이저 별도 필요 — Z4 이후 과제로 명시

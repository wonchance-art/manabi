## 2. 화면의 세 가지 진입점

```text
← 내 서재             HSK 6 · 과 이동
자료 제목             [듣기] [Aa] [학습] [⋯]

Aa — 읽기 설정        학습 — 활동          ⋯ — 자료 관리
글자·배경             받아쓰기             원문 수정
학습 표시             읽기 확인            선택 범위 다시 분석
읽기 진행             회화 연습            전체 다시 분석
                                          자료 정보/기존 관리
```

- 제목과 도구를 별도 행으로 둘 수 있게 한다. 긴 제목은 줄바꿈하고 버튼 영역은 유지한다. 전체 제목을 툴팁만으로 제공하지 않는다.
- Aa에는 표시와 동작의 취향만 남긴다. 활동을 시작하거나 원문을 바꾸는 버튼은 밖으로 옮긴다.
- 학습 메뉴에는 현재 범위를 표시한다. 전체 자료/선택 문장/선택 구간을 구별하며, 각 기존 도구가 실제로 지원하는 범위만 제공한다.
- 범위별 결과 저장을 지원하지 않는 활동에는 선택 문장을 조용히 주입하지 않는다. 예를 들어 현행 전체 자료 읽기 확인은 전체 자료라고 표시하고 기존 기록 의미를 유지한다.
- 자료 관리의 소유권/원본·학습 사본 제한은 기존 판정을 그대로 사용한다. 메뉴 위치를 바꾸기 위해 권한을 넓히지 않는다.

## 3. 데스크톱과 모바일 배치

### 넓은 화면

```text
┌──────────────────── 상단 경로·제목·도구 ────────────────────┐
│                                                            │
│  원문: 읽기에 알맞은 폭             ┌────────────────────┐  │
│                                    │ [단어] [문장 번역] │  │
│  현재 문장과 선택한 단어            │ 표제어·독음·뜻     │  │
│  다음 문장                         │ 현재 원문          │  │
│                                    │ ▸ 더 알아보기      │  │
│                                    ├────────────────────┤  │
│                                    │ 저장/복습 행동     │  │
│                                    └────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

읽기 영역의 가용 폭 약 1120px 이상을 보조 패널 전환점으로 시작해 검수한다. 본문 약 660–760px, 패널 320–360px, 사이 24px가 초기 기준이다. 실제 컨테이너 폭과 확대 상태를 기준으로 전환한다.

항상 세 열을 예약하던 방식에서 **본문 + 보조 패널 한 곳**으로 정리한다. 번역·문맥과 단어는 이 패널의 탭으로 전환한다. 번역에서 단어를 누르면 단어 탭으로 이동하고, 문장 탭으로 돌아가면 같은 결과·스크롤을 유지한다. 두 기능과 기존 링크는 유지한다.

선택이 없으면 패널을 접고 본문을 가운데 둔다. 넓은 화면에서 카드가 열릴 때 본문 폭은 가능한 한 유지하고 그룹의 수평 정렬을 바꾼다. 카드 때문에 본문 줄바꿈이 계속 달라지지 않게 한다. 가용 폭이 부족하면 좁은 화면 배치를 사용한다.

### 좁은 화면

```text
상단 경로/제목/도구
현재 읽는 원문 — 다른 단어를 바로 누를 수 있음
┌──────── 단어/문장 패널 · 높이 조절 · 닫기 ────────┐
│ 표제어와 뜻                                      │
│ 현재 문장                                        │
│ ▸ 문형 / 유의어 / 한자 / 사전                     │
├──────────────────────────────────────────────────┤
│ 저장/복습 버튼                                   │
│ [단어] [문장 번역]                               │
└──────────────────────────────────────────────────┘
```

- 기본 높이는 약 55dvh, 사용자가 펼치면 최대 약 85dvh를 출발점으로 삼는다. 짧은 화면·확대에서는 콘텐츠가 버튼에 가려지지 않도록 조정한다.
- 패널 헤더/본문/행동/탭을 **같은 레이아웃 안**에 둔다. 독립적인 fixed 버튼 바가 복습 버튼을 덮지 않는다.
- 단어 패널은 비모달이다. 뒤의 원문을 누르거나 범위를 선택할 수 있고 키보드 포커스를 가두지 않는다. 열릴 때 제목으로 포커스를 옮기되, 닫힌 카드의 단축키는 기존 1차 가드로 막는다.
- Aa와 받아쓰기 같은 활동만 모달이다. 모달을 열면 단어 패널을 잠시 숨기고 선택·스크롤을 보관한다.
- 모바일 키보드와 안전 영역을 실제 보이는 높이에 반영한다. 하단 고정 영역이 화면을 과도하게 차지하면 해당 영역을 일반 흐름에 놓는다.

이 보조 패널 정리는 기존 학습 기능의 재배치다. 보류한 원본 문서 split view를 신설하지 않는다.

## 4. Aa의 구체적인 구성

데스크톱: 폭 약 520px의 중앙 대화상자. 모바일: 최대 85dvh 아래 시트. 같은 native dialog 기반으로 제목/닫기/탭을 유지하고 옵션 영역을 스크롤한다.

```text
읽기 설정                                      [닫기]
[글자·배경]   [학습 표시]   [읽기 진행]

현재 문장 미리보기 — 최대 두 줄, 접기 가능
────────────────────────────────────────────────────
본문 크기       [−] ━━━━━●━━━━ [+]       26
병음 크기       [−] ━━●━━━━━━━ [+]       12
줄 사이         [좁게 ━━━●━━━━ 넓게]     현재값
글자 사이       [촘촘 ━━●━━━━━ 넓게]     현재값
서체            [고딕] [명조]
배경            [밝게] [종이] [어둡게]
────────────────────────────────────────────────────
[이 탭 기본값]                   [이번 변경 되돌리기]
```

| 탭 | 첫 화면의 항목 | 접어서 제공할 항목 |
|---|---|---|
| 글자·배경 | 본문 크기, 중국어 병음 크기, 줄/글자 사이, 실제 서체, 배경 | 세부 안내 |
| 학습 표시 | 작은 프리셋 한 줄, 발음 전체/새 단어만/숨김, 탭으로 확인, 단어 상태 | 성조, 문법 범위, 한자 정보와 각 범례 |
| 읽기 진행 | 문장 집중, 자동 진행 허용, 목표 속도 | 속도 산정 출처/훈련 단계, 단어 선택 시 발음, 기존 재생 속도 |

프리셋 카드는 큰 그림 세 장에서 작은 선택 한 줄로 바꾼다. 프리셋은 학습 표시 탭에만 둔다. 개별 변경 후에는 정확한 프리셋과 일치할 때만 그 이름을 표시하고, 아니면 ‘사용자 설정’으로 표시한다.

### 설정 적용과 복원

1. 조절 즉시 적용한다. 별도의 저장 버튼 없이 닫으면 유지한다.
2. Aa를 열 때 전체 설정 스냅샷을 한 번 보관한다. ‘이번 변경 되돌리기’는 그 스냅샷으로 복원한다. 탭 이동 때 덮어쓰지 않는다.
3. ‘이 탭 기본값’은 현재 탭의 설정만 초기화한다. 활동 결과·학습 데이터·자동 진행의 실행 상태는 초기화 대상이 아니다.
4. 미리보기는 현재 문장의 기존 토큰으로 그리는 순수 표시 컴포넌트다. AI 호출·단어 만남·저장·읽기 완료·진도 쓰기를 발생시키지 않는다. 자료가 없으면 자체 작성 예시를 쓴다.
5. 미리보기는 최대 두 줄이며 작은 높이/확대에서는 접을 수 있다. 고정 헤더가 옵션 영역을 다 차지하지 않게 한다.
6. 설정 저장 실패 시 현재 화면 적용은 유지하고, ‘이 브라우저에 저장하지 못했어요’를 표시한다. 성공한 것처럼 안내하지 않는다.

### 프리셋 의미

| 프리셋 | 발음 | 탭 공개 | 상태색 | 성조 | 문장 집중 |
|---|---|---|---|---|---|
| 몰입 읽기 | 숨김 | 끔 | 끔 | 끔 | 켬 |
| 학습 모드 | 전체 | 끔 | 켬 | 중국어에서 켬 | 끔 |
| 암기 확인 | 새 단어만 | 켬 | 켬 | 끔 | 끔 |

현재 프리셋의 의미를 유지한다. 다만 다른 탭의 ‘문장 집중’도 바뀐다는 설명을 프리셋 옆에 붙인다. 문법/한자·배경·서체·음성 속도는 프리셋이 덮어쓰지 않는다. 어느 프리셋도 자동 진행이나 소리를 시작하지 않는다.

‘새 단어만’은 저장 단어와 이미 앎 기록의 발음을 가리는 기존 판정이다. 저장했다고 외웠다고 간주하는 새 규칙을 넣지 않는다. 발음 모드/프리셋 변경, 자료 판본 변경 시 임시 공개 기록을 지운다. 공개 기능을 끄면 공개 기록도 초기화한다.

숨긴 발음에만 첫 탭 공개 → 다음 탭 카드 규칙을 적용한다. 발음이 없는 토큰은 첫 탭부터 카드를 연다. 집중 모드의 다른 문장 선택과 드래그 선택이 발음 공개보다 우선하는 기존 제스처를 유지한다.

## 5. 병음과 서체

### 중국어 조판의 결정

현재 `0.26em`은 1em 한자 칸에 긴 병음을 넣기 위한 제약이다. 기본 본문 약 26px에서 병음은 약 6.8px이고, 최소 본문에서는 약 3.3px다. **항상 1em 폭을 고정하는 규칙을 교체하고 읽을 수 있는 병음의 크기를 우선한다.**

초기 검수값:

| 항목 | 신규 기본값/출발점 | 조절 범위/주의 |
|---|---|---|
| 중국어 본문 | 약 26px에 해당하는 rem | 우선 권장 20–40px, 기존 유효한 12.8–48px 값은 강제로 덮어쓰지 않음 |
| 중국어 본문 병음 | 0.75rem, 보통 기본 환경에서 약 12px | 0.75–1rem. 브라우저 확대/기본 글자 크기를 따름 |
| 단어 표제어 | 약 40–56px | 1글자라고 패널 전체를 채우지 않음. 긴 단어는 24px 안팎 아래로 계속 축소하는 대신 줄바꿈 |
| 카드 뜻/본문 인용 | 약 18px/18–22px | 한국어 설명은 15–16px 출발, 접근성 확대와 함께 커짐 |
| 카드 병음 | 약 14–16px | 큰 한자의 26%로 기계적으로 계산하지 않음 |

수치는 구현 시 실렌더로 조정할 초기값이며 접근성을 보증하는 선언이 아니다. 읽기 설정은 본문과 인용을 조절하고 사이트 메뉴 전체 크기를 바꾸지 않는다. 별도 병음 조절을 일본어 요미가나에 함께 적용하지 않는다.

### 균일한 병음 칸

- 한 글자/한 음절 대응과 동일한 병음 글자 크기·기준선을 유지한다.
- 표시되는 병음의 서체/크기에서 정상 중국어 음절이 들어갈 **공통 최소 칸 폭**을 계산한다. 한자 폭과 병음 폭 중 큰 쪽 + 작은 좌우 여유를 사용한다.
- 긴 음절 하나만 축소하거나 단어마다 칸 폭을 달리하지 않는다. 실제 자료의 오염된 병음 문자열 하나가 전체 글자 간격을 늘리지 않도록 검증한 음절 집합/유효 범위로 측정한다.
- 병음 표시 또는 탭 공개가 가능한 동안은 모든 대응 한자에 같은 공간을 예약한다. 숨김↔탭 공개, 이미 저장된 단어와 새 단어 사이에서 글자가 밀리지 않는다.
- **완전 숨김 + 탭 공개 끔**이면 자연스러운 본문 간격으로 전환한다. 이 모드 전환의 줄바꿈은 허용하되 읽던 위치를 복원한다.
- 자간 슬라이더는 안전한 최소 간격 위의 추가 여백을 조절한다. 겹치도록 최소 폭을 침범할 수 없게 한다.
- 병음/한자 수 불일치, `T恤`·숫자·영문·儿化·문장부호는 기존 폴백을 유지하며 별도 검수한다. 발음을 임의로 고치거나 글자에 잘못 분배하지 않는다.
- 이합사 연결 아치, 밑줄, 선택 그립은 새 글자 크기·칸 폭·줄바꿈 이후 위치를 다시 계산한다. 예전 0.58em 좌표를 그대로 복사하지 않는다.

가장 긴 음절이 들어가는 칸은 작은 한자에 비해 성겨질 수 있다. 한 줄 글자 수를 유지하기 위해 병음을 다시 작게 줄이지 않는다. 긴 음절 연속/일반 문장/모바일에서 균일함과 밀도를 함께 보고 공통 폭의 여유를 줄인다.

### 실제로 바뀌는 서체만 제공

- 중국어: 현행 **Noto Sans SC 고딕**을 기본으로 유지하고 **Noto Serif SC 명조**를 두 번째 선택으로 권장한다. 간체 자형을 유지한다. Noto Serif SC는 공식 메타데이터에서 간체 지원과 OFL 배포를 확인했다. [메타데이터](https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/METADATA.pb), [라이선스](https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/OFL.txt).
- 병음: 현행 Noto Sans. 한글 UI: 현행 Noto Sans KR. 둘을 중국어 본문 서체와 함께 무조건 변경하지 않는다.
- 중국어 선택 UI에서 실제 적용되지 않는 KR 명조·고정폭·Inter 선택을 제거한다. 명조는 로딩/실제 글리프 적용까지 확인해 제공한다. 실패 시 고딕으로 읽을 수 있게 하고 선택 성공을 가장하지 않는다.
- 새 CJK 서체는 중국어 뷰어/명조 사용 범위에 한정해 로드하는 방안을 검증한다. 초기 네 언어 화면 모두에 새 대용량 글꼴을 선로드하지 않는다. 용량·요청 수·캐시 상태를 측정해 정한다.
- 일본어는 현행 Noto Sans JP/요미 조판을 보존하고 실제 지원 서체만 보여준다. 영어·프랑스어에는 중국어 발음 옵션을 만들지 않는다.

## 6. 색과 테마

승인된 언어 토큰을 그대로 재사용한다. 중국어 세이지 `#466C5D`, 일본어 모브 `#80576A`, 프랑스어 잉크블루 `#4D5D85`, 영어 앰버 `#85602F`다. 새 브랜드 팔레트를 만들지 않는다.

- 기본 화면은 종이 계열 바탕, 진한 본문, 절제한 구분선, 선택한 부분에 언어색을 쓴다.
- 밝게/종이/어둡게를 읽기 화면 전체의 표면·문자·구분선·입력창·선택·포커스 토큰으로 정의한다. 모달/포털에도 동일한 읽기 테마를 전달한다.
- 어두운 테마는 실제 어두운 불투명 배경을 사용한다. 밝은 부모 위 반투명 흰색으로 처리하지 않는다. 네 언어마다 별도 색상 열두 세트를 임의로 늘리지 않고 공통 표면과 기존 언어 강조색을 조합한다.
- 새 사용자에게만 종이 테마를 기본으로 제안한다. 명시적으로 저장한 light/sepia/dark는 그대로 존중한다. 이전 코드의 미설정 기본값 dark와 사용자가 저장한 dark를 구별한다.
- 성조는 병음 글자색, 단어 상태는 옅은 바탕/상태 설명, 문법 후보는 밑줄과 표지로 역할을 분리한다. 선택은 외곽선과 별도 선택 배경으로 우선 표시한다.
- 집중 모드에서 주변 문장 전체에 opacity 0.18을 적용하지 않는다. 대비를 유지하는 보조 본문색과 선택 문장 표식으로 집중을 안내한다.
- 보조 정보와 성조도 각 테마에서 읽을 수 있게 대비를 검사한다. 일반 텍스트는 4.5:1을 목표로 검수하며 색 이름만으로 상태를 안내하지 않는다. [W3C 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- 그라데이션·강한 유리 효과·배경 모션을 추가하기보다 글자, 여백, 작은 동작 상태로 manabi의 분위기를 만든다. 모션 감소 설정을 존중한다.

## 7. 단어 카드의 정보 순서와 행동

```text
단어 · HSK 정보                       [재생] [닫기]
盛                 chéng
담다                               [뜻·발음 수정]

현재 문장
她盛粥。                         ← 선택 단어 강조
번역이 이미 있으면 표시 / 없으면 [문장 번역]

▸ 이 문장에서는?
▸ 관련 문형 후보 N개
▸ 유의어·반의어
▸ 한자 정보
▸ 사전의 다른 뜻·예문
──────────────────────────────────────────────────
새 단어 저장 — 얼마나 알겠어요?
[다시] [어려움] [알맞음] [쉬움]
```

위 문장은 자체 작성 예시이며 실제 HSK 자료의 독음/뜻을 고쳤다는 의미가 아니다.

1. 표제어·독음 → 문맥 뜻 → 현재 원문 → 행동의 순서를 고정한다. 긴 문장은 줄바꿈하고 필요하면 펼친다. 일부 발췌는 생략 표시와 원문 이동을 제공한다.
2. 기존 문장 번역이 없으면 원문부터 보여준다. 카드만 열었다고 새 번역·문맥 판정을 자동 생성하지 않는다.
3. 문형은 후보라는 표시와 개수로 접는다. 현재 문형을 확정한 것처럼 보이지 않게 한다. 관련 교재 링크를 유지한다.
4. 유의어·한자·다른 사전 뜻은 접어서 시작한다. 선택이 바뀌면 새 토큰 기준으로 초기화한다. 같은 토큰의 데이터 갱신은 사용자가 펼친 상태·스크롤을 보존한다.
5. 접힌 추가 정보는 필요한 경우 펼칠 때 기존 경로로 불러온다. 요청/캐시/늦은 응답 가드는 1차 것을 사용하며 외부 전송 범위를 늘리지 않는다.
6. **현재 4등급 신규 저장을 유지한다.** 초기 설계의 단일 ‘저장’ 버튼은 기존 초기 복습 등급 선택과 충돌하므로 이번에 채택하지 않는다. 키 1–4, 등급별 계산, 저장 취소 보호는 그대로다.
7. 새 단어는 ‘저장’, 복습 시점인 기존 단어는 ‘복습’, 아직 복습 시점이 아닌 단어는 ‘단어장에 있음/이 문맥 추가’를 표시한다. 같은 카드에 새 저장과 복습 행동이 동시에 중복되지 않게 한다.
8. 원탭 무등급 저장은 기존 단어 목록 경로를 유지한다. 새 ‘이미 알아요’ 쓰기는 부활시키지 않는다. 과거 이미 앎 상태와 기존 해제 기능은 보존한다.
9. 행동 영역은 패널 안 하단에 유지한다. 입력 키보드·200% 확대·긴 설명에서는 콘텐츠를 가리지 않도록 흐름 배치로 전환한다. 복습 숫자 키는 입력칸/모달에서는 실행하지 않는다.

## 8. 화면 상태와 자동 진행

영속 설정과 현재 활동 상태를 분리한다. 모든 것을 저장하거나 여러 boolean으로 중복 판단하지 않는다.

| 종류 | 내용 | 수명 |
|---|---|---|
| 읽기 취향 | 글자·발음·테마·목표 속도 | 브라우저 저장, 언어별 |
| 현재 문맥 | 자료/판본/토큰·문장/보이는 위치 | 현재 자료 |
| 보조 패널 | 닫힘/단어/문장, 각각의 결과와 스크롤 | 현재 자료·선택 |
| 모달 | 없음/Aa/활동/편집/분석 확인 중 하나 | 한 번에 하나 |
| 자동 진행 | 꺼짐/준비/진행 중/잠시 멈춤 | 현재 세션, 재방문 자동 시작 안 함 |

모달을 열 때 이전 패널·선택·읽기 앵커·호출 버튼을 보관한다. 뒤의 단어 패널은 숨기고 비활성화한다. 모달을 닫으면 유효한 같은 자료/판본에서만 복원한다. 자료가 바뀌면 예전 패널이나 입력을 새 자료에 붙이지 않는다.

### 자동 진행 상태표

| 행동 | 결과 |
|---|---|
| Aa에서 자동 진행 허용 | 준비. 문장이 자동으로 넘어가지 않음 |
| 본문 ‘자동 진행 시작’ | 현재 문장/읽던 앵커 문장부터 시작. 선택만 하며 AI 분석은 호출하지 않음 |
| 카드/Aa/활동 열기, 드래그 선택, 앱이 뒤로 감 | 일시 정지. 남은 시간과 이유 보관 |
| 마지막 정지 원인이 해제됨 | 직전 실행 중일 때만 재개. 남은 시간이 짧아도 최소 2초 여유 |
| 정지 중 다른 문장 선택 | 새 문장의 전체 체류 시간을 확보 |
| 수동 정지, 빈 곳 클릭으로 문장 해제, 사용자가 직접 스크롤해 벗어남 | 준비/정지. 패널을 닫아도 저절로 재시작 안 함 |
| 집중 모드 해제 | 진행 정지. 집중을 다시 켜도 시작은 사용자 행동 |
| 마지막 문장 | 종료하고 준비 상태. 이것만으로 읽기 완료/실력 향상을 기록하지 않음 |

작은 시작/멈춤 제어는 자동 진행을 허용한 경우에만 나타낸다. 예전의 ‘문장을 고르면 자동 시작’ 규칙을 명시적 시작으로 교체하는 제안이다. 원문을 단순히 선택했을 뿐인데 시간이 흐르는 문제를 없앤다. 읽던 속도 이력과 훈련 사다리는 기존 계산을 사용하고, 페이서 속도를 사용자의 독립 읽기 실력으로 합치지 않는다.

### 위치 보존

기존 앵커 helper를 확장한다. 자료/판본/토큰 ID, 긴 문장 안의 위치, 화면 상단에서의 오프셋을 캡처한다. 글자·서체·병음 공간·폭·활동 복귀가 바뀌어도 이 기준으로 복귀한다.

한 번의 requestAnimationFrame만 기다리는 현재 방식에 더해 실제 폰트 로드와 크기 변화를 처리한다. 그사이 사용자가 스크롤하거나 다른 자료로 이동했다면 늦게 복원하지 않는다. 매 프레임 전체 문서를 측정하지 않고 영향이 있는 변경에만 측정한다.

스크롤 목표 영역에서 고정 헤더와 열린 시트/행동바를 제외한다. 단순한 window 중앙 이동으로 선택 단어가 시트 뒤에 가려지지 않게 한다. 설정 재배치 때문에 진행률·단어 만남·완독 기록이 증가하지 않도록 사용자가 읽은 이동과 구별한다.

## 9. 받아쓰기와 활동 레이어

- 공통 모달 프레임을 사용해 Escape, Tab/Shift+Tab, 제목, 명시적 닫기, 호출 지점으로 포커스 복귀를 일치시킨다. 단어 패널의 z-index만 올려서 해결하지 않는다. [W3C 모달 동작 기준](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).
- 받아쓰기 선택 → 입력 → 결과를 같은 활동 프레임 안의 단계로 전환한다. 모달 위에 또 다른 모달을 쌓지 않는다.
- 입력 단계에는 뒤의 원문·번역·단어 카드를 시각적으로 숨기고 접근성 트리/포커스에서도 제외한다. 반투명 가림만 하지 않는다.
- ‘원문 보기’를 명시적으로 누르면 이번 시도에 표시한다. 이 시도를 인출 성공이나 완벽한 이해의 근거로 오인하지 않게 한다. 새 FSRS 이벤트를 만들지 않는다.
- 입력 중 닫아도 같은 자료/판본의 초안은 메모리에 보존한다. 재개 시 복원하며 브라우저를 닫은 뒤에도 저장된다고 약속하지 않는다.
- 오류 안내/재시도는 현재 활동 안에 둔다. 읽기 확인·회화의 기존 요청 범위와 안전 가드를 유지한다. 회화 재시도는 발화를 중복 추가하지 않는다.
- 새 활동으로 전환할 때 이전 오디오를 정지한다. 실제 음성 품질·물리 기기의 마이크 권한은 이번 코드/에뮬레이션 검수와 구별해 보고한다.

## 10. 기존 설정과 학습 데이터 이관

현재 `viewer_*` 값은 언어 공통이다. 새 스키마는 공통 취향(배경·재생 속도 등)과 언어별 조판/학습 표시로 구분한다. 기존 키는 삭제하지 않고 유효한 값을 초기 이관에 사용한다. 이후 언어별 변경이 다른 언어의 크기/병음 취향을 덮지 않게 한다.

수치 범위/enum/JSON 오류를 검사하고 미설정 항목에만 새 기본값을 적용한다. 예전 중국어 ‘Inter/명조’ 값은 실제 한자에 적용되던 Noto Sans SC로 해석하며 영어의 Inter 취향까지 삭제하지 않는다. 기존 명시적 테마는 보존한다.

새 형식은 이관 완료를 기록해 매 진입마다 구 값을 다시 덮어쓰지 않는다. 저장소가 막혀도 세션 메모리로 동작한다. 설정 초기화는 원문·분석·출처·복습 일정·학습 결과를 건드리지 않는다.

## 11. 구현 순서와 파일 책임

이번은 세 내부 단계로 나누되, 서로 맞물리는 메뉴·상태·조판을 하나의 검토 가능한 개편으로 완성한다.

| 단계 | 구현 | 검수 기준 |
|---|---|---|

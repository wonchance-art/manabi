# 교재·내 자료·복습 연결 — 3차 적용 안내

2026-09-05. 사용자의 직접 적용 승인에 따라 Manabi 운영 DB 마이그레이션과 권한 검증을 완료했다. 웹 앱은 아직 배포하지 않았다.

## 사용 흐름

1. 교재 단원의 **자료와 함께 복습하기**에서 내 읽기 글이나 PDF를 연결한다. 자료 뷰어의 **연결한 교재 단원**에서도 연결·해제할 수 있다.
2. 교재 예문·레슨 어휘, 자료의 선택 단어·드래그 문장, PDF 분석 결과에서 **복습에 담기 / 문맥 추가**를 누른다.
3. 단어 카드가 이미 있으면 추가 발췌만 저장한다. 뜻이 다르면 두 뜻을 비교해 확인한다. 다른 뜻은 취소한다.
4. 단어 복습에서 답을 연 뒤 **이 표현을 만난 문맥**을 펼친다. 교재 예문, 자료 토큰, 입력한 PDF 쪽수로 돌아갈 수 있다.
5. 자료 연결이나 추가 문맥은 개별 삭제할 수 있다. 단어 카드·자료 원본·복습 일정은 삭제하지 않는다.

교재의 일반 예문과 레슨 어휘에 우선 적용했다. 구조화된 긴 대화·모든 임의 본문 선택까지 동일 저장 도구를 확장한 것은 아니다.

## 적용 순서와 범위

저장소의 기본 규칙은 오너 수동 적용이지만, 이번에는 사용자가 “직접 적용할 수 있나 환경 갖춰졌으면 적용”이라고 명시적으로 승인했다. 해당 SQL에 한해 연결된 Supabase 도구로 직접 적용했다. 저장소의 전역 규칙은 변경하지 않았다.

1. **완료:** `supabase/migrations/20260905065205_textbook_material_contexts.sql`을 Manabi에 적용하고 원격 이력을 확인했다. 이 SQL을 다시 적용하지 않는다. 로컬 파일 번호도 원격 마이그레이션 버전과 맞췄다.
2. **완료:** 운영 DB에서 비로그인·모든 기존 자료 소유자·무관한 사용자 역할로 읽기 권한을 확인했다. 적용 당시 그룹 연결 자료는 0개였다.
3. **남음:** 이 변경을 포함하는 앱 배포와 실제 로그인 상태의 읽기 자료/PDF 연결·단어 저장·복습 출처 이동 검증.

SQL은 `textbook_material_links`, `vocabulary_contexts`, `save_vocabulary_context` RPC를 추가한다. 단어장 기존 행을 일괄 수정하거나 복습 값을 갱신하지 않는다. 기존 앱은 새 테이블 없이도 운영할 수 있지만 **새 UI는 SQL 적용 후 배포**해야 한다. DB 쓰기를 감춘 성공 처리나 로컬 저장 대체는 하지 않는다.

### 함께 보완하는 읽기 권한

읽기 전용 점검에서 `reading_materials`에 `USING (true)`인 permissive SELECT 정책이 공존하는 것을 확인했다. 이런 정책은 더 좁은 permissive 정책과 OR로 합쳐져 비공개 제한을 약화시킨다.

적용한 SQL은 기존 정책을 삭제하지 않고 restrictive SELECT 정책을 추가했다. 공개 자료와 소유자 자료 읽기를 유지한다. 관리자는 이 추가 제한에서 제외하되 실제 읽기 허용 여부는 기존 permissive 정책도 따른다. 새 연결 API도 공개/소유 여부를 명시적으로 검사한다. 비공개 PDF는 소유자만 연결한다. 사용자와 자료 소유권은 클라이언트 요청값이 아닌 인증 정보와 DB에서 검증한다.

현재 확인한 정책에는 그룹 멤버용 읽기 규칙이 없었다. 이번 제한은 그룹 멤버의 별도 읽기 권한을 새로 만들지 않으므로, 기존 그룹 공유를 일반 공개와 다르게 운영 중이라면 해당 접근 계약을 확인한 뒤 명시적인 그룹 정책을 함께 설계해야 한다. 현재는 보완 SQL을 적용했고, 비로그인 사용자에게 비공개 자료가 노출되지 않음을 운영 DB 역할 검사로 확인했다.

## 저장 계약과 한계

- `reading_materials.id`는 실제 DB의 bigint, `uploaded_pdfs.id`와 단어 ID는 UUID를 사용한다.
- 새 카드는 NFC·앞뒤 공백을 정리한 기본형으로 저장한다. 기존 정확 표기 카드가 있으면 재사용한다. 없으면 같은 언어의 `base_form` 단일 후보를 재사용한다. 복수 후보는 확인 안내로 중단한다.
- 기존 `(user_id, word_text)` 고유 키를 변경하지 않았다. 언어가 다른 동일 표기 카드나 의미별 별도 카드 생성은 이번 이행 범위 밖이다. 뜻 충돌을 강제로 통합하지 않으며 사용자가 같은 의미라고 확인한 경우에만 기존 카드에 연결한다.
- 공통 저장 API 안의 단어·출처 저장은 원자적이다. 출처 권한 검사나 제약이 실패하면 새 카드 생성도 취소되며 기존 카드의 복습 필드는 유지된다. 최신 자료/PDF 뷰어의 기존 저장 경로는 먼저 정본 조립기로 카드를 저장하고 문맥 RPC를 호출한다. 이 경우 문맥 연결만 실패하면 카드 저장 성공과 구분해 알리고 재시도 버튼을 제공한다. 자료 뷰어의 4등급 초기 일정과 저장 취소를 유지한다.
- 출처는 원문 발췌·교재 내용 지문과 내부 위치 식별자를 저장한다. 외부 URL이나 PDF 서명 URL은 저장하지 않는다. 교재 내용 지문은 불변 출판 판본 ID가 아니다.
- 읽기 위치는 토큰 ID + 표면형이다. 재분석 후 일치가 불명확하면 임의 위치로 이동하지 않는다. PDF는 직접 입력한 쪽수까지만 연결하며 쪽수를 모르면 문서 처음부터 연다.
- 삭제·비공개 전환으로 접근 불가능해진 자료의 연결과 추가 문맥은 RLS로 숨긴다. 과거에 개인 카드의 최초 예문으로 저장한 `source_sentence`는 복습 데이터 보존을 위해 그대로 둔다.
- 목록은 최근 개인 읽기 자료 100개 + PDF 100개를 선택 후보로 제공한다. 단원 연결은 최대 100개, 단어별 추가 문맥은 최초 50개를 표시한다. 대규모 자료 검색과 문맥 페이지 이동은 추후 확장한다.
- 게스트의 기존 로컬 레슨 카드는 유지한다. 로그인 이후 새 저장은 서버 단어장으로 보내며 기존 로컬 카드는 자동 이관하지 않는다.

## 검증

- 관련 Vitest 13개 파일 / **216개 테스트 통과**. 인증 거부, 비공개 자료 차단, 서버 원고/토큰에서 발췌, 입력 검증, 충돌 처리, 사용자별 조회·삭제, 공개 수정 제목과 기존 교재/복습 회귀를 포함한다.

- **격리 Chrome에서 실제 React/React Query 컴포넌트**의 10개 흐름 검증. 단원 양방향 연결, 세 출처 저장, 중복 재저장, 뜻 확인/취소, 원문 토큰 강조와 위치 변경 안내, PDF 쪽수 fragment, 문맥만 삭제, 저장 실패, 비로그인 쓰기 차단을 확인했다.
- 320/390/1024px × 밝은/어두운 테마, 총 6개 조합에서 가로 넘침·JS 실행 오류 없음. 실제 스크린샷을 검토하고 새 도구의 글자 대비를 보완했다.
- 변경 통합 JSX 구문 검사와 실제 교재 서버 렌더 성공. 변경 파일 린트 오류 없음. PDF 분석 자동 실행의 기존 Hook 의존성 경고 1건은 유지했다. 별도의 미정의 변수 검사에서 발견한 기존 뷰어 부분 재분석 버튼의 잘못된 setter 호출도 수정했다.

브라우저의 인증·API는 격리된 테스트 응답으로 대체했다. 실제 배포에서 로그인→서버→운영 DB까지의 통합 검증, PDF 파일에서 쪽수의 시각적 일치, 전체 앱 프로덕션 빌드는 수행하지 않았다. 로컬 iCloud 의존성 설치 문제를 피해 임시 검증 도구를 사용했으며 프로젝트 의존성·환경 파일은 변경하지 않았다.

PostgreSQL 검증 재실행: `PGLITE_MODULE=/설치경로/@electric-sql/pglite node supabase/tests/textbook-material-contexts.mjs`. 이 스크립트는 로컬 메모리 DB만 사용하고 운영 연결 문자열을 받지 않는다.

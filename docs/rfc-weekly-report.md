- 상태: **R1(엔진) 진행 · R2(UI) 목업 승인 대기** — 오너 연속 위임(2026-08-23 "다음 큰
  목표 이어서 ㄱㄱ")으로 자율 설정. UI 반영은 목업 합의 선행.
- 기준: `origin/main` `3196475` (+#1108 서재 i+1 R2 대기 중)
- 근거: evaluation-and-strategy Phase 2 P1 **"주간 리포트 — ❌ 미구현"**(재평가 표 기준
  잔여 ❌ 중 학습 웹·결정적 계산에 정합하는 유일 항목. AI 작문 피드백 ❌ 표기는 이후
  /study 산출 문항·writing-feedback API로 부분 해소돼 문서가 낡음 — 별도 갱신 대상).
- 원칙: 이메일 발송 없음(인프라·오너 결정 필요 — 비목표, 대시보드로만). 보상·랭킹 없음
  — 리포트는 거울이지 성적표가 아니다. LLM 없음 — 결정적 집계.

## 1. 결론

**"이번 주 나"를 한 카드로**: 복습량·정답률·새로 담은 말·만난 말·완독 자료를 KST 주간
경계로 집계하고 지난주와 나란히 보여준다. /study 순환의 산출 정거장을 주간 단위로
비추는 거울이며, 만남 모델(§4.5 서버 정본)이 "만난 말" 축으로 자연 합류한다.

## 2. 실측 — 이미 있는 재료 (2026-08-23 조사)

- **growthStats.js가 성장 지표의 명시적 정본** — kstWeekStartMs(월요일 경계, "흩어진
  동일 구현의 정본"이라 주석에 선언됨)·kstDayStartMs·isKnownWord. 주간 경계는 여기만 쓴다.
- 주간 소품 선례: /study 주간 약점 세션(일요일)과 주간 회고 2카운트("문항 n·강해진
  기억 m") — 리포트는 이들의 확장이지 대체가 아니다.
- 데이터 전부 기존재: review_events(created_at·correct·source), user_vocabulary.created_at
  (ProfileStats 히트맵이 이미 소비), material_progress.completed_at(HomePage 소비),
  user_vocab_encounters.first_met_at(§4.5).
- 표면 후보: **ProfileStats**(히트맵·오늘 지표가 이미 있는 통계 화면 — 1후보),
  HomePage 위젯(2후보). 목업은 ProfileStats 기준.

## 3. 설계

### 3.1 집계 엔진 (R1 — weeklyReport.js, 순수)

- **주간 경계**: kstWeekStartMs 정본 그대로(월 0시 KST). 이번 주 = [주 시작, now],
  지난주 = [주 시작−7일, 주 시작).
- **복습**: review_events 중 **채점 문항만**(source가 ui·dict가 아닌 것 — EWMA 다이얼과
  같은 판정, §4.9 무간섭 결). total·correct·accuracy(표본 0이면 null — 0 무표기).
- **새로 담은 말**: user_vocabulary.created_at 주간 count.
- **만난 말**: user_vocab_encounters.first_met_at 주간 count(첫 만남 기준 — 불변 철학
  그대로, 재만남은 세지 않는다).
- **완독**: material_progress.completed_at 주간 count.
- 전부 순수 함수(행 배열 + now 주입) — 쿼리는 소비 화면 몫(growthStats 관례 동일).
- '레벨 변화'(원 기획 문구)는 제외 — XP 레벨은 이미 상시 노출이고 주간 스냅샷 비교는
  저장 없이는 부정확. 대신 만난 말 축을 더한다(만남 모델 확장 — 원 기획에 없던 우리 축).

### 3.2 UI (R2 — 목업 승인 후)

**목업 A. ProfileStats 상단 "이번 주" 카드** (로그인 화면이라 게스트 무관):

```
┌────────────────────────────────────────────┐
│ 이번 주 (8/18 ~ 8/24)                       │
│ 복습 132문항 · 정답 86%      지난주 118 · 82% │
│ 새로 담은 말 24 · 만난 말 41 · 완독 2편        │
└────────────────────────────────────────────┘
```

- 지난주 비교는 회색 병기(화살표·증감 색상 없음 — 압박 배제). 축이 0이면 그 축 무표기,
  전 축이 0이면(첫 주) 카드 자체 생략(0 무표기 결).
- 주간 회고 문구("강해진 기억")와 겹치는 축 없음 — 회고는 세션 결과 화면, 리포트는 통계 화면.

## 4. 선례 조사 (규약)

| 대상 | 판정 | 근거 |
|---|---|---|
| growthStats 정본 | 채택(재사용) | 주간 경계·지표 판정의 선언된 단일 소스 — 새 경계 계산 신설 금지 |
| Duolingo류 주간 메일 | 배제 | 이메일 인프라·리텐션 압박 결 — 대시보드로만(원 기획의 "이메일 또는 대시보드" 중 후자) |
| 앱 스토어식 증감 화살표·색 | 배제 | 하락 주간을 빨갛게 칠하는 건 압박 — 회색 병기만 |
| 주간 약점 세션·회고(기존) | 공존 | 소비 지점이 다름(세션 내 vs 통계 화면) — 문구 축 비중복 확인 |

## 5. 비목표

- 이메일·푸시 발송(오너 결정·인프라 — 후속 gate)
- 보상·스트릭 연동·증감 색상(압박 배제)
- 월간·연간 확장(주간이 성립한 뒤)
- LLM 요약 문구 생성(결정적 수치만)

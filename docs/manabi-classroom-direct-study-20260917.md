# 수업 원본 직접 학습 · 뜻 수정 전달

## 사용 흐름

1. 학생이 수업 암호로 팀에 들어가 교재 또는 수업 기록을 연다.
2. 원본 뷰어에서 표현을 눌러 뜻·병음·후리가나를 확인한다.
3. 기존 네 등급 중 하나를 눌러 개인 단어장에 저장한다. 자료 전체 사본은 생성하지 않는다.
4. 복습 카드에 저장 당시의 문맥과 수업 원문 링크가 표시된다. 링크는 새 탭에서 해당 표현으로 돌아간다.
5. 자료 전체가 필요하면 팀의 **보관 옵션**을 명시적으로 선택한다. 이미 보관한 개인 사본은 그대로 유지한다.

비로그인은 수업 자료를 읽을 수 있고, 선택한 표현의 저장 요청만 이 탭에 보관한 뒤 로그인한다. 로그인 자체가 자료를 복제하거나 일괄 저장하지 않는다. 원문이 바뀌었다면 다시 선택하도록 알린다.

## 뜻 수정 전달

- 교사의 수업 표현 수정: 메타데이터와 정확히 일치하는 단일 토큰의 뜻을 같은 CAS 저장에서 갱신한다. 문장 번역을 구성 단어 전체에 덮어쓰지 않는다.
- 원본 읽기: 온라인 재진입마다 현재 접근 권한·자료·수정된 뜻을 다시 받는다. 메타데이터에만 수정이 남은 이전 원본도 읽기 페이로드에서 일치시킨다.
- 개인 사본: 기존 변경 안내에서 전후 뜻을 확인하고 반영한다. 학생이 직접 고친 값과 토큰 위치는 보존한다. 예전 메타데이터 전용 수정의 재알림과 개인 교정 오인도 방지한다.
- 저장한 개인 단어: 교사 수정이 개인 카드의 뜻이나 복습 일정을 자동 변경하지 않는다. 다른 뜻을 같은 카드에 연결하려면 현재 카드의 뜻을 확인해야 한다.
- 열어 둔 자료가 저장 직전에 바뀌면 409로 중단한다. 서버는 현재 단어를 원본에서 재구성하고, DB 트랜잭션은 원문·분석·팀 암호 세대·소유권을 다시 검사한다.

## 권한과 기록

수업 열람 권한과 개인 자료 소유권은 별개다. `reading_materials`의 비공개 RLS를 넓히지 않는다. 수업 전용 읽기 API와 로그인·서명된 팀 토큰을 모두 확인하는 저장 API를 사용한다.

신규 `vocabulary_contexts.kind='class'`는 팀·원본 ID·토큰 위치·발췌만 담는다. 원본 FK를 생성하지 않아 교사 자료가 삭제돼도 학생의 단어와 개인 발췌는 유지된다. 원문 열기는 그때의 수업 권한을 다시 검사한다. 다른 학생의 단어나 발췌는 볼 수 없다.

학생의 읽던 위치·읽기 완료는 이 기기의 계정·팀·원본별로 분리한다. 개인 자료의 서버 진도나 교사의 진도와 합치지 않는다. 온라인 권한 실패에는 캐시로 우회하지 않는다. 오프라인에서는 유효한 로컬 수업 토큰과 일치하는 팀의 기존 7일 캐시만 사용한다.

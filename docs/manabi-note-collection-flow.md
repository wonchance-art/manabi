# 개인 노트: 지금 모으고 나중에 정리

2026-09-16. 기존 비공개 노트의 필기 → 선택 인식 → 후보 보관 → 검토 → 개인 단어장 연결을 유지하면서, 수업 중 인식할 때마다 검토 패널이 열리던 흐름을 정리한다.

## 사용 흐름

1. 노트에서 선택한 필기의 이미지를 확인하고 인식한다. 결과는 후보 목록에 누적하고 전체 필기 화면으로 돌아간다. 인식 자체로 단어장에 저장하지 않는다.
2. 도구의 단어 정리 아이콘에 미완료 개수를 표시한다. 인식 직후 안내의 ‘지금 정리’는 이미 모은 후보만 연다. 단어 정리 도구는 기존처럼 텍스트/표현 요소도 수집한다.
3. 미완료를 기본으로 열고, 담음·제외·전체 필터로 이동한다. 미완료 항목의 표기와 뜻을 확인해 선택한다. 현재 보이는 선택 항목만 저장한다. 선택만 해도 목록에서 사라지지 않는다.
4. 저장에 성공한 항목은 담음으로 이동하고 실패한 항목은 미완료에 남는다. 기존 단어의 뜻이 다르면 명시적으로 문맥 연결을 확인한다. 기존 FSRS 일정은 바꾸지 않는다.
5. ‘계속 필기 · 나중에 정리’로 패널을 닫는다. 수정한 뜻·선택·제외·저장 ID는 기존 노트 JSON과 기기 초안에 보관된다. 새로운 상태 테이블은 만들지 않는다. 서재용 개수는 저장된 후보에서 서버가 계산한 요약으로 기존 metadata에 함께 보관한다.
6. 서재 카드에서 ‘미완료 N개 · 이어 정리’로 `/notes/:id?review=1`을 연다. 다른 노트나 계정의 집계를 섞지 않는다. 명시적 기존 어휘의 원문 복귀는 해당 후보 상태를 먼저 연다.

## 화면과 동작

- 태블릿/큰 화면은 필기와 정리 패널을 함께 표시한다. 좁은 화면은 패널이 전체 화면을 사용하며 배경 도구의 초점 이동을 막는다.
- 담은 항목은 독음·표현·뜻·원래 필기 링크만 남긴다. 원문 상세에서 ‘이 노트에서 다시 정리’를 선택하면 해당 노트 후보만 다시 검토한다. 기존 개인 단어는 삭제하거나 바꾸지 않는다.
- 제외는 삭제가 아니다. 제외 탭에서 다시 포함할 수 있으며 재수집하더라도 기존 제외·수정 상태를 유지한다.
- 저장 중에는 필터 변경, 재선택, 원래 필기 이동 및 닫기를 막아 부분 저장 결과를 확인할 수 있도록 한다. 오류가 있으면 정상 완료 안내보다 저장 오류를 먼저 표시한다.
- 서버 저장 완료 시 같은 계정의 새 책장·정리 개수·기존 보관 도구 캐시를 갱신한다. 새 책장은 보이는 개인 노트의 요약만 20개씩 묶어 읽으며 필기와 표현 본문을 가져오지 않는다. 요약이 없는 이전 노트에는 숫자 없이 이어 정리 링크를 제공한다. 저장 실패 시 완료된 것처럼 개수를 바꾸어 표시하지 않는다.

## 보존 및 경계

기존 소유권 확인·CAS revision·오프라인 초안·충돌 시 새 노트 보관·선택 PNG 확인/동의·취소·후보 중복 방지·원문 위치를 그대로 재사용한다. API, DB/schema/env, AI 공급자, 교사 설명판 데이터 형식은 바꾸지 않는다. 교사 화면 변경은 개인 노트인 경우의 대기 개수 표시만 해당한다.

설명판 서버 백업·공유 미리보기 이미지 수리·PDF·음성·외부 노트 반입은 별도 후속이다. 물리 iPad/Pencil 검수와 자동 WebKit 검수는 구분한다.

# N3 교재와 앱 발행 계약

N4를 마친 학습자가 정보의 출처·조건·근거·태도를 구별하고 자신의 설명을 쓰도록 48과를 제공한다. 작은 장면, 어휘, 표현 설명·예문, 대화, 말하기, 독해·확인, 쓰기의 N5/N4 제작 방식을 계승했다. 8과마다 누적복습 3문항씩 6세트와 시작 안내 4개를 포함한다. 웹의 198개 구간은 PDF 쪽수가 아니다.

확정 판본은 `4978c146953f14140bcb49d2`다. 내용 SHA-256은 `4978c146953f14140bcb49d21bc58d236195ad73d1568dc0d516c2546547aaf5`, 자산 묶음 SHA-256은 `1dfbabcd4369412ca5d80f5a3ba5c01070f9f233dc2dcd787f8235eef8dbad62`다. 검수 영수증은 [verification.json](verification/n3-app-release-20261021/verification.json)에 있다. 새 원고와 자산만 추가하며 기존 N5/N4 판본은 덮어쓰지 않는다.

## 원고와 출력 수락

세 집필자의 각 16과는 다른 담당자가 전 필드를 감수했다. M00는 시작 안내 4개와 누적문항 18개를 독립 검토하고, 최종 48과의 실제 파일 SHA와 수락 영수증을 대조했다. 정답 위치 조정은 기존 의미 검수본과 직접 비교하여 보기 순서 외 전 필드가 같음을 확인했다. 별도 Astra high 감사는 미리 고정한 16개 상황과 14개 과의 지정 용법을 대조했으며 전체 원어민 감수로 계산하지 않는다.

두 번 생성한 11개 파일이 바이트까지 일치했다. 실제 5종 WOFF의 필요한 1,308개 코드포인트 누락은 0이다. 단독 웹은 48과 × 4폭 × 기본/답안표시 384개 조판 관측과 원문·보기값·답안 재접속 저장·표시 토글·색인 검색·저장 실패 안내를 확인했다. 제작 담당자의 실제 화면 24장과 M00의 대표 화면 3장 직접 검토는 자동 조판 검사와 구분한다.

핵심 93묶음과 같은 가족의 명사 수식 변형 1개, 기존 N4 선수 13개, 본서 핵심 외 58개를 내부 실제 목록 165개와 대조했다. 공식 JLPT 전체 출제 목록이나 합격 보장을 뜻하지 않는다. 명시 회수 근거가 없는 이전 과는 누적복습까지 포함하면 0이다. 다만 +1/+3/+7의 계획 133쌍 중 실제 인용으로 확인한 것은 46쌍이며, 계획 전체를 이행했다고 주장하지 않는다. 어휘 576회 표기는 중복을 포함한 본서 표기 횟수이며 공식 N3 신규 단어 수가 아니다.

## 앱과 운영 경계

N3는 책장·읽기·원문 선택·담은 표현·과 범위 복습·같은 판본 원문 복귀를 기존 계약에 연결한다. N3의 끝은 48과이고 기존 N5/N4의 42과 경계는 유지한다. 미지원 교재 거절은 N2로 계속 검사한다. N3 관리자 페이지는 기존 계정 전환 시 서버 렌더를 비우는 보호 목록에 추가했다.

DB 호환 migration `20261021110823_textbook_n3_book_support`는 세 CHECK와 두 책장 함수에 N3만 추가했다. 실제 적용 전후 기존 교재·학습 데이터 집계와 RLS·정책·권한·함수 보안 설정이 동일했다. 독립 코드 검토와 격리 PostgreSQL 12개 시나리오를 통과했다.

초기 발행 SQL은 정확한 최종 원고·자산·검수 영수증을 검증한 뒤 별도로 생성한다. 기존 N5 두 판본·N4 한 판본, 두 공개 포인터와 전체 행 해시가 다르거나 N3 기록이 이미 있으면 중단한다. 현재 실제 관리자 identity/profile을 확인하고 두 INSERT만 원자적으로 수행한다. 격리 성공 검사는 합성 기준값을 쓰며, 수정하지 않은 운영 SQL은 합성 전체 행 기준값 불일치로 안전 중단함을 별도로 확인했다. 관리 DB 등록은 실제 계정 로그인 검수가 아니다.

새 PDF·음성은 제공하지 않는다. 로컬 앱 검수의 합성 학습자와 격리 HTTP 백엔드는 정상 운영 계정 검증으로 계산하지 않는다. 운영 발행·배포 식별자와 실제 익명 응답 검수는 최종 실행 보고에서 별도로 기록한다.

## 복원

최초 N3 공개에 문제가 생기면 확인된 직전 코드 배포로 복원하여 새 진입점을 숨긴다. 기존 판본과 학습 출처를 삭제하지 않는다. 이후 개정은 기존 교재별 발행 RPC의 기대 버전 검사를 사용한다. N3 자료가 있는 상태에서 CHECK를 N5/N4 전용으로 축소하지 않는다.

## 최종 로컬 앱 검수

실제 Next 앱과 격리 HTTP 백엔드의 합성 학습자로 14개 기능 및 48과 × 4폭의 192개 조판 조건을 통과했다. 선택 저장·중복 방지·인용 및 소유 경계, 실제 복습 1회와 일정 저장, 같은 판본 원문 복귀, 43–48과 출처, N5/N4 진행 분리를 포함한다. 검수 담당자는 화면 15장, M00는 대표 화면 2장을 직접 확인했다. 별도 보조 스크린샷 도구의 과도한 모든 쓰기 금지 검사는 정상 읽기 활동 기록으로 실패했으며 수락 근거에서 제외했다.

실제 검수에서 발견한 책장 SSR의 N5/N4 고정 목록과 찾아보기의 N4 전용 선택자를 수정했다. 책장 3개 회귀 테스트와 배포 앱의 N3 진입·48과·찾아보기 2개 브라우저 검사를 CI에 추가했다. 최종 전체 770개 파일의 9,121개 테스트, lint, 운영용 빌드, 5개 서버 경로의 실제 NFT 파일 추적을 통과했다. 운영용 빌드는 실제 폰트와 CI용 공개 DB 대역을 사용했다.

# 수업 교재 출처 복귀 — 1차 구현

오너 승인 설계(2026-09-11)의 첫 범위다. 부모 draft #1301/cdf9b76c에서 분리한 `codex/classroom-source-return-20260911`에서 진행한다. 원본 iCloud 작업 공간과 다른 세션 변경은 수정하지 않는다.

## 학습 동작

- 교재의 단어·드래그 표현·문장을 수업 노트에 추가하면 자료 ID, 실제 선택 구간, 정확한 원문, 앞뒤 문맥을 함께 저장한다.
- 수업 돌아보기의 `n과에서 선택한 표현 → 교재에서 보기`는 노트/항목 ID로 출처를 조회한다. 새 주소에 원문이나 긴 문맥을 싣지 않는다.
- 현재 분석의 토큰으로 위치를 다시 찾는다. 같은 원문의 분석 ID가 바뀌거나 토큰이 나뉘고 합쳐져도 원래 표현을 복원한다. 과거 오프셋만으로 복수 후보 중 하나를 고르지 않는다.
- 원문·주변 문맥이 달라지거나 같은 후보가 여러 개면 본문을 열고 상단에 위치 확인 안내를 보여 준다. 노트에 저장한 원문/뜻은 바꾸지 않는다.
- 기록의 검색어·교재 밖 표현 필터·날짜·불러온 기록 수·스크롤을 복귀 주소에 보존한다. 공유 교재나 수업 노트에 UI 상태를 저장하지 않는다.

## 데이터와 권한

`metadata.classSources[entryId]`를 확장한다. 새 테이블이나 RLS 정책은 추가하지 않는다. `TextQuoteSelector` 형태의 `anchor`를 쓰되 오프셋은 기존 뷰어/교재 주의점과 같은 JavaScript UTF-16 단위다. 교실 표현은 5,000단위, 주의점은 기존 1,000단위를 각각 유지한다. 이모지가 문맥 경계에서 잘리지 않게 한다.

기존 `textbookStream`/`resolveTextbookAnchor`를 재사용한다. `classroom_append_study`는 소유자·수업 교재 소속·원문·선택 위치·앞뒤 문맥을 DB에서 확인하고 텍스트 스트림의 `streamDigest`를 붙인다. 이 지문은 감사용 변경 식별자이며 권한이나 모호한 위치 선택에 사용하지 않는다. 같은 위치는 토큰 ID/분석 갱신과 무관하게 중복 방지하고, 다른 위치 및 명시적 `한 번 더 추가`는 보존한다. 여러 줄 표현도 한 출처로 중복 방지한다. 응답 유실 재시도는 같은 요청의 결과를 반환한다.

교사는 RLS로 자기 노트를 조회한다. 학생의 출처 API는 기존 수업 해제 토큰/세대를 검증하고, 노트와 연결된 교재가 모두 현재 팀 소속인지 확인한 뒤 출처만 반환한다. 뷰어는 이미 소유한 사본의 `source_ref`와 출처 자료 ID를 대조한다. 원본 접근 권한을 넓히거나 사본을 자동 덮어쓰지 않는다. 게스트 `local:` 뷰어는 네트워크 없이 기존 기기 사본과 30분짜리 탐색 힌트로 처리하고, 힌트가 없으면 기록에서 다시 열도록 안내한다.

교재 주의점·수업 표현·개인 단어/FSRS의 저장 경로는 기존 분리를 유지한다. sourceToken/sourceQuote 및 개인 복습 sourceText 링크도 호환한다. 위치 정보가 없는 이전 기록을 추측으로 일괄 변환하지 않는다.

## 검토 경계

이번 오너 지시는 웹 UI·저장 검증·회귀 테스트 구현 범위를 승인했다. 월드 SPEC/exact snapshot/도시 생성 전용 제한은 이 작업에 적용하지 않는다. 범위와 관계없는 월드 파일·교재 내용·PDF·음성·시험은 수정하지 않는다. 기존 문자열 계약 1건은 새 복귀 주소 래퍼를 반영해 갱신하며, 실제 교사/학생 브라우저와 DB 검사를 함께 둔다.

새 SQL 파일: `supabase/migrations/20260911051522_classroom_source_anchors.sql` (CLI로 생성). 운영 DB 적용은 별도 확인 대상이고 기존 함수 시그니처/INVOKER/인증 사용자 권한을 유지한다. merge/force-push는 하지 않는다.

## 실검수에서 확인한 포인터 보완

WebKit에서 터치로 길게 누르는 중 별도 마우스 포인터의 이동이 들어오면 기존 document 리스너가 이를 같은 제스처로 취급해 선택을 취소했다. 시작한 pointerId와 pointerType에 해당하는 이동/놓기/취소만 처리하도록 드래그와 양끝 핸들을 함께 보완한다. 실제 브라우저 회귀 검사에 터치 중 마우스 이동·놓기를 넣는다.

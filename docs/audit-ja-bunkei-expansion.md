## 3. 삼분 기준 (2단 triage의 판정 규칙)

| 유형 | 예 (실물) | 처분 |
|---|---|---|
| (a) **표기 차이만** | N5 「〜た あとで」 vs N4 「〜たあとで」 | 표기 정본 통일 후 하위 레벨 정본·상위 삭제 |
| (b) **동일 용법 중복** | N5 「〜と」 vs N4 「〜と」(같은 조건 용법이면) | 최초 도입 레벨 정본, 상위 레벨은 삭제 또는 참조 표기 |
| (c) **정당한 용법 재도입** | N5 「〜ながら」(동시 동작) vs N3 「〜ながら(も)」(역접) / N5 「〜まで」 vs N2 「〜まで(も)」(강조) | **유지** — 상호 참조 표기 권고("N5의 ながら와 형태 동일, 뜻이 다른 상급 용법") |

- (a)(b)와 (c)의 구분은 **의미 필드(explain·ex) 대조가 필요한 콘텐츠 판단** — 기계 목록(1단)으로는 확정 불가. 표본 12종 수기 판정 결과 (c)가 상당 비중으로 추정되어, "중복 114 = 삭제 114"가 아님을 명시한다.

## 4. 표준 대비 갭 — N4 파일럿: 갭 0

- JLPT N4 표준 대표 문형 42종(조건 4형·양태/전문·수수 3형·수동/사역/사역수동·의무/허가/금지·경험/조언·변화/결정 계열 등)을 정규화 포함 대조 → **42/42 커버**.
- 유일 후보였던 「〜てはいけない」는 N5에 「〜ては いけません」으로 선행 배치(금지·거절 뉘앙스 주석 완비) — 갭 아님.
- N3·N2·N1 표준 대조는 2단에서 같은 방법으로 확장(대표 목록 저작 필요 — 비공식 출처 표지 의무).

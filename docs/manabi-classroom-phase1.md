- 기존 뷰어, 공유·암호, 7일 사본, 복습·FSRS는 유지한다. 기존 분석·CAS 보존 경로를 재사용한다. 실제 검수에서 드러난 공통 LLM 요청 설정과 읽기 복귀 링크는 아래 후속 보정에 포함했다.

### 검증 한계

자동 회귀 검사는 합성 교사·수업 및 격리 DB를 썼다. 별도로 실계정의 명시적 검수 수업에서 입력과 AI 요청을 확인했다. 기존 운영 수업 원문은 수정하지 않았다. PGlite는 단일 연결에서 실행하므로 서로 다른 운영 PostgreSQL 연결의 lock timing을 실측한 근거는 아니다. 물리 iPhone/iPad Safari, 교실 네트워크의 실시간 지연, 실제 학습자의 로그인·사본 저장 왕복은 후속 검수다. 서버 저장 확인과 채널 연결 상태를 구분하며 태블릿의 화면 표시 수신 확인을 보장하지 않는다.

## 변경

- `/class`: 역할별 입구, 수업 표지, 수업 열기 우선, 유효한 기기 방문 기록과 링크 입력. 새로운 수업 주소·초기 암호 자동 생성. 기존 공유 주소 유지.
- 팀 홈: 수업 노트를 먼저 보여 주고 교재와 구분. 공유된 과 수와 학습 진도를 구분한다.
- `/live`: IME 대응 여러 줄 입력. IndexedDB에 항목별 보관이 완료된 뒤에만 입력창을 비운다. 계정·팀·시작 날짜별 대기열, 오류 유지와 재시도, 원문 저장과 분석 분리.
- 입력 중인 초안도 기기에 복원한다. 전송 시작과 입력 취소는 같은 IndexedDB 트랜잭션에서 판정한다. 응답 유실처럼 서버 저장 여부가 불명확한 항목은 취소로 숨기지 않고 재시도로 확인한다. 후속 입력은 실패 항목을 추월하지 않는다.
- 원자적 RPC `classroom_append_entry`: 소유자 루트 행 잠금 아래 날짜 노트 생성과 추가, UUID 요청 재전송 멱등성. 같은 내용의 별도 요청은 그대로 두 번 기록한다. 기존 원문·토큰·교정·사용자 metadata는 유지한다.
- 대표 뜻은 문장 전체의 뜻이 있을 때만 사용한다. 여러 토큰 뜻은 보충 설명으로 내리고 대표 뜻을 직접 적을 수 있다. 영어·프랑스어 독음은 표시하지 않는다.
- `/board`: 원어·독음·대표 뜻 중심 한 표현, 목록, 뜻 가리기, 글자 크기, 이전·다음, 최신 따라가기. 과거 항목을 선택하면 폴링에도 유지한다. Board 자체는 원격 쓰기 0이다. 폰의 선택은 소유자 CAS 저장 후 알림을 통해 서버 정본을 다시 읽는다.
- 집중 판에는 자체 브랜드·나가기만 남긴다. 폰에서는 입력과 최근 표현, 넓은 화면에서는 선택한 표현 미리보기를 함께 배치한다. 320px 헤더 잘림, 최소 44px 주요 조작, 키보드 초점, 기존 다크 설정과 종이 배경 사이 대비 충돌을 보정했다.
- 기존 뷰어, 공유·암호, 7일 사본, 복습·FSRS는 유지한다. 기존 분석 공통 모듈을 수정하지 않고 수업 경로에서 재사용한다.

## 운영 반영 조건

`supabase/migrations/20260909165823_classroom_atomic_entries.sql`은 검토용이며 아직 운영 적용하지 않았다. 2026-09-10 운영 프로젝트에 `BEGIN READ ONLY … ROLLBACK`으로 집계만 확인했다: 수업 루트 1개, 중복 팀 key 0개, 중복 날짜 노트 0개, 신규 RPC 미설치. 개인 본문은 읽거나 수정하지 않았다. 적용 직전 동일 사전 검사를 다시 해야 한다. 유일성 인덱스는 중복이면 적용을 중단하며 기존 공유 링크를 자동 변경하지 않는다.

```sql
select processed_json #>> '{metadata,team,key}' as team_key, count(*)
from public.reading_materials
where processed_json #>> '{metadata,team,root}' = 'true'
group by 1 having count(*) > 1;
```

운영 DB는 CLAUDE.md의 오너 적용 규칙에 따라 별도 승인 후 처리한다. RPC가 없을 때 원문은 기기 대기열에 남고 서버 저장이 준비 중임을 표시한다. 이를 정상 운영 완료로 보고하지 않는다. 기존 고정 뷰어 프리뷰를 이번 클래스 프리뷰로 교체하지 않는다. Merge/force-push 없음.

### 검증 한계

브라우저 기능 검수는 합성 교사·수업 및 격리 DB를 썼다. 실제 운영 수업에 입력하거나 AI 분석을 요청하지 않았다. PGlite는 단일 연결에서 실행하므로 서로 다른 운영 PostgreSQL 연결의 lock timing을 실측한 근거는 아니다. 물리 iPhone/iPad Safari, 교실 네트워크의 실시간 지연, 실제 학습자의 로그인·사본 저장 왕복은 후속 검수다. 서버 저장 확인과 채널 연결 상태를 구분하며 태블릿의 화면 표시 수신 확인을 보장하지 않는다.

### 운영 적용 순서

1. 오너가 위 SQL의 운영 적용을 승인한다. 적용 직전 migration 이력·팀 key/날짜 중복을 다시 확인한다.
2. 신규 함수와 인덱스만 적용하고 권한·소유자 거부 조건 및 기존 원문/metadata 보존을 확인한다. 임의 기존 데이터 정리 없음.
3. 승인된 실제 검수 수업에서 폰 입력 → 서버 노트 → 큰 화면 → 수업 노트 뷰어 왕복을 확인한다. 모바일 물리 기기 결과는 별도로 기록한다.
4. Claude 검토·병합 창구로 운영 웹 반영을 진행한다. Codex는 merge·force-push하지 않는다.

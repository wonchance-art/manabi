## 원고와 의미 검토

정본은 `scripts/textbook/n5-written-practice.json`이다. 각 문제에 고유 ID, 네 선택지,
정답 한 개, 정답 이유, 나머지 세 선택지의 오답 이유를 기록했다. 배열 문제는 네 조각의
전체 순서와 ★의 답을 함께 대조했다. 자동 검사는 이 근거의 무결성을 확인하며 의미의
자연스러움이나 모든 대안 어순의 불가능성을 스스로 증명하지 않는다.

- 장음: コーヒー의 두 장음, ノート의 장음 위치, ケーキ의 장음과 끝 글자를 구별한다.
- 작은 ッ: コップ·ベッド·ポケット은 기존 권말 단어 노트에 있는 말이다. 초반 과에서
  이미 배웠다고 가정하지 않고 접힌 단어 준비와 해당 카드 링크를 제공한다.
- 비슷한 글자: シャツ·パン·パソコン은 기존 원고/단어 노트의 표기로 고정한다.
  シ/ツ·ソ/ン과 탁점/반탁점을 섞어 보되, 각 오답에서 달라진 위치를 설명한다.
- 배열: `この`와 `ください`, `います`, `ねる`와 `あらいます` 등 문장 바깥의 고정 부분까지
  포함해 해설의 완성 문장과 맞췄다. 名前·書いて는 독음 도움을 함께 제시한다.
- 글 속 문법: 서점에서 책을 보고 요리책을 산 어제, 그 책을 읽는 지금, 요리를 만들고
  싶은 내일을 구분한다. そこ/その와 과거형/たい를 연결어 이외의 문맥 연습으로 다룬다.
  문제의 단서는 의도된 발판이며 실전 모의고사와 동일한 난도라고 주장하지 않는다.

가타카나 선택 문제의 부재는 이번 9문항으로 보강된다. 다만 공식 유형 전체의 독립 문제량,
상황 다양성, 난도와 어휘 충분성은 여전히 별도 검토 대상이다. 청해 4유형은 계속 보류한다.
공식 유형 비교 기준과 원문 링크는 `n5-coverage-copy-20260925.md`에 보존한다. 이전 판본에
고정된 감사 기록을 새 판본의 전범위 인증으로 바꾸지 않는다. 공식 문제 본문을 복제하지 않았다.

## 보존 계약

- 기준 bundle/세 자산 SHA-256을 확인하고 새로운 불변 판본에만 출력한다.
- 기존 42과 내용·정답·선택지·문항 ID·625어휘·125문형·103한자는 그대로다.
- 기존 494페이지의 ID와 상대 순서를 유지한다. 5페이지를 끼워 넣어 화면 쪽 번호만 갱신한다.
- 기존 입력 키와 출처 ID 1,142개를 유지한다. 새 입력 키 15개와 42과 출처 2개만 추가한다.
- 새 원고를 지웠을 때 기준 원고와 동일해야 한다. 옛 섹션은 지정한 진입 링크와 쪽 번호
  이외에 바꾸지 않았는지 계약 검사한다.
- HTML의 판본 표식·자체 JS/CSS 링크와 JS의 페이지 목록을 새 후보로 맞춘다.
  기존 서체·음성 147개·미디어 경로는 상속하며 CSS와 나머지 런타임은 그대로다.
- 전역 복습/개인 기록/DB/발행 포인터는 변경하지 않는다. 답안은 기존 방식대로 판본별
  브라우저 저장이며 이전 판본의 답을 새 문제에 임의로 옮기지 않는다.

## 검수 중 탐색 안정화

WebKit에서 이전 후보의 함께 읽기 화면을 자동 prefetch하다가 취소 오류가 기록됐다.
교재 내부 앵커는 그대로 두고 BookReader의 외부 화면 Link 5개와 초기 책 홈 BookHome의 같은 목적지 Link 2개만 클릭 시 불러오도록
지정한다. 발행본의 실제 클릭 이동·복귀와 읽는 동안 자동 요청 0을 제품 빌드에서 확인한다.
인증·발행·읽기 저장 계약은 바꾸지 않는다.

## 검토와 판단

41개 기본 읽기의 본문·질문·답·해설, 별도 구조인 39과 안내 읽기,
42과의 단문·중문·정보 검색 3지문/4질문을 작성자가 대조했다.
다른 형식의 39과를 읽기가 없는 과로 집계하지 않는다. 독립 일본어 감수는 아니다.

| 읽는 목적 | 검토한 과 | 판단 |
|---|---|---|
| 소개·친구·물건 주인 구별 | 1–5 | 초반 반복은 단어·조사 발판 역할이므로 유지 |
| 위치·존재·특징 찾기 | 7–9, 12, 33 | 9과는 방 그림과 함께 판단; 33과 지시어 보완 |
| 가격·수량·기본 정보 비교 | 6, 11, 13, 15–16, 40 | 일본어의 대상·수량을 읽어야 답할 수 있음 |
| 약속·시각·장소 연결 | 10, 19, 22, 35 | 시작/종료, 만날 곳/목적지, 제안/확정 구별 유지 |
| 행동·순서·허락·필요·부탁 | 17–18, 23–28, 31, 38–39, 41–42 | 39과의 먹기 금지/반입 금지 구분을 유지 |
| 희망하는 행동 | 21 | 오늘과 주말의 행동을 구별 |
| 대조·상태·경험·관계 | 14, 20, 29–30, 32, 34, 36–37 | 32과 たり를 시간 순서로 단정하지 않는 질문 유지 |

33과에서 원래 `ここで`는 방 전체 또는 창가를 가리킬 수 있었지만, 정답은 창가로
좁혀져 있었다. 마지막 문장을 `まどの ちかくで ゆっくり 本を 読みます。`로 바꾸어
학습자가 실제 지문에서 장소의 근거를 찾게 했다. 같은 지문에서 이미 나온 말만 재사용한다.

42과 짧은 메모는 기존 정답 ②를 유지하고 각 보기가 혼동한 인물·시간·행동을 설명한다.
정보 검색은 C가 세 조건을 모두 충족하는 이유와 A/B/D의 불일치를 각각 제시한다.
후속 질문은 금요일에 시간이 없어도 금요일보다 먼저 신청할 수 있음을 `までに`의
마감과 연결한다. 중문 문제는 기존 해설이 이미 네 보기의 근거를 다루므로 유지했다.

단문·일상 지문 이해와 안내의 필요한 정보 찾기는
[공식 N5 유형별 목적](https://www.jlpt.jp/e/guideline/pdf/n5_e_revised.pdf)의 구분을 참고했다
(2026-09-26 확인). 문항 수·지문 길이·검사 통과로 시험 전범위나 난도 적합성을 인증하지 않는다.

## 구현과 보존

정본은 `scripts/textbook/n5-reading-review.json`이다. 기존 `build-n5-copy-review.py`에
선택 원고와 편집 이력, 한 구절 교정 모드를 추가해 재사용한다. 한 구절 교정은 전체 원고의
전후 차이와 실제 HTML의 일치를 확인하고 주변 후리가나를 그대로 둔다. 이전 원고의
기본 실행 결과는 바꾸지 않는다. 새 후보만 자기 판본의 표식·JS/CSS 주소를 사용한다.

```sh
python3 scripts/textbook/build-n5-copy-review.py --plan scripts/textbook/n5-reading-review.json
```

499페이지 모델·42과·336개 구조화 문항(과 내부 315개 포함)·1,144개 출처 식별자, 모든 기존 정답·보기·입력 키·
페이지 순서·기존 판본 자산·공개 포인터를 보존한다. 새 문제는 추가하지 않았다.
계정 단어/SRS와 브라우저 교재 답안은 별개이며 이전 판본 답안을 새 판본으로 옮기지 않는다.

|---|---|
| 기존 원고 교정기·후리가나/예문/해설 렌더러 | 채택: 다섯 필드만 고치고 기존 판본을 재현 가능 |
| 기존 출처 추출·후보 무결성·합성 역할 검사 | 채택: 출처와 학습 기록 계약을 그대로 검증 |
| 외부 문제은행·새 UI 라이브러리 | 배제: 이번 결함은 문장과 해설의 근거 문제라 추가 의존성이 해결하지 못함 |

## 남는 과제

도서관·카페·모임 상황이 반복된다. 초반 어휘 재사용에는 장점이 있지만 독립 읽기 전이
검증은 부족하다. 새 지문을 추가한다면 기존 모임표를 반복하기보다 시간 변경 공지나
받은 메시지에 대한 행동 선택처럼 다른 읽는 목적을 먼저 정한다. 현재 범위의 개정과
독립 일본어 감수·실제 학습 효과·수업 역할 검수는 별도로 판단한다.

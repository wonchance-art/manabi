## 판단

생활 장면 → 설명·예문 → 대화 → 말하기·읽기 → 연결 연습의 방향은 유지한다.
공식 필기10유형에 대응하는 대표 문항은 있으나 **시험 대비 전범위가 완성됐다고 판단하지 않는다.**
표기 유형 중 가타카나 선택 연습이 부족하고, 유형별 독립 문제 수·상황 다양성·난도 검수가 남았다.
청해4유형은 이번 음성 제외 범위이며 텍스트 대화나 일부 기존 음성으로 완료 처리하지 않는다.

JLPT는 고정 어휘·한자·문법 출제 목록을 공개하지 않는다. 따라서 내부 항목 수나 유형 이름의
존재만으로 충분성을 계산하지 않는다. N5의 읽기·듣기 수준과 공개된 문제 목적을 기준으로,
원고의 실제 문항·정답·해설·도착 페이지를 연결했다.

## 재발 방지와 보존

- 이전 후보의 bundle 해시를 고정하고 정확한 원문과 일치할 때만 교정한다. 전체 문자열
  치환 대신 지정한 article 안에서 바꿔 동일한 히라가나 안내까지 변경하지 않는다.
- 새 불변 판본을 생성한다. 기존 판본 파일·발행 포인터·개인 기록·SRS·PDF·음성은 유지한다.
- 기록된 유형 근거의 문항 해시·문항 ID·화면 위치를 검증한다. 내용이 달라지면 재검토 없이
  기존 커버리지 판단을 재사용할 수 없다.
- 기존 결정적 패키저·출처 추출·실제 웹 검수기를 재사용했다. 새 외부 생성기·문제은행을
  도입하지 않았다. 공식 자료는 기준으로 부분 채택하고, 문제 원문 복제나 단어 수의
  전범위 인증 해석은 배제했다.

## 다음 우선순위

**가타카나 표기와 필기 취약 유형의 소규모 독립 연습**을 먼저 권한다. 현재 교재에서 가르친
말을 쓰되 정답이 유일하고 혼동 이유가 분명한 새 문제를 만든다. 기존 문항 ID는 유지하고
새 ID를 부여한다. 문자표에서 연습·해설로 왕복하고, 초반 과의 가벼운 분위기는 유지한다.
그다음 문장 배열·글 속 문법·서로 다른 독해 장면을 늘려 유형별 균형을 재평가한다.

완료 조건은 가타카나의 장음·촉음·유사 글자 구별, 문제별 선택지/해설 의미 감수, 본학습에서
가르친 말과 연결, 좁은 화면·답안 보존 확인이다. 문제 수 목표만으로 완성 판정을 하지 않는다.
독립 일본어 감수는 별도 필요하다. 청해·PDF는 사용자가 다시 진행하도록 정하기 전까지 제외한다.

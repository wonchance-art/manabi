2026-09-25 KST. 기존 발행본 `7f572327dc67893e9453246c`에서 만든 별도 웹 개정 후보
`e44cd7230ef94ff7f6293e2d`. 부모 #1321의 뷰어 작업과 분리한다.

42과는 새 문법과 누적 회상, 읽기 유형을 한 번의 20–25분 학습처럼 안내하고 있었다.

학습 내용을 덜어내지 않고 단계와 마침점을 만든다. 시간 측정 근거가 없으므로 새 시간
숫자를 붙이지 않고, 무엇을 할 수 있게 되면 쉬어 가는지 제시한다.

## 학습자가 지나가는 순서

```text
책 홈 → 과의 장면 → 공부 순서 → 표현/예문 → 대화/내 문장
                              ↓                  ↓
                         단계별로 바로 이동      여기서 쉬기
                                                 ↓
                                        누적 회상 / 읽기
                                                 ↓
                         막힌 표현 다시 보기 ← 답과 근거 확인
                              ↓
                         앞 과 → 뒤로 가기 → 하던 복습
```

| 과 | 단계 | 다시 볼 곳 |
| --- | --- | --- |
| 20 | 이동 표현·조사 / 대화·길 안내 | 19과 행동 장소, 타고 내리는 조사 |
| 23 | 이동 목적 / 앞 과 누적 회상 | 위치, 취향, 권유, 장소·도구, 이동 |
| 35 | 이유 연결 / 몸 상태·연락 | 30과 보통체, 26과 상태, 연결 카드 |
| 42 | 새 표현 / 모임 준비 회상 / 글자·문장 / 메모·이야기·안내 | 수량, 동시 행동, 제안, 연결어, 안내 |

42과 유형 7은 ‘가게가 작지만 조용해서 좋다’ 대신 ‘늘 사람이 많지만 오늘은 아무도 없다’로
대비의 근거를 명확히 했다. 덧붙이기로도 읽힐 수 있던 `それから` 보기를 `だから`로 바꾸고
왜 이유–결과가 아닌지도 설명한다. 정답 `② でも`, 문항 ID와 저장 키는 같다.
다른 예문·문형·한자·원고 본문은 유지한다. 어휘/문형/한자 개수로 JLPT 전범위 충족을
인증하지 않는다. 듣기·독립 감수는 이번 개정의 완료 주장에 포함하지 않는다.

## 보존과 제작

`scripts/textbook/n5-study-routes.json`이 개정 내용이며 `build-n5-study-routes.py`가 제작기다.
검수된 원본 bundle 해시를 고정하고, 원본 HTML의 표현·ruby·예문 박스·입력 키를 재사용한다.
변경하는 것은 명시한 경로/마침점, 35과의 표현 순서, 유형 7 한 문항뿐이다.
기존 원본 제작 도구는 PDF까지 다시 만들고 현 후보 포인터도 덮어쓰므로 이번 웹 개정에는
그대로 실행하지 않았다. 이 제작기는 저장소 파일만으로 재현되며 개인 다운로드 파일에 의존하지 않는다.

```sh
python3 scripts/textbook/build-n5-study-routes.py
python3 scripts/textbook/build-n5-study-routes.py --out /tmp/n5-verify

```

- 기존 489개 페이지 ID + 경로 4개 = 493개 출판 모델 항목. **새 PDF 493쪽을 제작했다는 의미가 아니다.**
- 기존 모든 출처 앵커와 답안 키를 유지한다. 학습 진도/답안은 기존대로 판본별로 분리한다.
  이전 진도를 새 판본 완료로 자동 변환하지 않는다. 이미 담은 표현은 예전 판본을 계속 가리킨다.
- 바뀌지 않은 약 80MB의 서체·기존 음성은 원본 판본의 검증된 자산 주소를 참조한다.
  새 bundle에 중복 복사하지 않는다. 원본 판본을 향후 배포에서 제거하면 안 된다.

  미발행 후보는 명시적 `?edition=...`와 기존 관리자 게이트로만 연다.

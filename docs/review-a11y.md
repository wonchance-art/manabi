## 반영한 수리

### 교재와 챕터

- [LessonsPage.jsx](../src/views/LessonsPage.jsx)에서 레벨 토글과 문형/어휘 링크를 형제 인터랙션으로 분리했다. 토글은 `aria-expanded`와 제어 대상 목록을 알리고, 사전·챕터 이동은 실제 `Link`를 쓴다.
- 언어·레벨 필터에 이름 있는 `group`과 `aria-pressed`를 추가했다.
- [index.css](../src/index.css)의 챕터 행 `outline: none`을 제거했다. 실제 렌더에서 수정 전 행 외곽선은 `none 3px`, 수정 후 네이티브 링크 포커스 링은 `solid 2px`였다.
- 수정 전 접근성 트리에서 접힌 레벨 버튼마다 내부 링크가 최대 1개 중첩됐고, 수정 후 모든 레벨 헤더의 중첩 인터랙션은 0개다.
- [ChapterDrills.jsx](../src/components/ChapterDrills.jsx) 입력을 보이는 문제 문장과 연결하고, 조립 문장·채점·완주·복습 큐 안내를 polite 상태로 공지한다.
- [WritingPractice.jsx](../src/components/WritingPractice.jsx) 작문 입력을 섹션 제목·프롬프트와 연결하고 모범답 영역의 펼침 상태와 점검 완료를 알린다.

실제 챕터 접근성 트리에서 수정 전 채우기 입력 이름은 `정답 입력`, 작문 입력 이름은 자리표시자 전체였다. 수정 후에는 각각 `Je ___ coréen.`, `Ils ___ médecins.`, 그리고 작문 섹션 제목+실제 프롬프트가 이름으로 노출된다.

### 어휘와 복습

- [VocabList.jsx](../src/views/VocabList.jsx)에서 클릭 가능한 행 역할을 제거하고 단어 상세/선택 전용 버튼과 듣기·편집·삭제 버튼을 독립시켰다. 검색 이름, 필터 그룹, 선택 상태, 아이콘 버튼 이름도 추가했다.
- [VocabPage.jsx](../src/views/VocabPage.jsx)의 로그아웃 화면 제목을 H1으로 바로잡았다. 덱 필터와 수동 추가 언어 선택은 현재 선택을 알린다.
- 단어 추가·편집·상세 모달은 이름 있는 `dialog`, `aria-modal`, 레이블 연결, 첫 포커스, Tab 순환, Escape 닫기, 닫힌 뒤 원래 포커스 복귀를 제공한다.
- [VocabDetailCard.jsx](../src/views/VocabDetailCard.jsx)의 닫기·발음 아이콘에 이름을 붙이고 기억 강도·학습 기간 막대를 `progressbar` 값으로 노출했다.
- [VocabReview.jsx](../src/views/VocabReview.jsx)와 [GrammarReviewSession.jsx](../src/views/GrammarReviewSession.jsx)에 모드 선택 상태, 문제 진행, 공개 답안, 채점 결과와 저장 상태 공지를 추가했다.
- [LandingPage.jsx](../src/views/LandingPage.jsx)의 게스트 로그인 권유는 `로그인 안내` 보조 영역으로 묶었다. 링크는 그대로 키보드 초점을 받고, 로그인은 권유일 뿐 교재·드릴·작문 접근을 막지 않는다.

## 실제 렌더 증거

### 키보드·의미 구조

- 랜딩 첫 Tab 대상 `교재`: `rgb(192, 82, 42) solid 2px`, offset 2px.
- `/lessons` 챕터 행: 수정 후 태그 `A`, 실제 `href`, 동일한 2px 포커스 링.
- `/lessons` 활성 프랑스어 칩: `aria-pressed=true`; 나머지 언어 칩은 `false`.
- 랜딩 전체 접근성 트리: `main` 안에 H1 1개, 언어별 링크 4개, `complementary "로그인 안내"`, 로그인 링크 순으로 노출.
- `/vocab` 로그아웃 화면: H1 `복습`, `문법 복습 이어가기`, `로그인하고 단어장 쓰기` 링크가 모두 노출.
- `/review/grammar` 로그아웃 화면: H1 `문법 복습`과 로그인 링크가 노출.
- 앱 레이아웃 경로에는 `본문으로 건너뛰기`, 이름 있는 주 내비게이션, `main#main-content`가 존재한다.

### 대비 — 시각 변경 승인 필요

다크 토큰 `--text-muted: #8A7055`의 계산 대비는 다음과 같다.

- `#1A1410` 기본 배경: **3.934:1**
- `#231C15` 보조 배경: **3.628:1**

작은 일반 텍스트의 4.5:1 기준에 미달한다. 시각 위계가 바뀌므로 이번 PR에서는 색을 바꾸지 않는다. 승인 시 후보 `#A08A72`는 가장 어두운 카드 배경 `#2D2318`에서도 약 **4.67:1**을 확보한다. 모든 테마·상태에서 재측정한 뒤 토큰 단위로 적용하는 것을 제안한다.

### 44px 타깃 — 시각 변경 승인 필요

프로젝트의 44px 계약보다 작은 실제 타깃 표본이다.

- 랜딩: 상단 텍스트 링크 26.5×23, 로그인 63.3×32.5, 본문 로그인 링크 38×16, 푸터 링크 높이 21.8.
- 교재: 필터 칩 높이 35, 사전 칩 높이 24.4, 챕터 행 높이 43.5.
- 챕터: 발음 버튼 40×40, 입력·확인 높이 32.5, 순서 토큰 높이 35.6, 선택지 높이 43.6.
- 단어장 CSS: 듣기 30×30, 편집/삭제 28×28, 상세 닫기/듣기 28×28.
- `/home` 보고 전용: GNB 조작 36–38.4 높이, `로그인하러 가기` 43 높이.

승인 시 조밀한 목록은 레이아웃을 키우는 대신 가상 타깃(의사 요소) 또는 행 전체 44px 확보를 우선 검토하고, 독립 아이콘·입력·칩은 `min-width/min-height: 44px`로 통일한다. 모바일 줄바꿈과 정보 밀도를 함께 재검증해야 한다.

## `/home` 보고 전용

로그아웃 `/home`은 접근성 트리에서 `H2 로그인 필요합니다`만 있고 페이지 H1이 없다. 또한 상단 아이콘 36×36과 로그인 링크 높이 43이 44px 계약에 못 미친다. 방향 갱신의 `/home` 수정 금지를 지켜 코드 변경은 하지 않았다. 후속 승인 시 H1 승격과 타깃 확대를 별도 소유자 작업으로 처리한다.

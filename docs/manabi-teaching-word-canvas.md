# 여러 표현과 필기를 함께 쓰는 설명판

2026-09-15. 오너가 승인한 2026-09-14 설계의 구현. 기준 main `663288eba51310413e7e28107aac02e4cbd37044`.

## 수업 동선

1. 교재에서 단어를 누르면 기존 뜻 창에서 발음과 뜻을 확인한다. 수업 화면에서는 독음은 위, 글자별 훈음은 아래, 단어 전체 뜻은 오른쪽에 표시한다.
2. **판에 놓기**로 현재 설명판에 더한다. 이미 놓은 단어와 필기는 그대로 유지한다.
3. 교재 밖 표현은 **＋ → 표현 입력 → 사전 찾기**에서 찾는다. 현재 교재·내 단어·최근 판의 일치 항목, 공통 사전, AI 설명 순으로 확인한다. 여러 뜻이 나오면 선생이 수업에 맞는 뜻을 선택하거나 직접 고친다.
4. **계속 추가**를 켜면 한 표현을 놓은 뒤 다음 표현을 바로 입력한다. 필요한 경우 놓기 전에 크게 볼 수도 있다.
5. 선택 도구로 여러 표현을 고른 뒤 가로/세로 정렬, 표시 설정, 여백 줄이기 또는 기존 묶기 기능을 사용한다. 필기와 단어는 동일한 Excalidraw 장면에서 움직이고 되돌릴 수 있다.
6. 학생에게 복습 항목으로 전달할 때만 **수업에 남기기**를 누른다. 상단 기록 아이콘의 **오늘 표현 N**을 누르면 화면 안에서 기존 수업 기록과 저장 대기·오류를 확인한다.

## 표현 조판

- 신규 항목은 **글자만**이 기본이다. 투명한 네이티브 앵커가 의미·출처를 보존하므로 테두리를 지워도 단어로 취급된다. **카드**로 배경과 테두리를 다시 켤 수 있다.
- 중국어 병음과 일본어 후리가나를 표시한다. 일본어 숙자훈을 한자별로 임의 분해하지 않는다. 정렬이 불확실한 독음은 표현 전체 위에 배치한다.
- 훈음은 저장소의 기존 한자 데이터로만 만든다. 찾을 수 없는 글자에는 임의 훈음을 생성하지 않는다. 영어·프랑스어에는 독음·훈음을 달지 않는다.
- 뜻은 오른쪽에 두고 긴 뜻은 줄바꿈한다. 병음/후리가나, 훈음, 뜻을 독립적으로 켜고 끌 수 있다.
- 표시를 끄는 동작은 필기 주변의 좌표를 움직이지 않는다. **여백 줄이기**는 내용 크기에 맞추고 구판의 큰 카드 여백을 줄이되, 다시 켤 독음·훈음의 공간은 보존한다.
- 새 항목은 시점을 강제로 이동시키지 않는다. 넓어진 판은 전체 보기로 맞추고, 필요한 위치로 직접 옮긴다.
- 네이티브 글자 수정 후에는 원래 교재 출처를 분리하고 오래된 독음을 제거한다. 뜻은 선생이 확인·수정한다.

## 보관과 권한

| 기록 | 저장 시점 | 용도 |
|---|---|---|
| 설명판 요소·필기 | 기존 기기 보관/복구 흐름 | 선생의 수업 판 |
| 오늘 표현 | 명시적인 수업에 남기기 | 학생 수업 전후 복습 |
| 개인 단어·복습 일정 | 기존 개인 저장 동작 | 개인 학습 |
| 교재 주의점 | 기존 교재 주의점 동작 | 다음 회차에도 다시 보는 교재 설명 |

동일 표현·동일 뜻·동일 출처는 중복 저장을 막는다. 같은 표현의 다른 뜻은 별도 항목으로 남길 수 있다. 이전 과에서 가져온 표현도 원래 자료를 현재 계정 권한으로 읽어 출처를 검증한다. 조회만으로 사전·개인 단어장·학생 기록을 수정하지 않는다.

기존 권한 검사와 원자적 수업 저장 RPC, 실패 큐를 사용한다. 저장 요청/대기/확인 필요를 서버 저장 완료와 구분한다. DB·RLS·환경 변수 변경은 없다.

## 호환성과 구현

기존 Excalidraw 0.18.1을 계속 사용한다. 새로운 그리기 라이브러리나 런타임 의존성은 추가하지 않았다. `TeachingWord` 미리보기와 `wordCardSkeleton` 캔버스 요소가 `teachingWordLayout`의 좌표 모델을 공유한다. 다중 표시 변경은 표현의 뜻·출처를 덮어쓰지 않는다.

기존 문서 버전과 저장 요소는 자동 변환하지 않는다. 신규 표현에만 `layoutVersion: 2`를 부여한다. 구판을 명시적으로 여백 줄이기 할 때만 변환한다. 발표의 가리기 설정은 임시이며 저장 장면을 바꾸지 않는다.

`POST /api/classroom/lookup`은 로그인·입력 길이·조회 횟수를 검사한다. 공통 사전을 읽은 뒤 실패/누락 시 기존 AI 제공자 체계를 이용한다. 입력은 인용된 데이터로 전달하며 전체 표현의 뜻을 요청한다. 조회 중 선생이 입력을 수정하면 늦게 도착한 결과를 적용하지 않는다. 실패하면 원래 입력을 유지하고 직접 입력할 수 있다. AI 출처는 조회 미리보기와 판의 표현 메타데이터에 남긴다.

이번 범위에는 필기 OCR, 실시간 학생 화면 동기화, 새로운 시험 기능, PDF 조판, 신규 음성 제작이 포함되지 않는다. 실제 iPad/Pencil의 필압·손바닥 접촉은 별도 기기 검수가 필요하다.

# 지난 설명판 페이지 재사용

2026-09-16 KST · 오너 다음 작업 승인 · #1317 계정 저장 기반 2차

현재 수업의 전체 메뉴 → 지난 설명판 → 날짜 옆 가져오기 → 페이지 미리보기/선택 → 현재 수업에 복사. 날짜 자체를 누르면 기존의 지난 수업 열기도 유지한다. 목적지는 시스템의 오늘이 아니라 교사가 현재 연 수업 날짜이며 선택 화면에 두 날짜를 표시한다.

복사는 새 페이지로 추가하고 첫 복사 페이지를 연다. 기존 판의 좌표와 필기를 움직이지 않는다. 페이지 전체의 표현·필기·화살표를 함께 다루며, 표현과 주변 필기의 부분 선택 복사는 후속이다. 학생 수업 기록은 기존 ‘수업에 남기기’로 명시적으로 저장한다.

## 보존과 실패 처리

- 기존 계정/기기 저장, private 다운로드, 교사 소유권 검사와 revision 충돌 보호를 재사용한다. 새 API·DB·Storage·환경 변수 없음.
- 원본 페이지는 쓰지 않는다. 대상 판은 삽입 순간의 최신 캔버스를 먼저 보관한다.
- 페이지·요소·묶음 ID를 새로 발급하고 boundElements/containerId/frameId/화살표 시작·끝 연결을 재매핑한다. 삭제 요소를 복원하지 않고 끊긴 연결은 제거한다. 교재 표현의 materialId/quote/anchor는 보존한다. 출처 접근·수업 기록 권한은 기존 서버에서 계속 검증한다.
- 가져온 페이지에 원본 board/day/page/revision을 보관한다. 저장/새로고침 후에도 동일 판본 중복을 막고, 수정된 새 판본은 다시 가져올 수 있다. 이 메타데이터는 설명용이며 권한을 부여하지 않는다.
- 페이지 20개/총 6MiB 한도를 삽입 전에 검증한다. 넘치면 부분 삽입 없이 선택을 줄이도록 안내한다. 소스 다운로드 실패는 재시도, 패널을 닫은 후 늦은 응답은 폐기한다.
- 알려진 계정 저장 충돌이 있으면 복사를 막고 기존 복구 동선으로 안내한다. 복사 뒤 계정 저장 실패는 기존 초안/저장 상태에서 복구한다.

## 부품 선택

| 부품 | 판단 | 이유 |
|---|---|---|
| 이미 채택한 Excalidraw 0.18.1 MIT | 부분 재사용 | exportToBlob의 실제 조판으로 420px 미리보기, 기존 편집 엔진 유지 |
| Excalidraw 내부 복제 함수 | 직접 의존하지 않음 | 설치된 공개 index.d.ts에 복제 함수 export 없음. 필요한 관계 재매핑만 작은 순수 모델로 검사 |
| 기존 계정 페이지 저장·원자적 revision | 재사용 | 새 저장소나 복제용 RPC 없이 현재 판에 추가 가능 |
| 새 템플릿 관리/협업 엔진 | 제외 | 날짜별 페이지 재사용에 필요 없음 |

페이지 미리보기는 가시 영역에서만 생성하고 메모리 Blob URL을 닫을 때 해제한다. 텍스트 요약을 같이 제공하며 이미지 실패로 복사를 차단하지 않는다. 색상/간격은 기존 판 토큰·작은 팝오버, 날짜 목록 복귀 포커스와 키보드 체크를 유지한다.

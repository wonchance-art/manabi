# manabi 수업 흐름 통합 설계

2026-09-12 · 오너 승인 후 구현. 독립 팀 홈, 교재 우선 진입, 교사 전용 공통 편집을 적용한다. 검수와 배포 상태는 `docs/verification/classroom-unified-20260912.md`를 따른다. 아래는 구현에 사용한 설계와 수락 기준이다.

## 1. 판단

선생님의 기본 활동은 교재를 펼쳐 수업하는 것이다. 현재는 수업 홈, 입력 중심의 수업 진행, 교재 뷰어, 함께 보는 화면, 날짜별 노트를 사용자가 직접 연결해야 한다. 기능이 늘어난 만큼 주 화면과 기본 행동을 정리해야 한다.

실제 확인한 기존 미리보기의 `/class/[team]/live?day=YYYY-MM-DD`는 1과가 선택돼 있어도 교재를 표시하지 않는다. 오늘 교재 선택, 본문 열기, 별도의 함께 보는 화면 링크, 표현 입력창이 각각 존재한다. 최신 구현에는 뷰어 안 수업 패널이 있지만 이중 입구와 역할별 명칭은 여전히 통합 대상이다.

권장 구조는 **팀 홈 → 교재 중심 수업 공간 → 같은 공간에서 마무리 확인**이다. 학생은 같은 팀의 **교재 / 수업 기록**만 알면 된다.

## 2. 팀 홈: 시작할 곳을 하나로

- 팀을 고른 뒤의 팀 홈은 독립된 수업 페이지다. 팀 선택 화면으로 가는 뒤로가기, 목록 경로 표시, 팀 전환 드롭다운을 상시 두지 않는다. 일반 브라우저의 뒤로가기는 가로채지 않는다.
- 상단의 명확한 `홈` 버튼은 웹앱 `/home`으로 이동한다. 팀 안의 이동은 팀 이름을 사용해 구분한다. 웹앱 홈으로 가기 전에 팀 선택 화면을 거치지 않는다.
- 팀 이름과 언어가 페이지의 주 제목이다. manabi 브랜드는 유지하고 언어 색상은 포인트로 쓴다. 큰 장식 표지로 교재와 시작 행동을 아래로 밀지 않는다.
- 선생님에게 가장 강한 행동은 `수업 시작` 또는 `수업 이어하기` 하나다.
- 현재 팀, 수업 날짜, 시작할 교재·과를 짧게 보여준다. 지난 수업 위치에서 시작하되 수업 시작 전에 바꿀 수 있다.
- 아래에 `교재 / 수업 기록` 두 영역을 둔다. 학생에게는 이 두 영역이 기본이다.
- 학생 초대와 수업 설정은 해당 팀의 보조 메뉴에 둔다. 팀 이름·교재·암호 변경도 이 팀 페이지의 설정 패널에서 끝내며 `/class`로 보내지 않는다. 학생에게 소유자 관리 기능은 나타나지 않는다. 전체 화면 입력판·발표판·노트 뷰어를 동급 카드로 나열하지 않는다.
- 최초 교재 미연결 상태에는 `교재 연결`을 우선한다. 교재 없이 수업을 하는 경우에는 같은 수업 공간의 표현 입력을 사용한다.
- 수업 시작은 작업 공간을 여는 행동이다. 빈 날짜 노트 생성, 학생 알림 발송, 공유 권한 변경을 동반하지 않는다.
- 팀 홈에서 특정 과를 누르는 것과 시작 버튼을 누르는 것은 같은 교재 중심 수업 공간으로 연결된다. 선생님이 어떤 입구로 열었는지에 따라 수업 도구가 사라지지 않는다.

## 3. 수업 공간: 뷰어를 본체로

교재 본문을 기본으로 보여주고, 기존 뷰어의 학습 기능을 재사용한다.

### 화면 구성

- 상단: 팀 홈으로 연결되는 팀 이름, 웹앱으로 가는 `홈`, 고정된 수업 날짜, 교재·과 선택, `마무리`와 보조 메뉴. 팀 목록으로 보내는 경로를 수업 진행 동선에 넣지 않는다.
- 중앙: 교재 본문. 수업용 공통 내비게이션은 간결하게 줄여 본문 공간을 확보한다.
- 도구 영역: 단어를 누르면 뜻 확인, `표현 찾기`를 누르면 직접 입력. 두 진입 방식은 같은 상세 영역을 사용한다.
- `오늘 배운 표현`은 개수와 최근 항목만 작게 표시하고 필요할 때 같은 공간의 패널로 펼친다.
- 교재에 붙인 설명은 해당 위치에서 확인하고 추가한다. 오늘 배운 표현 목록과 섞지 않는다.

### 기기별 구성

- 넓은 화면·태블릿 가로: 본문과 보조 패널. 패널을 닫으면 본문이 넓어진다.
- 태블릿 세로·휴대전화: 하나의 하단 패널. 단어 상세와 오늘 표현 목록이 겹쳐 뜨지 않고 같은 패널의 내용이 전환된다.
- 입력기가 나타나면 현재 입력과 뜻, 주동작을 우선하며 교재 위치와 선택을 유지한다.
- 확대 화면을 닫으면 원래 본문 위치, 선택, 초점으로 돌아간다. 본문 위에 패널과 팝업이 연속 중첩되지 않게 한다.

## 4. 표현 하나의 동작을 통일

교재 단어 선택, 여러 단어 드래그, 직접 입력 모두 다음의 동일한 상세 화면으로 모인다.

1. 표기, 독음, 핵심 뜻을 확인한다.
2. 필요하면 수업용 뜻을 수정한다. 원문·개인 단어 뜻을 자동으로 덮지 않는다.
3. 주요 행동은 `크게 보기`와 `오늘 표현에 추가` 두 가지다.
4. 설명을 마치고 돌아오면 교재가 그대로 남는다.

`기록만 하기 / 보여주고 기록 / 수업 노트에 추가 / 추가 ↑`처럼 입력 경로마다 다른 이름을 통일한다. 한 번 추가한 항목은 추가됨 상태를 보여준다. 의도적인 반복 추가는 보조 동작으로 유지한다.

크게 보기에서 필요한 경우에도 동일한 `오늘 표현에 추가`를 사용한다. 확대와 저장을 강제로 묶지 않는다. 단순 조회·발표는 학생 기록이나 개인 복습을 생성하지 않는다.

뜻 조회 실패·미등록이면 해당 패널에서 직접 입력할 수 있다. 로딩 동안 이전 단어 뜻을 새 단어의 뜻처럼 보이지 않게 한다.

## 5. 저장 목적은 유지하고, 행동할 자리로 구분

| 사용자 행동 | 저장 대상 | 학생에게 보이는 위치 |
|---|---|---|
| 오늘 표현에 추가 | 팀·날짜별 수업 표현 | 수업 기록 |
| 교재에 설명 남기기 | 교재의 특정 부분에 붙는 공통 설명 | 해당 교재 위치 |
| 기존 개인 단어 저장 | 해당 계정의 개인 단어·복습 | 자신의 단어장 |

추가할 때마다 위 세 가지 중 하나를 고르는 팝업을 띄우지 않는다. 동작이 필요한 문맥에 각각 배치한다.

- 교재 설명: 해당 부분의 작은 표시와 `교재에 설명 남기기`. 다음 방문 재표시, 누적, 수정 이력, 보관·복원 유지. 교사 개인 메모로 오해하지 않도록 학생도 볼 수 있는 공통 설명임을 표시한다.
- 오늘 표현: 그날 복습할 내용만 명시적으로 추가. 교재 출처가 있으면 자동으로 연결하고 교재 밖 입력이면 그 사실을 표시한다.
- 개인 단어: 기존 네 등급 저장을 보존한다. 수업 기록과 시각적으로 구분하고 자동 채점·자동 저장하지 않는다.

## 6. 학생에게 보여주는 화면

`크게 보기`는 현재 선택한 표현을 같은 수업 공간 위에 확대한다. 원어·독음·뜻과 뜻 숨기기, 이전 화면 복귀가 중심이다. 계정·개인 단어 등급·작성 중 교재 설명은 발표 내용에 섞지 않는다.

기존 `함께 보는 화면`은 기본 진입에서 내리고 `다른 화면에서 열기`라는 보조 기능으로 묶는다. 한 기기로 진행하는 수업은 이를 알 필요가 없다.

기존 별도 판이 저장된 표현을 표시하는 동작은 유지한다. 저장하지 않은 표현의 기기 간 실시간 미러링이 이미 구현됐다고 가정하지 않는다. 향후 이 동작까지 통합하려면 발표 상태와 수업 기록의 동기화 규칙을 별도로 검증해야 한다. 이번 기본 흐름의 필수 기능으로 만들지 않는다.

## 7. 마무리: 저장 작업을 새로 만들지 않는 요약

`마무리`는 현재 화면에서 수업 범위와 저장된 표현을 확인하는 요약을 연다.

- 저장된 오늘 표현 확인·필요한 수정 경로 제공.
- 오늘 다룬 교재 범위 확인. 단순히 열어 본 과를 모두 진도로 확정하지 않는다.
- 전송 대기·실패가 있으면 해당 항목과 재시도 표시. 기기 대기를 서버 저장 완료처럼 표시하지 않는다.
- 닫으면 팀 홈으로 돌아가며 같은 날짜 수업을 다시 이어갈 수 있다.

별도의 공개·배포 버튼이나 필수 마감 단계를 만들지 않는다. 명시적으로 저장된 표현은 기존 권한에 따라 학생 수업 기록에 반영되며, 마무리를 누르지 않았다고 사라지지 않는다. 자정을 넘겨도 진행 중인 수업 날짜를 몰래 바꾸지 않는다.

## 8. 학생 경험

팀 링크 → 입장·필요한 로그인 → 팀 홈의 `교재 / 수업 기록`.

- 팀 선택 화면을 방문하지 않고 직접 공유 주소로 들어와도 완결된 페이지여야 한다. 로그인·암호 재입력 후 해당 팀과 열려던 교재·기록으로 복귀한다. 권한 확인 전에는 비공개 팀 내용을 표시하지 않는다.
- 선생님과 같은 팀 이름·교재·기록 구성을 사용한다. 주요 행동은 `이어 읽기`이며, 자기 읽기 기록이 없으면 시작할 과를 명확히 보여준다. 역할은 실제 권한으로 확인하고 교사/학생 화면 선택을 요구하지 않는다.
- 교재: 이어 읽기, 단어 뜻·독음 확인, 교재 공통 설명 확인, 개인 단어 저장.
- 수업 기록: 날짜별 다룬 범위와 표현, 검색, 교재 밖 표현 필터, 해당 교재 위치로 이동.
- 기록에서 교재를 보고 돌아오면 날짜·검색·필터·스크롤을 유지한다.
- 같은 계정은 기존 개인 사본을 재사용한다. 교사 원본과 학생 사본의 권한, 개인 수정 및 복습 일정은 유지한다.
- 학생의 읽기 위치, 선생님의 수업 진행 위치, 해당 날짜에 다룬 범위는 서로 대체하지 않는다.
- 교재 설명은 교재에 귀속돼 같은 교재를 사용하는 승인된 다른 수업에서도 재사용할 수 있다. 날짜별 수업 기록은 해당 팀에, 개인 단어는 해당 계정에 귀속된다. 팀 홈의 독립된 화면 구성을 위해 교재를 새로 복제하거나 권한을 넓히지 않는다.

## 9. 기존 기능의 위치 변경

| 기존 위치·명칭 | 개편 위치·명칭 |
|---|---|
| 입력 중심 수업 진행 | 교재 중심 수업 공간 |
| 본문 열기 | 수업 공간에서 처음부터 표시 |
| 별도 표현 입력판 | 교재 안 `표현 찾기`와 교재 없는 수업의 같은 입력 영역 |
| 함께 보는 화면 | 크게 보기 + 보조 기능 `다른 화면에서 열기` |
| 노트 읽기·수업 돌아보기 | `수업 기록`으로 명칭 통일 |
| 주의점 | 교재 위치에서 `교재 설명`으로 안내 |
| 날짜별 기록 상세 | 교재 공간의 오늘 표현 패널 및 팀 홈의 수업 기록 |
| 팀 홈의 `← 수업` | 제거. 웹앱 이동은 `홈` |
| `/class`로 이동하는 수업 설정 | 해당 팀 안의 설정 패널 |

기존 주소를 없애지 않는다. `/live`, `/viewer`, `/board`의 공유·복귀 주소를 호환하고 같은 교재 렌더러와 권한 검사를 재사용한다. 팀·날짜·선택·개인 복습 문맥을 잃는 일괄 리다이렉트를 피한다. 일반 서재 뷰어에 수업 도구가 상시 나타나지 않게 한다.

## 10. 구현 순서와 수락 기준

1. 수업 공간 통합: 시작 즉시 교재, 교재 안 입력, 같은 단어 상세와 버튼. 기존 입력판은 교재 없는 수업에서도 같은 도구를 사용.
2. 오늘 표현·교재 설명 정리: 패널 중첩 제거, 이름 통일, 저장 목적 표시, 실패·재시도 유지.
3. 팀 홈·마무리·학생 기록 정리: 시작 행동 하나, 두 영역, 범위·개인 진도 구분.

세 단계는 기능을 따로 발표하는 새 화면 세 벌이 아니라 하나의 통합 결과로 검수한다.

수락 기준:

- 교재가 정해진 팀에서 한 번의 시작 행동으로 본문에 도착한다.
- 팀 홈·수업 공간에서 팀 선택 화면으로 보내는 뒤로가기가 없다. `홈`은 웹앱 홈으로, 수업 공간의 팀 이름은 해당 팀 홈으로 이동한다.
- 교재 연결·수정, 팀 설정, 학생 초대를 해당 팀 안에서 끝낼 수 있다.
- 팀 홈의 과 목록으로 열어도 시작 버튼과 동일한 수업 도구와 팀·날짜가 유지된다.
- 팀 링크 직접 진입, 새로고침, 로그인 왕복에서 팀 목록 방문 없이 원래 목적지로 복귀한다.
- 교재 단어 선택→뜻→확대→복귀→기록에 페이지 이동이 없다.
- 교재 밖 표현 입력도 교재를 닫거나 다른 페이지를 열지 않는다.
- 입력 경로와 무관하게 같은 기록 버튼을 사용한다.
- 교재 설명은 다음 수업에도 나타나지만 날짜 기록에 자동으로 복제되지 않는다.
- 학생은 기록한 표현에서 자기 사본의 정확한 교재 위치로 이동한다.
- 실패·새로고침·과 이동·기기 회전 시 초안, 본문 위치, 날짜, 저장 상태가 정직하게 유지된다.
- 교사 태블릿 가로·세로, 휴대전화, 데스크톱과 별도 학생 계정을 검수한다.

시험, 출결, 성적표, PDF·음성 제작, 일반 서재 전체 split view는 이번 흐름 정리의 범위를 넓히지 않는다.

## 11. 추가 검토 결과: 구현 전 고정할 세부 동작

1. **이어하기의 기준:** 선생님은 팀의 지난 수업 위치, 학생은 자기 읽기 위치를 사용한다. 수업 범위는 별도 기록이다. 기록이 없을 때 `진행 중` 등 가짜 상태를 만들지 않는다.
2. **과거 기록을 여는 경우:** 과거 노트에서 교재로 갔다가 돌아오면 그 날짜·검색·위치로 돌아온다. 과거 기록을 읽는 행동만으로 오늘 수업 날짜나 진행 위치를 바꾸지 않는다. 기록을 추가할 때 대상 날짜를 분명히 표시한다.
3. **팀 홈 복귀:** 수업 공간에서 팀 이름을 누르면 해당 팀 홈으로 돌아간다. 표현 확대 닫기는 교재 복귀이며, 기록에서 들어온 교재의 복귀는 원래 기록이다. 화면마다 이 중 한 가지 주 복귀만 제공하고 팀 목록은 복귀 대상으로 사용하지 않는다.
4. **마무리의 의미:** 현재 데이터는 팀·날짜 단위다. 새 출석·세션 종료 모델을 만들거나 의무 종료 절차를 추가하지 않는다. 마무리는 저장·범위 확인용 선택 요약이며 같은 날짜에 다시 이어갈 수 있다.
5. **첫 사용·실패:** 교재가 없으면 그 팀 안에서 연결, 기록이 없으면 짧은 안내, 읽기 위치가 없으면 첫 과, 자료가 사라졌으면 같은 팀의 다른 과 선택을 제공한다. 조회 실패를 빈 교재로 처리하지 않는다.
6. **설정 영향:** 교재 연결이나 암호 변경은 해당 팀의 설정으로 표시한다. 기존 학생 재입장이 필요한 변경은 저장 전에 안내하되 매 수업 시작에 확인 절차를 넣지 않는다. 기존 공유 주소·원본·학생 사본·날짜 기록을 임의로 재생성하지 않는다.

이 세부 동작을 포함하면 다음 단계는 구현이다. 팀 홈에 공지·일정·출석·시험 등 새로운 독립 메뉴를 더할 필요는 없다.

# 교재 안 수업 학습 · 학생 사본 연결

2026-09-10, 오너가 승인한 교재 안 수업 도구 및 학생 사본 2A/2B 설계를 구현한다. #1299 뒤의 의존 작업이며 운영 merge는 Claude 창구다.

## 적용 내용

- 수업 교재를 열면 기존 텍스트 뷰어의 단어/문장 패널 안에서 뜻 확인, 수업용 뜻 수정, 수업 노트 추가를 끝낸다. 일본어 대응·상세 설명·개인 단어 저장 네 등급은 기존 기능을 사용한다.
- 넓은 화면은 본문과 350px 보조 패널, 작은 화면은 단일 하단 패널이다. 모바일의 교재 선택/검색은 펼칠 수 있고 표제어·뜻·추가 버튼을 우선한다. 선택한 본문이 패널 뒤에 있으면 필요한 만큼만 이동한다.
- 직접 입력 조회는 기존 사전만 사용한다. 미등록/실패 시 수동 뜻 입력을 제공한다. 단순 선택·조회는 수업 판과 개인 복습을 변경하지 않는다.
- 원문·뜻·읽기·출처·요청 ID를 한 트랜잭션으로 저장한다. 응답 유실 재시도, 동일 출처 중복 방지, 명시적 반복 추가를 구분한다. 영속 큐·기존 분석 CAS를 재사용하고 같은 원점의 수업 분석은 Web Locks로 조정한다.
- 학생은 실제로 여는 자료만 원자적으로 보관한다. 계정/원본별 대표 사본을 별도 테이블로 연결하며 과거 중복 행은 삭제하지 않고 선택한다. 조회 실패를 새 자료 생성으로 간주하지 않는다.
- 로그인만으로 기기 캐시 전체를 가져오던 효과를 제거했다. 명시적 로그인 저장 요청 하나를 IndexedDB에 보관하고 계정/탭에 묶어, 사본 확보 → 단어 → 문맥 → 선택 위치 복귀 순서로 처리한다. 문맥 실패 후에도 재시도할 수 있으며 기존 FSRS를 덮어쓰지 않는다.
- 새 수업 내용은 알림/뜻 변경 비교/명시적 반영으로 처리한다. 원문 편집·삭제·단어 분할 변경은 자동 합치기를 중단한다. 기존 토큰 ID·개인 교정·해설·대화문·판본/출처를 보존한다. 읽기 위치와 원본 분석 작업 상태는 공유하지 않는다.
- 비로그인 캐시는 timestamp만 믿지 않고 내용 지문으로 새 버전을 확인한다.

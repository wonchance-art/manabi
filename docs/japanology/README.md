## 수위 정책 검토 (1기 → 심층)

1기 정책: 종교는 관습·행사 층위만 / **특정 작품·작가·상호 무언급** / 전승·통설 헤지.

심층에서의 제안(오너 결정 대기):
- **문학·예술 도메인에 한해 '작가·작품 언급' 완화** — 학술 서술의 본질상 불가피. 단 (a) 퍼블릭 도메인
  (원문 기준) 확정 작가 우선, (b) 번역문은 번역자 저작권 별도이므로 원문+자체 해설로만, (c) 현대
  상업 IP(만화·애니 특정 작품)는 계속 무언급(산업 구조 층위만).
- **종교**: 교리 평가 배제 유지. 신화는 "문학·인류학 텍스트 + 학자 해석" 프레임으로 완화(religion-folklore.md §5).
- **근현대 정치·전쟁**: 사실 층위만, 평가·논쟁은 '학설 갈림' 분리 표기 유지.

## 심층 문서 로드맵 (기존 일본학 7문서의 후속)

각 테마 파일의 '목차 제안' 섹션이 5~8섹션 초안을 담고 있다. 편찬 우선순위 제안:
1. **식문화 심층**(jp-food-deep) — 자료 밀도 최고·기존 culture.js §3의 확장. 여행 결합 자연스러움.
2. **길과 도시로 읽는 일본사**(jp-history-roads) — 가도·조카마치·세계유산. 기존 역사 2편의 지역 축 보완.
3. **문학 기행**(jp-literature) — 아오조라 원문 연계 시 언어 트랙과 시너지(원문 읽기 자료화 가능성).
4. **예술 순례**(jp-art) — 퍼블릭 도메인 이미지 활용 여지(라이선스 표 art.md §5).
5. **신앙과 축제의 지리**(jp-folk) — 순례길·마쓰리. 수위 완화 결정 후.

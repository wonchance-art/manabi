## 1. 학술 문헌

### 한국어 번역·저술
- **《일본 미술사》**, 무토 마코토(武藤 誠) 저, 한국어 번역본 | 교보문고 등 주요 도서관
- **《일본 미술의 역사》** | 교보문고 등 주요 도서관
- **글로벌 세계 대백과사전 - 세계미술 / 동양미술의 흐름 / 일본의 미술**  
  https://ko.wikisource.org/wiki/글로벌_세계_대백과사전/세계미술/동양미술의_흐름/일본의_미술/일본의_근대·현대_미술  
  (공개 위키문헌)

### 주요 논점별 학술 자료
- **우키요에**: 17~20세기 에도 시대 풍속화 ⟶ 1765년 하루노부의 다색 목판화(니시키에) 완성 ⟶ 19세기 후반 자포니즘으로 인상파 영향
  - 참고: "우키요에가 19세기 후반 서양 미술사에 끼친 영향", KCI 학술지 논문
  - 우키요에 대가: 호쿠사이(《후지산 36경》), 히로시게(《도카이도 53차》)

- **일본화 유파의 전개**:
  - 야마토에(大和絵): 국풍 문화 시대 일본풍 회화, 도사파 계승
  - 린파(琳派): 17~18세기 소타쓰·고린파, 야마토에+중국 수묘화 융합
  - 가노파(狩野派): 15세기~메이지 시대 주류, 중국 영향+일본 병풍화
  - 가나자와 금박 문화와의 상호작용 주목

- **건축사**: 신사·사찰·성·민가·다실의 시대별 양식 변화
  - 일본식 나목 구조와 석조 요새의 발달 (특히 16세기 천수각 성형)

### 기본 참고서
- 나무위키 "우키요에", "일본 건축", "가부키", "노가쿠" 등 (개설적 정보)
- 위키백과 한국어판 "일본의 성", "신사(신토)", "일본 건축"

## 2. DB·컬렉션 및 공개 이미지 자료

### 일본 국립박물관 통합 DB
**ColBase (国立文化財機構所蔵品統合検索システム)**
- URL: https://colbase.nich.go.jp/?locale=en
- 범위: 도쿄국립박물관, 교토국립박물관, 나라국립박물관, 규슈국립박물관 + 2개 연구소
- 규모: 약 140,000점 (2024년 2월 기준)
- 라이선스: 출처명시 하에 상업/비상업 이용 자유
- 검색 가능 항목: 우키요에, 도자기, 칠기, 불교미술, 국보·중요문화재

### 개별 박물관 온라인 컬렉션
**도쿄국립박물관**
- 공식 웹사이트: https://www.tnm.jp/
- 120,000점 이상 소장 (국보 89점, 중요문화재 648점)
- 우키요에·도자·칠기 대규모 컬렉션

**교토국립박물관**
- 공식 웹사이트: https://www.kyohaku.go.jp/ko/
- 소장품 데이터베이스: 9,000점 이상 기본정보+이미지
- 사찰 건축, 정원, 전통공예 특화

### 고해상 디지털 아카이브
**e국보 (National Treasures Image Database)**
- URL: https://emuseum.nich.go.jp/top?langId=ko
- 범위: 도쿄·교토·나라·규슈 국립박물관 + 나라문화재연구소의 국보·중요문화재
- 제공: 고정밀 이미지 + 다언어 해설(일본어, 영어, 중국어, 한국어)
- 유의: 사적 이용 범위만 무제한 허용 / 재사용은 각 박물관 이용창구 문의 필요
- 모바일 앱 'e국보' (iOS, Android)

### 일본 문화유산 온라인 (공개DB)
**文化遺産オンライン (Cultural Heritage Online)**
- URL: https://online.bunka.go.jp/
- 범위: 1,094개 참여 기관, 308,257개 공개 작품
- 특징: "Time Machine Navi" (시대·지역별 검색), UNESCO 세계유산, 무형문화재 동영상 포함
- 주요 작품: 호쿠사이의《후지산 36경》, 불교조각, 장식미술

### 해외 미술관 퍼블릭도메인 컬렉션
**메트로폴리탄 미술관 (The Metropolitan Museum of Art)**
- URL: https://www.metmuseum.org/ko/art/collection
- 공개: 375,000여 점의 미술품 사진을 CC0 퍼블릭 도메인으로 공개 (2017년 2월 이후)
- 일본 미술 포함 우키요에·도자·칠기 다수 소장
- 라이선스: 저작권 제약 없음, 학습·앱 활용 모두 가능

**시카고 미술관**
- 우키요에 및 일본 목판화 컬렉션 보유
- (구체적 공개 라이선스 확인 필요)

## 3. 지역 예술 지도 (현장 학습 기초)

### 가나자와 (金沢)
**금박 공예의 중심지**
- 일본 금박 생산량 99% 점유율
- 전래: 1593년 (근원은 교토 킨카쿠지 문화)
- 방문처: 가나자와 시립 야스에 금박공예관 (安江金箔工芸館)
  - 금박 붙이기 체험 프로그램 (단시간, 저가)
  - 히가시챠야가이 거리 근처

**가나자와 칠기 (금沢漆器)**
- 17세기 초 도입 (마에다 가(家)가 교토에서 명공 초빙)
- 특징: 금·은가루, 조개껍질 장식 / 화려한 번주용품·미술공예품
- 학술: 도사파 회화와의 장식성 공통점

**관광기반**: 공식 가이드 https://visitkanazawa.jp/kr/crafts

### 교토 (京都)
**전통 공연과 건축의 집약**
- 주요 사찰: 기요미즈데라(목조 건축), 킨카쿠지, 닌나지, 고다이지
- 세계문화유산: 고대 교토의 역사 기념물 다수

**다실 건축**
- 쇼렌인(聖論院) 내 고분테이(好文亭): 고사쿠라마치 천황 서재 ⟶ 후대 다실 개조
- 무로마치 시대 쇼인즈쿠리와 다실의 결합
- 다도 4대 원칙: 조화(和)·존중(敬)·청정(清)·평안(寂)

**전통 공연**
- 가부키: 유네스코 세계무형유산 / 모든 시대에 새로운 표현 지속 창출
- 노(能): 가면무극, 별도 전용극장(노가쿠도) / 전문배우 노가쿠시

### 나오시마 (直島)
**현대미술 재개발 사례**
- 베네세 아트 사이트 프로젝트 (1989년~, 베네세 그룹)
- 주요 건축가: 안도 타다오 (안도 건축의 지하·자연 통합 미학)
- 주요 시설:
  - 베네세하우스 뮤지엄 (1992년)
  - 지중미술관 (2004년): 모네, 제임스 터렐, 월터 드 마리아 등
  - 이우환미술관 (2010년)
  - 발레 갤러리 (2022년): 쿠사마 야요이 등
- 연간 방문객: 50만 명 (이전 폐허섬 ⟶ 세계 예술성지)
- 지리적 유의: 도쿠시마 현 보류

### 도자 산지 (陶芸の里)
**일본 6대 고요지 (육고요·롯코요)**
1. **세토 (瀬戸야き)**: 가마쿠라 시대 중국 기술 전래, 가도 가게마사 시작
2. **도코나메 (常滑やき)**: 헤이안 시대 말기부터 존속 / 최오래·최대 산지
3. **에치젠 (越前やき)**
4. **시가라키 (信楽やき)**
5. **단바 (丹波やき)**
6. **비젠 (備前やき)**

**근현대 도자 거점**
- **마시코 (益子)**: 도자 공예촌, 현대 도예가 집중
- **아리타 (有田)**: 이삼평(조선인 도공) → 백자 발견 → 일본 자기의 시조
  - 히젠번(佐賀현) 중심, 2017년 일본 유산 선정

**학술 참고**: 모모야마 시대 다도 세나 리큐의 영향 (비젠·시가라키·이가·탄바·가라쓰 등)

## 4. 목차 제안 (5~8섹션)

### 총 8섹션 구성
1. **일본 미술의 통사 개요**  
   선사~현대 / 중국 영향과 야마토에의 형성 / 에도 시대 대중미술 발흥

2. **회화의 전개: 유파와 기법**  
   야마토에 → 가노파 → 린파 → 우키요에 → 근현대 일본화 / 유파별 특징·계승 방식·재정의

3. **우키요에: 목판화의 예술과 산업**  
   탄생(무로마치)·확대(에도)·완성(니시키에 1765)·해외 영향(자포니즘) / 호쿠사이·히로시게 대가 / 배우·풍경·풍속의 주제별 분석

4. **건축: 신사·사찰·성·민가·다실**  
   신사의 구조(도리이·본전·배전)와 토속 신앙 / 사찰 건축과 선종 영향 / 성의 진화(환호집락→천수각) / 다실과 다도의 정신성 / 민가의 헤이안·가마쿠라 변화

5. **정원 미학: 枯山水와 地泉回遊式**  
   가레산스이의 선종 철학(돌·모래·이끼) vs 지천회유식의 귀족적 쾌락 / 뮤로마치 시대 발달 / 교토·교토 사찰 사례

6. **공예의 계층성과 지역성**  
   도자기 6대 고요지의 역사 / 칠기와 금박의 가나자와 전통 / 직물(유젠·오미·조자쿠) / 발전 계기로서 모모야마 다도 문화

7. **전통 공연예술: 能·歌舞伎·文樂**  
   산악(散樂) 기원 → 능의 가면무극·엘리트성 vs 가부키의 대중성·혁신 / 분라쿠의 인형극과 조루리 음악 / 유네스코 무형유산 등재

8. **근현대 일본 예술의 변화**  
   메이지 일본화의 수용과 저항 / 양화 도입 vs 일본화 재평가 / 나오시마식 현대 재개발의 새로운 모델

## 5. 이미지 라이선스 & 주의점

### 라이선스 함정 및 권리 관계
**박물관 소장품 이미지의 혼재된 권리**
- ✅ **퍼블릭도메인 자유 사용**:
  - 메트로폴리탄 미술관의 CC0 공개 컬렉션 (375,000점)
  - ColBase의 출처명시 이용 자유
  - e국보의 다운로드 이미지 (단, 재사용 시 각 박물관 문의)

- ⚠️ **조건부 사용**:
  - e국보: 교육·학습용 개인 이용만 무제한 허용 / 상업 재출판은 각 박물관과 별도 협의 필수
  - 문化遺産オンライン: 개별 기관별로 라이선스 상이 / 확인 필수
  - 도쿄·교토 국립박물관 소장 작품: 전시 이미지는 각 박물관 이용허가 필요

- ❌ **확인 필수**:
  - 17~19세기 목판화 (저작권 소멸 여부는 국가별 상이)
  - 근현대 미술가 작품 (상속인의 저작권 유존 가능)
  - 개인 소장 또는 사찰 개인 관리 문화재

### 학습 앱 활용의 법적 근거
- **CC0 또는 Public Domain 명시 작품**: 자유로운 변형·디지털화·학습 앱 삽입 가능
- **각 박물관 이용약관 재확인 권장**: 메타데이터에 라이선스 태그 필수 기록
- **한국 저작권법**: 인용·편의수집 목적의 복제는 허용되나, 원본 인정 및 출처 명시 의무

### 유파·기법의 통설 vs 학설 충돌 예시
1. **린파의 계승 방식**: 통설(직접 사승 계승)과 달리 "천재적 개인의 간접 계승"이라는 학설 충돌  
   → 고린, 호이쓰 등의 시간차·지역 분산 재검토 필요

2. **가노파의 "일본화" 정의**: 중국 수묘화 기법 vs 대형 병풍 장식화의 일본 토착화  
   → 메이지 근대 일본화 개념과의 연속성 논쟁

3. **우키요에 분류**: 육필화(회화) vs 목판화(판화)의 범주 논쟁  
   → 니시키에 발명 이전 단색 목판화(가라쓰에) 포함 여부

4. **다실의 "정신성"**: 다도의 선종 철학(사코쿠 미나야마 해석) vs 무사계급 실리적 도구화(가타모리 설)

### 출처 명시의 권장 방식
```
[작품명]. [시대]. 목판화. [박물관명] 소장.  
이미지: ColBase / e国保 / The Metropolitan Museum of Art.  
라이선스: CC0 Public Domain / 개인 학습용 / 출처명시 자유 이용  
(한국어 앱 인용 시 이 정보 메타데이터에 포함)
```

# 일본 종교·민속 학술 자료집 (한국 학습자용)

## 1. 문헌 — 민속학 고전 및 학술 저작

### 야나기타 구니오 (柳田國男, 1875–1962)
- **주요 저작**: 『도노모노가타리』(遠野物語, 1910)
  - 일본 민속학의 기초 문헌
  - 산촌 생활의 민간전승·요괴·신앙 기록
  - 퍼블릭 도메인 상태: 1910년 출판이므로 일부 국가에서는 PD이나, 현행 저작권 여부는 출판권 보유처에 따라 확인 필요
  - 무료 접근: 일본 국회도서관 디지털 컬렉션(NDIC), 프로젝트 구텐베르크 일본 컬렉션, 한국 도서관 등에서 일부 공개

- **저작 성격**: 야나기타는 일본 민속학의 창시자로, 관습사·생활문화·구전 전승을 중심으로 연구
  - 다른 주요 저작: 『일본 민간전설기(日本民間伝説記)』, 『마을의 신앙(村の信仰)』
  
### 모토오리 노리나가 (本居宣長, 1730–1801)
- **신토 사상가**
  - 『고사기전(古事記伝)』: 고대 신화 텍스트 해석
  - 신토에서 불교·유교 색채 제거, 일본 고대 원형 복원 시도
  - 영향: 국학(국학파 철학) 운동의 중심 인물
  - 제자 500명 이상, 존왕 운동·근대 국가신토 수립에 영향

### 일본 불교사 주요 저작 (서지)
- **정토종 역사**: 호넨(法然, 1133–1212) 『선택본원념불집』, 신란(親鸞, 1173–1262) 『교행신증문류』
- **진언종**: 구카이(弘法大師空海, 774–835) 『즉신성불의』
- **임제종 (禅)**: 에사이(榮西, 1141–1215) 『興禅護国論』

**논문·근대 학술지**:
- 박규태: "일본 불교의 성지와 순례 문화 연구" (서울대학교 학위논문)
  - URL: [박규태_완.pdf](https://s-space.snu.ac.kr/bitstream/10371/139594/1/3.%20%EB%B0%95%EA%B7%9C%ED%83%9C_%EC%99%84.pdf)
- "일본불교의 영장(靈場)과 성지순례문화 연구 -근대의 종교상황에 이르기까지-"
  - 종교연구 제52권, 한국종교학회 (2008)
- 박수철: "신사(神社)와 '야오요로즈가미'(八百万神)의 나라 일본"
  - 서울대 S-Space: [박수철.pdf](https://s-space.snu.ac.kr/bitstream/10371/139598/1/7.%20%EB%B0%95%EC%88%98%EC%B2%B2.pdf)

**공식 자료**: https://www.jinja.jp/ (일본어, 신도 교리·제도 설명)
**한국어 정보**: 제한적 — 위키백과, 문화관광청 정보 활용 권장

## 3. 지역 민속 및 성지·순례 지도

### 도노 (遠野) — 岩手県
- **특징**: 야나기타 구니오 『도노모노가타리』의 배경지
- **민속**: 산촌 요괴 전승, 민간 신앙, 무속 관습 (마을 무녀·점쟁이)
- **현황**: 도노 문화유산 센터, 도노 관광 협회 자료 제공
- **학술 가치**: 일본 민속학 실증 연구의 모태

### 이즈모 (出雲) — 島根県
- **신화**: 오오쿠니누시(大國主大神) 신화의 중심지
  - 국양 신화: 오오쿠니누시가 국을 양도하고 이즈모타이샤에 좌정
  - 신들의 회합: 음력 10월(신월), 전국 800만 신들이 모인다는 전설
- **신사**: 이즈모대사(出雲大社) — 신토의 중요 사원
- **제도**: 신불습합 전통 — 신사와 불사가 인접, 융합된 지역 신앙
- **문화**: 연중 제사(마쓰리)의 학술 기록

### 고야산 (高野山) — 和歌山県
- **종파**: 진언종(眞言宗) 밀교의 본산
- **개창**: 헤이안 시대(819년경) 구카이(弘法大師)
- **구조**: 117개 사원, 약 50% 슈쿠보(宿坊, 순례자 숙박시설) 운영
- **순례 문화**: 
  - 시코쿠 88개소 순례(헨로) 완료 후 고야산 참배가 전통
  - 고야산 단계별 밀교 수행 체험 가능
- **학술 의의**: 불교 성지 순례 문화의 완성형

### 히에이산 (比叡山) — 滋賀県
- **종파**: 천태종(天台宗) 총본산
- **개창**: 헤이안 초기(788년경) 사이초(最澄)
- **특징**: 밀교화된 천태 신앙, 불도수행과 순례의 복합 구조
- **순례**: 고야산과 함께 일본 불교 2대 성지

### 시코쿠 88개소 헨로 (四国八十八ヶ所) — 전 4개현
**경로 및 의미** (1,400km):
1. 도쿠시마현 (1–23번): "발심(發心)" — 신앙 각성
2. 고치현 (24–39번): "수행(修行)" — 정진
3. 에히메현 (40–65번): "보살(菩薩)" — 깨달음 추구
4. 카가와현 (66–88번): "열반(涅槃)" — 완성

**역사**:
- 12세기 처음 등장
- 16–17세기 88개소 체계 확립
- 가마쿠라 이후 대중화, 현재 가장 발전된 순례

**문화 요소**:
- "오셋다이(接待)": 순례자에게 공양하는 전통
- 백의 수행복(백의순례), 지팡이, 순례 수첩

**학술 자료**:
- 카가와현 관광청: https://www.my-kagawa.jp/ko/sightseeing/sightseeing05
- 시코쿠 헨로 공식 가이드: https://shikoku-guide.com/ko/about_shikoku/pilgrimage/

### 도호쿠 3대 여름 마쓰리
1. **센다이 다나바타 마쓰리** (마이 7월 / 그레고력력 8월, 센다이市)
   - 유래: 중국 칠석 전설 + 일본 풍농 기원 절기 결합
   - 대나무에 단자쿠(소원 종이) 매달기
   
2. **아오모리 네부타 마쓰리** (8월 초, 아오모리現)
   - 거대 인형 행렬
   - 국가 지정 중요 무형 민속 문화재

3. **아키타 간토 마쓰리** (8월 초, 아키타現)
   - 긴 대나무(간토)에 유등(종이 행등) 무수히 달기
   - 국가 지정 중요 무형 민속 문화재

## 4. 자료집 목차 제안 (5–8섹션)

### 제안 구성

1. **신토의 제도·관습사 층위**
   - 신사(神社)의 구조와 제사(마쓰리)
   - 야오요로즈가미(八百万神) — 다신숭배 체계
   - 신불습합(神佛習合) — 신토·불교 융합
   - 신사참배 의례, 부적(오마모리), 연년행사

2. **일본 불교 체계 및 순례 전통**
   - 주요 종파 개관: 정토종, 정토진종, 진언종, 임제종(선)
   - 성지 순례 문화: 고야산, 히에이산, 시코쿠 88개소 헨로
   - 불교와 신토의 공존 방식

3. **민간전승·요괴·민속학**
   - 야나기타 구니오와 도노 민속 조사 방법론
   - 요괴의 발생·변화·현대화 과정
   - 민간 신앙과 마을 공동체 의례

4. **연중행사·절기·마쓰리**
   - 오절구(五節句): 새정월, 복날, 다나바타, 칠석, 중양절
   - 다나바타 마쓰리 (센다이, 아오모리, 아키타)
   - 오봉(お盆) — 추석 유사 조상 제사
   - 신사 마쓰리의 계절성

5. **지역 신화·신앙**
   - 이즈모 신화권: 오오쿠니누시와 국양 서사
   - 도호쿠 및 산촌 로컬 신앙 다양성
   - 산신(山の神), 물의 신, 집의 신 등 미시적 신앙

6. **공개 학술 자료 및 DB 활용법**
   - Nichibunken 데이터베이스 검색 방법
   - 국립역사민속박물관, 신사본청 공식 자료 접근
   - 대학 논문 데이터베이스 (KCI, S-Space)

7. **여행·체험·학습 결합 포인트**
   - 도노·이즈모·고야산·시코쿠 방문 시 학습 가이드
   - 마쓰리 시즌 및 관찰 포인트
   - 신사·절 참배 실제 예절 및 문화적 의미

## 5. 주의점 및 수위 조정안

### 기존 1기 수위 정책 (관습·행사 층위만)
> 종교는 교리 평가·신앙 우월성 논의 배제, 관습·제도·행사의 역사·인류학적 층위에서만 기술

### 심층 자료집에서 **지킬 선** (엄격)
- ✓ 신토·불교의 **교리적 내용** 제시 금지 (예: 신의 속성, 구원론, 윤리)
- ✓ "이것이 참된 신앙"이라는 평가 배제
- ✓ 역사적 분쟁·정치화 (예: 국가신토 이념화, 근현대 종교 국가화) 시 **사실만**, 평가·정당화 금지
- ✓ 민감 지역·신앙 (예: 위안부 관련 신사, 야스쿠니 신사 등) 불필요시 논외로 두기

### **완화 가능한 선** (유연)
- ✓ **신화적 내용**: 문학·인류학 텍스트로 제시 가능
  - 예: "오오쿠니누시 신화는 야마토 왕권의 지방 통합 과정을 기록한 것으로 해석된다"
  - 학자의 해석·가설 형태로만 제시
  
- ✓ **제도·의례 설명**: 관습사로 깊이 있게 기술 가능
  - 예: "신사 마쓰리는 농촌 공동체의 결속 갱신 의례로 기능하며, 봄·여름·가을 절기별로 분화"
  - 기능·의미를 사회학·민속학으로 분석

- ✓ **순례 문화**: 종교사적 배경과 현대적 활용 병기
  - 예: "고야산 순례는 헤이안 밀교 신앙의 전승이면서 동시에 현대 관광·명상 복합 체험"

- ✓ **요괴·민간전승**: 문화콘텐츠·문학 연구로 적극 활용
  - 학술 해석 (젠더, 사회 불안, 해석 변화 추적)
  - 고전→근대→현대의 대중화 궤적 기술

- ✓ **역사 배경**: 왕권·통일·국가 형성 과정으로 제시
  - 신불습합, 지방 신앙의 다층성 인정
  - 종파 분화와 대중화 과정 (사회경제적 배경)

### **주의 체크리스트**

| 항목 | 허용 | 금지 |
|------|------|------|
| 신화 텍스트 인용 | ✓ 학자 해석 함께 | ✗ "진실"로 제시 |
| 제사·의례 설명 | ✓ 구체적 절차·의미 | ✗ 신성성 강조 |
| 신토 교리 | ✗ 원문 최소 | ✓ "근대 국가 이념화" 역사적 기술 |
| 불교 종파 | ✓ 종파 특성·역사 | ✗ 우월성 비교 |
| 순례·성지 | ✓ 문화유산·관광 결합 | ✗ 영적 효험 단언 |
| 민속·요괴 | ✓ 적극 활용 | ✗ 미신 폄하 |

### **아우팅 시 고려**
- 학습자가 한국인: "일본 문화 이해"라는 인류학적·여행학적 프레임 유지
- 신토·불교는 "종교"가 아닌 "생활 문화", "제도", "예술 전통"으로 재구성
- 지역학·건축·음식·축제와의 연계로 **통합 이해** 유도

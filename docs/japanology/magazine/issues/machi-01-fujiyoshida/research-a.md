## 3. 「이 글만의 관찰」 후보를 뒷받침/반박하는 사실

후보: 같은 길이 한 시대에는 산으로 오르는 순례자의 길이었고, 지금은 산을 「찍으러」 오는 사람의 길이다 — 길의 방향은 그대로, 바라보는 이유만 바뀌었다.

뒷받침
- A02: 1572년 새 마을은 처음부터 「富士山に向かって南方に延びる街路」를 축으로 설계됐다 → 길의 방향(산을 향함)은 성립 때부터.
- A16·A17: 富士道가 下吉田에서 남쪽으로 꺾여 후지산으로 곧게 뻗음, 「富士に真向かう一直線の道」(현 山梨県 자료).
- A19: 富士講이 富士みち를 지나 吉田口로 입산 → 순례자의 길.
- A20·A36·A38: 町에서 이어지는 吉田口登山道가 산정으로 직선 — 길의 연장이 곧 등산로.
- A21·A68: 지금 本町通り는 SNS 촬영 스폿, 2017년경부터 주목(市 富士山課, 보도).
- A44: 신사 스스로 「본래는 기점 신사에 참배하고 등산」을 권함 — 「바라보는 이유」의 변화를 신사 측이 의식.
- A25: 실제로 講社를 맞는 御師는 5軒 → 순례의 길로서의 쓰임은 가늘어졌다.

반박·주의(쓰기 전에 반드시 반영)
- 축은 순례 전용이 아니었다: A03 — 중심가로는 甲府盆地와 駿河를 잇는 鎌倉道(鎌倉海道). 「순례자의 길」만으로 쓰면 과장. 「산을 향한 길이자 교역의 길」로.
- 장소 구분: 촬영 인파가 모이는 本町二丁目交差点는 下吉田(織物·商業 「俗なる町」, A17·A23) 쪽이고, 御師町은 金鳥居 남쪽 上吉田. 같은 富士道 위지만 같은 블록이 아님 — 「같은 길」이라 쓸 때 下吉田→金鳥居→上吉田의 연속으로 서술할 것.
- 「바라보는 이유만 바뀌었다」에 대해: 산을 「바라보는」 신앙(遙拝)은 원래부터 있었다(신사 由緒 「遥かに拝み祭祀を行う場」, sengenjinja.jp/yuisho·fuji). 신앙 쪽도 「보기」에서 「오르기(登拝)」로 바뀐 역사가 있음 — 대비를 단순화하지 말 것.
- 순례 자체가 끝난 것은 아님: A25(5軒 활동 중), A53(富士講이 지금도 火祭에 참여), A69·A70(2026년 吉田口 등산자 16만여 명, 기슭부터 걸어 오르는 사람 약2만 명).
- 관광객 서술은 수치·조치만(A66~A70). 보도(A68) 원문의 국적 언급은 표에 넣지 않았다(비방 맥락 회피).

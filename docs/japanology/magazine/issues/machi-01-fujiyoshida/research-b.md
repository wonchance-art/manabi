## 2. 감각 재료(첫 장면용)

- **직기 소리(擬音)**: 「ガチャっとするだけで1万円」(B32, 1次 観光庁DB) / 英文 "every clack of a loom's shuttle (gacha)"(B33) / 「ガチャッとひと織り」(B37, 2次) / 「機織機をガチャンと動かす」(B42, 2次). → 1次 표기는 「ガチャっと」. 「ガチャン」「ガシャン」은 2次 또는 미확인.
- **직기 회전**: ふじやま織は「ゆっくりとした回転数で時間をかけて織り上げる」(B14).
- **촉감(천)**: 甲斐絹「非常に軽く、平滑な薄手」「腰があり」「サラッとした風合い」(B15). 「見る角度により色が変わって見える」玉虫甲斐絹(B18). 一寸に緯糸200〜280本(B19).
- **물**: 염색에 「富士山の天然水」(B12)・「純度の高い湧き水」(B14)・「硬度の低い富士の天然水」(B41, 2次). 시 개요 「その中腹から流出する水が集まって桂川となり」(B73). 수掛麦「富士山の湧き水を利用」(B60). 신사 手水 「冷たい雪解け水」(B104, 2次).
- **우동 반죽의 단단함**: 「ビニール袋のまま足で踏んでこねる」(B52)・「力強く練るため、歯ごたえ、コシ」(B51)・「日本一硬い」とも言われる(B57). 「絹糸を触る手が荒れないように」(B50) — 손의 촉감.
- **빛·풍경**: 甲斐絹「独特の光沢」(B15). 金鳥居 「柱の間に」 富士山(B92)・「しめ縄との間に富士山が収まって」(B98). 本町通り 「富士山に続くように延びた」(B99).
- **온도·고도**: 年平均気温12.6℃(2018, B74). 「標高700〜900mほどの冷涼な気候」(B49).
- **바람**: 1차 원문에서 바람에 관한 구체 묘사는 찾지 못함. (サライ 기사 제목에 「富士山麓の風吹き抜ける」가 있으나 잡지 표제라 감각 재료로는 약함 — 2次)
- **시간의 리듬**: 우동집은 「お昼だけ営業」(B62). 絹屋町의 市 「毎月1と6のつく日」(B38, 2次). 공장 개방 「毎月第3土曜日」(B11).

## 3. 「이 글만의 관찰」(길의 방향은 그대로, 바라보는 이유만 바뀌었다) 관련 사실

- 뒷받침: 本町通り는 「富士山に続くように延びた」 길이며 지금은 「ＳＮＳで話題の富士山ビュースポット」(B99, 2次). 金鳥居는 「富士山頂に続く吉田口登山道の初めの門」, 「俗界と富士山の信仰世界とを分かつ「境界」」(fujiyoshida.net p=24, B97 동일 출처). 富士講은 昭和39年 スバルライン 개통 후 「急激に衰退」(B96, 1次) — 순례자의 길이 끊긴 시점의 근거.
- 뒷받침(같은 길의 시간 층): 金鳥居 1788 초건→1957 현 鳥居(B93). 第1回 ハタフェス 메인 회장이 本町通り(B34) — 같은 길이 직물의 축제 공간이기도 함.
- 주의/반박 소지: 本町通り(下吉田)와 金鳥居(上吉田)·御師町은 지번이 다르다(B97·B99). 「같은 길」이라고 쓰려면 本町通り→金鳥居→御師町→神社가 한 축이라는 1차 근거가 필요하다. 이번에 찾은 1차는 「富士山駅から北口本宮冨士浅間神社にかけてのエリアに集積」(B75)와 金鳥居市民公園〜神社 約2km(B95)까지다. 本町通り의 道路 축이 「富士山へまっすぐ」라는 県 자료(富士道 모델코스 PDF)는 글자 추출이 되지 않아 표에 넣지 않았다(5절). A 담당의 도로 축 사실과 맞춰야 한다.
- 「찍으러 오는 사람」: 1차 당국 수치나 조치는 이번 범위에서 찾지 못했다. 撮影 마나 호소는 2次(B100)뿐이다.

## 4. 異同

1. **甲斐絹의 기원 3설**: 南蛮貿易の「海気」(B25, 県・甲斐絹ミュージアム, 「といわれ」) / 徐福が伝えた(B31, 市あらまし, 「とされる」) / オランダ人の「近渡裂」を研究(B40, 観光ガイド2次). 본문에서는 단정하지 않는다.
2. **延喜式의 「布」**: 麻布だったようだ(B20, 甲斐絹ミュージアム) ↔ 税を絹で支払った(B35, 観光庁DB) ↔ 「甲斐（山梨）の国は布を納めること」(観光ガイド, 2次). 1次끼리 충돌한다. 「絹으로 세금」은 쓰지 않는 편이 안전하다.
3. **국산 넥타이 4할**: 「国産ネクタイ生地の4割で使用」(B06) ↔ 「国産ネクタイの4割はこの郡内地域で生産」(B07). 둘 다 県 자료.
4. **郡内地域 범위**: 5市町(上野原 포함, B01) ↔ 「富士吉田市、西桂町、都留市、大月市」 4市町(県 specialty/fabric.html). 県 甲斐絹 페이지는 「吉田市」로 표기(원문 그대로).
5. **우동 유래의 여성 역할**: 「織物の機械を動かす女性」(B50 うちの郷土料理) ↔ 「主に製糸を担っていた女性たち」(B58 伝統食図鑑). 같은 省 안에서도 다르다.
6. **우동 유래 시기**: 昭和初期(B50・B58) / 20世紀初め(B62 観光庁) / 江戸時代 富士講 참예객 상대(B59) / ガチャマン(戦後)期に有名に(観光ガイド, 2次).
7. **단정 강도**: うちの郷土料理 「といわれる」「という」 / 伝統食図鑑 「とされる」「という」. 인용할 때 어미를 그대로 둔다.
8. **표고**: 市街地 652〜850m(B69 市あらまし) / 概ね650〜850m(B73) / 富士吉田市 標高700〜900mほど(B49 MAFF).
9. **우동집 수**: 約50軒(B61, 観光庁 R1=令和元年度) / 60店舗(B66, 県観光ネット, 시기 불명) / 40店舗 2026年現在(B63, 2次). 「今」은 40店舗(2次)뿐이므로 본문에서는 수치를 빼거나 「数十軒」으로.
10. **甲斐絹 전성기**: 「明治時代に…最盛期」(B03) ↔ 「江戸末期から昭和初期にかけて…全国に知られていました」(B45 리플릿). 모순은 아니지만 범위가 다르다.
11. **Met 연대**: 표시 "ca. 1830–32" ↔ objectBeginDate 1820 / objectEndDate 1842(B86). 표기는 표시값을 쓴다.
12. **御坂의 소재**: 「現在の山梨県笛吹市に位置する御坂（三坂）」(B87) ↔ 「御坂峠」(B89). 峠는 笛吹市와 富士河口湖町 경계에 있으나, 이를 확인한 1차 원문은 열지 못했다(5절).
13. **富士山駅 개칭 날짜**: 富士急 沿革은 「2011年」뿐이다(B77). 7월 1일은 2026-06-25 보도자료의 「本年7月1日に…15周年」에서 역산한 것이다(B78). 「2011年7月1日」을 직접 쓴 1차 원문은 보지 못했다.

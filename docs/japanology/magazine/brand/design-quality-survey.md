# 디자인 품질을 올리는 방법 — 최신 현황 조사 (2026-10-16 KST)

질문: 표지는 그럭저럭 되는데 브랜드 마크가 "폰트로 친 느낌"이다(BRUTUS·&Premium·Casa·POPEYE
대비). 에이전트 단독 레터링 실험(L1~L3)은 "훨씬 이상"했다. 무엇으로 품질을 올릴 수 있나.

조사 한계: 일부 1차 출처(help.figma.com·developers.figma.com·openfontlicense.org)는 컨테이너에서
열리지 않아 2차 출처에 기댔다. 아래에서 **(2차)**·**(미확인)**으로 표시한다. 제품 수치(문자
정확도 등)는 대부분 단일 블로그 테스트라 참고치로만 둔다.

## 1. Anthropic 쪽 디자인 기능

- **Claude Design (Anthropic Labs, 2026-04-17 공개, research preview)** — 프로토타입·슬라이드·
  원페이저를 만들고, 팀 디자인 시스템(색·타이포·컴포넌트)을 구축해 Canva/PDF/PPTX/HTML과
  Claude Code handoff로 내보낸다. **로고·레터링 제작에 대한 언급은 공식 발표에 없다.**
  표지 조판 보조로는 쓸 수 있지만 마스트헤드를 해결하지는 못한다.
  <https://www.anthropic.com/news/claude-design-anthropic-labs>
- **anthropics/skills** (상당수 Apache 2.0, canvas-design LICENSE 확인)
  - `canvas-design`: 디자인 철학 문서 작성 → 캔버스 PNG/PDF. 번들 폰트를 그대로 쓰고,
    커스텀 레터링 절차는 없다.
  - `frontend-design`: 타이포 위계, 'AI 티' 회피 목록. 표지 조판 규율에는 쓸모 있다.
  - `algorithmic-art`: 시드 기반 생성 패턴. 배경·텍스처에는 쓸 수 있지만 글자에는 못 쓴다.
  - `brand-guidelines`: Anthropic 자사 브랜드 전용이라 무관하다.
  - <https://github.com/anthropics/skills>
- 이 세션: Artifact **Design 타입**이 있다(계정에 디자인 시스템은 0). Vercel MCP에
  `import-claude-design-from-url`이 있다(Claude Design → v0).

## 2. Figma 생태계

- **Figma MCP 쓰기(2026-03 베타, 2차)**: 에이전트가 프레임·벡터·컴포넌트·변수를 직접
  만들고 고칠 수 있다. 향후 사용량 과금이 예고됐다.
  <https://www.scalekit.com/blog/figma-mcp-vs-api>
- 판단: 에이전트가 Figma에 벡터를 그려도 곡선 판단이 같으니 품질은 SVG 직접 작성과 다르지
  않다. 가치는 **사람이 Figma에서 손보고 → 에이전트가 읽어 빌드에 반영하는 왕복 루프**에 있다.
  이 세션의 Figma 커넥터는 **미인증**이라, 오너가 claude.ai 커넥터 설정에서 연결해야 쓸 수 있다.
- **Vectorize(2026-02)**: 스케치·PNG를 편집 가능한 벡터로 바꾼다. **손그림 레터링 스캔 →
  벡터** 경로로 유효하다.
  <https://forum.figma.com/product-updates-3/vectorize-images-in-design-and-draw-50595>
- Make·Buzz: 코드·마케팅 에셋 도구라 레터링과 무관하다. Draw 2026-05 업데이트는 미확인이다.

## 3. AI 벡터·이미지 생성기와 권리

| 도구 | 레터링 품질(참고치) | 권리·ToS |
|---|---|---|
| Recraft V4/V4.1 | 진짜 SVG 출력. 타이포는 면밀한 검수가 필요하다 | 상업 권리는 유료·API 한정 |
| gpt-image-2 | 일본어 정확도가 높다는 주장(단일 테스트) | 저작권 불명 |
| Nano Banana Pro | 일본어 약 10자 한계라는 보고(미검증) | 저작권 불명 |
| Midjourney V8 | 짧은 라틴 문구만 안정 | 저작권 불명 |
| Ideogram | CJK는 수동 보정 권장 | 소유권을 주장하지 않으나 무료 출력은 공개 <https://about.ideogram.ai/tos> |
| Kittl | — | Pro/Expert 플랜만 "exclusive ownership" |
| Firefly Text to Vector | — | 엔터프라이즈 면책 적용 범위는 미확인 |

어느 것도 **BRUTUS급 일본어 마스트헤드를 결정적으로 내놓는다는 근거는 없다.**

권리 정리:
- **미국**
  - 저작권청 Part 2 보고서(2025-01-29): 프롬프트만으로는 저작자가 아니다. 사람이 수정하거나
    배열한 부분만 보호된다.
    <https://ipwatchdog.com/2025/01/29/part-two-copyright-office-ai-report-says-creative-prompting-doesnt-constitute-authorship/>
  - Thaler v. Perlmutter: 2026-03-02 상고 불허로 인간 저작자 요건이 굳어졌다.
    <https://www.mayerbrown.com/en/insights/publications/2026/03/supreme-court-denies-review-in-ai-authorship-case>
- **일본**: 문화청 「AIと著作権に関する考え方について」(2024-03)는 창작 의도와 창작적 기여를
  종합해 판단한다.
- **반전 — 사람이 그린 로고타입도 일본에서는 대개 저작물성이 부정된다**(ゴナU 사건,
  最判 H12.9.7). 워드마크의 실질 보호 수단은 **상표 등록**이다.
- 따라서 AI 워드마크의 실제 위험은 "저작권 0"보다 **ToS 변동, 독점성 부재(유사 출력),
  학습 데이터 유사성, 출처를 설명할 수 없음**이다. "우리가 소유한다"는 원칙과 맞지 않는다.

## 4. 폰트·레터링 도구, OFL 베이스

- **Fontra**(GPL-3.0, 브라우저 기반, CJK 대형 폰트를 위해 출발): 컨테이너에서 서버를 띄우고
  오너가 브라우저로 곡선을 손보는 협업 루프가 이론상 가능하다(**실행 미검증**).
- **Glyphs 4**(2026, 맥 전용): 사람 디자이너용이다.
- Monotype·Google의 "AI 폰트 디자인" 제품은 확인된 출시가 없다.
- **OFL 베이스 변형**: OFL 조건과 RFN(예약 폰트명)은 **폰트 소프트웨어를 재배포할 때만**
  적용된다. 아웃라인을 변형한 로고 SVG에는 RFN 문제가 없다(OFL FAQ 요지, 2차). LINE Seed JP는
  OFL 1.1로 2026-01 Google Fonts에 공개됐다. 후보별 OFL.txt의 RFN 선언은 쓰기 전에 개별로
  확인한다.
- 한계: 폰트를 "살짝" 바꾼 로고는 오너가 지적한 "폰트로 친 느낌"을 벗어나기 어렵다. 베이스는
  골격으로만 쓰고 획을 실질적으로 다시 그려야 한다. 그 다시 그리는 손이 사람이어야 한다는 것이
  L1~L3의 결론이다.

## 5. 사람에게 의뢰 (일본·한국)

- 시세(2025-26)
  - 일본 로고타입: 3만~15만 엔. 개인 프리랜서는 1만~3만 엔부터, 제작사는 20만~30만 엔이다.
    <https://imitsu.jp/cost/design_office/article/logo>
  - ココナラ 손글씨 문자 로고: 1만~2만 엔 중심. 저작권 양도는 상위 플랜이나 옵션인 경우가 많다.
  - 크몽 텍스트 로고: 15만~45만 원. 원본 AI 파일과 저작권 이전이 상위 패키지에만 있는 경우가
    있다.
- 계약 체크리스트
  - 著作権譲渡(27·28조 명기)
  - 著作者人格権不行使
  - 벡터 원본과 미채택 시안의 처리
  - 독점성
  - **AI 不使用 표명보증**(조문 예시는 찾지 못했으므로 자체 작성)
  - 상표 출원 협력
  - <https://atsoho.com/blog/moral-rights-non-exercise-clause>

## 6. 에이전트 작업 방식의 근거

- 연구 결과
  - CyberAgent(SIGGRAPH Asia 2024): GPT의 정렬·겹침·여백 평가는 사람 평가와 꽤 상관이 있지만
    세부를 놓친다. <https://arxiv.org/abs/2410.08885>
  - AesEval-Bench(2026): 그래픽 미감 판정에서 최고 모델도 정확도가 약 0.73이다.
    <https://arxiv.org/html/2603.01083>
  - 사람 비평의 예측력이 LLM 단독 비평보다 높다는 UI 비평 연구가 있다.
- 함의: VLM 비평은 **규칙 위반 탐지(정렬·여백·겹침·위계)**에는 쓸 만하다. 레터링의 "멋"을
  판정하는 데는 믿을 수 없다. 우리 '비평가 역할' 라운드도 이 범위로 좁히는 게 맞다.
- 무드보드와 실물 크기 교정은 업계 관행이지만 정량 근거는 찾지 못했다. 타사 마스트헤드는
  **구조 분석용**으로만 참조하고 형태를 차용하지 않는다(정책 ⑴).

## 추천 경로

1. **마스트헤드는 사람에게 의뢰한다.** 에이전트가 준비할 것:
   - 브리프 패키지: となり/TONARI/トナリ의 역할, 사용 크기, 금지사항, 표지 실물 크기 목업.
   - 후보 3~5인의 포트폴리오 비교표.
   - 위 계약 체크리스트.
   - 예산은 2만~10만 엔으로 잡는다.
2. **에이전트는 납품 후 "정밀화와 시스템"을 맡는다.**
   - SVG 정규화(fontTools/skia-pathops).
   - 소형용·1색·반전 변형.
   - 표지 배치 규칙을 계약 테스트로 고정한다.
   - 실물 크기 PDF 교정.
   - VLM 비평은 규칙 체크리스트로만 쓴다.
3. **의뢰 전 임시안이 필요하면** OFL 골격 1종을 고른다(RFN 확인). 그 다음 둘 중 하나로 진행하고,
   결과를 에이전트가 결정적 빌드로 고정한다.
   - 오너가 Figma(인증 후)나 Fontra에서 몇 획을 직접 고친다.
   - 손그림 스캔을 Vectorize로 벡터화한다.

| 파일 | 내용 |
|---|---|
| `geom.py` | SVG(절대 M/L/C/Z + translate) → shapely. 베지어는 24점 고정 분할(결정적) |
| `measure.py` | 실측: 글자 사이 최소 틈·속공간·획 굵기(잉크 높이 H 대비 %) |

| `sheet.mjs` | 전/후·사용 크기·색·조합판 시트 → `v1/sheet.png` |

재생성(리포 루트): `python3 -I docs/japanology/magazine/brand/ai-gen/refine/build.py && node docs/japanology/magazine/brand/ai-gen/refine/sheet.mjs`

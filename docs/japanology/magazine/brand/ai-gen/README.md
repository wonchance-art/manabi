# ai-gen — AI 생성 브랜드 마크 접수 파이프라인

**경위**: 2026-10-16 KST 오너 질문 「요즘 이미지 생성기는 그걸 맡을 정도로 뛰어난가?」에 대한 답은 이랬다.
생성기는 형태 탐색(손맛)에 강하고 정밀도·국소 수정·벡터에는 약하다. 그래서 **생성기 탐색(오너) → Claude 정밀화**로 나눈다.
이어 오너가 「이어 받아서 작업할 수 있도록 하는 옵션까지 전부 고려해서 프롬프트 제안해줘」라고 요청해, 이 폴더를 되살리고
`PROMPTS.md` v2를 만들었다.

- 최종 마크 채택 여부는 아직 정하지 않았다. 생성물은 **후보 탐색 재료**다.
- 조사(`../design-quality-survey.md`)가 짚은 위험 4가지는 아래 **채택 전 점검**으로 관리한다.
  - 저작권이 불명이다.
  - 이용약관(ToS)이 바뀔 수 있다.
  - 독점성이 없다.
  - 기존 마크와 닮을 수 있다.

## 진행 순서 (오너 개정 2026-10-16 KST)
1. **`CONCEPT.md`** — 컨셉 브리프로 생성기에 잡지를 설명하고 자유롭게 넓게 뽑은 뒤 좁힌다(기본 경로).
2. **`PASTE.md` 2단계** — 고른 안의 정리판·패밀리 확장·글리프 시트·골격판을 받는다(이어받기).
3. `PASTE.md` 1단계(방향 A~F)와 `PROMPTS.md` §3은 틀을 정해 둔 탐색이다. 컨셉 탐색이 막힐 때만 보조로 쓴다.

## 분담
- **오너**: `PROMPTS.md`로 생성 → 고른 것만 `inbox/`에 넣는다 → `log.csv`에 한 줄씩 기록한다.
- **Claude**: 아래 순서로 처리한다.
  1. `intake.mjs`를 돌린다.
  2. 단색 벡터, 사용 크기, 표지 2종(라이브 표지 규격 검사 포함)을 비교 시트로 낸다.
  3. 고른 후보를 정밀화한다.
     - 노드를 줄이고 곡선을 다듬는다.
     - 글자 사이와 광학 중심을 맞춘다.
     - 소형용·1색·반전 변형을 만든다.
     - 결정적 빌드로 고정한다.

## 넣는 법
- 파일 이름은 `<역할>-<도구>-<안번호><판>.<png|jpg|webp|svg>` 형식이다. 판 = o 원본 · c 정리판 · g 글리프 시트 · s 골격판(`PROMPTS.md` §6). g·s는 표지에 앉히지 않고 추적만 한다.
  - 역할 = `TONARI` | `hira`(となり) | `kata`(トナリ)
  - 예: `TONARI-recraft-01.svg`, `hira-gptimage-03.png`
- 한 장에 마크 하나만 들어가야 하고, 평평한 바탕이어야 한다. 어두운 바탕은 자동으로 반전한다. 여러 개가 그려진 이미지는 잘라서 넣는다.
- 경로는 셋 중 하나를 쓴다.
  - GitHub 웹에서 이 브랜치의 `inbox/`에 업로드한다.
  - Google Drive 폴더를 알려 준다(Claude가 가져온다).
  - 대화창에 파일을 첨부한다.

## 돌리는 법(리포 루트, Node 24, Python + vtracer)
```
pip install vtracer        # MIT, 최초 1회
node docs/japanology/magazine/brand/ai-gen/intake.mjs [--base ippon-H1,danmen-H5]
```
- 결과는 `out/sheet.png`에 나온다. `out/`은 재생성물이라 커밋하지 않는다.
- 표지 바탕은 `prototype/cover-machi01/12-hip/covers/<base>.html`이다. 제호 자리만 바뀐다.
  - 제호 크기 상한: 폭 157.7mm, 높이는 바탕 체계의 제호 잉크 높이.
  - 가나 후보는 아래 줄을 TONARI로 바꾼다.
- 검사 항목
  - 제호 SVG가 글자 상자와 겹치지 않는지, 안전선 안에 있는지.
  - 나머지 글자에 대한 `check-cover.cjs` 결과.

## log.csv
| 칸 | 내용 |
|---|---|
| file | inbox 파일 이름 |
| tool / model / plan | 예: `recraft / V4 / Pro`. **플랜은 상업 권리를 판정하는 근거라 꼭 적는다** |
| generated_kst | `2026-10-16 21:30` 형식(KST) |
| seed | 도구가 보여 주면 적는다 |
| prompt_id / prompt_extra | `PROMPTS.md`의 방향(A~F)과 덧붙인 지시 |
| human_edit | 사람이 고친 내용(채택 전 필수 — 아래) |
| note | 고른 이유 |

## 채택 전 점검(최종 마크 확정 시)
1. **플랜**: 상업 이용과 출력 소유 권리를 주는 플랜에서 생성했는지 확인한다. 생성 당시의 ToS 조항을 URL과 열람 일시(KST)로 기록한다.
2. **사람 손 수정**: 곡선, 획 두께, 글자 사이 중 하나 이상을 사람이 실제로 고치고 `human_edit`에 남긴다.
   - 미국 저작권청 2025년 보고서 기준으로, 사람이 고친 부분만 보호 대상이다.
   - Claude의 정밀화 작업은 이 '사람 수정'으로 계산하지 않는다.
3. **유사 마크 검색**: 같은 류(16·41류 등)의 유사 등록 마크가 없는지 확인한다.
   - 대상: J-PlatPat(일본), KIPRIS(한국), USPTO(미국).
   - 기존 잡지·브랜드 마크와 닮았으면 탈락시킨다(브랜드 정책 ⑴).
4. **상표 출원**: 일본에서는 로고타입의 저작물성이 약하다(ゴナU 판례). 실효적인 보호는 상표 등록이다. 출원 여부는 오너가 결정한다.

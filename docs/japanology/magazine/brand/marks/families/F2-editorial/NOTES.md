# F2 클래식 에디토리얼 — NOTES (2026-10-15 KST)

**한 줄 콘셉트**: 디돈 세리프(Bodoni)와 올드 명조(Zen Old Mincho)를 '세로 강세 · 가로:세로 = 7:20' 한 붓으로 다시 칠한 지적인 가족. 주홍은 글자가 아니라 문장부호 하나다.

| 마크 | 역할 | 주홍 문장부호 |
|---|---|---|
| **TONARI.** | 국제·보편(우산) | 마침표 — 라틴 문장의 끝 |
| **となり。** | 일본 국내 시리즈 | 구점(고리) — 일본어 문장의 끝 |
| **トナリ・** | 하이브리드·경계 | 가운뎃점 — 외래어를 이어 쓰는 경계 기호(「トナリ・ことば」처럼 꼭지 이름과 바로 이어진다) |

기존 패밀리(Murecho 굵은 고딕, 주홍 = 본체 곁의 작은 획)와 다른 점: 굵기 대비가 큰 세리프/명조이고, 주홍이 획이 아니라 문장부호다.

## 파일
- `svg/F2-TONARI-{light,dark}.svg`, `svg/F2-tonari-hira-{light,dark}.svg`, `svg/F2-tonari-kata-{light,dark}.svg`
  - light = 밤 #151b2c 글자, dark = 눈 #eef0f4 글자, 둘 다 주홍 #d4462a 문장부호.
  - 모두 아웃라인 path이고 `<text>`는 없다. viewBox 1px = 10단위, 잉크 상자로 잘랐다(여백 없음).
- `build-f2.py`: 서체 내려받기 + SHA256 검증 → 윤곽 → 붓 → 배치 → SVG·`card.html`·`family.json`.
- `family.json`: 원리 숫자, 붓 전후 실측, 쌍별 간격 실측, 서체 URL·SHA256.
- `card.html` / `card.png`: 폭 1500px 카드 한 장.
  - 맨 위: 이름과 한 줄 콘셉트, 원리.
  - 세 마크를 같은 배율(1단위 = 0.1309px)로 밝은 바탕·밤 바탕 두 줄.
  - 웹 헤더 24px(1:1) 견본.
  - 표지 제호 폭 312px(390px 표지의 80%) 견본.
- 재생성(리포 루트, Node 24):
  ```
  python3 -I docs/japanology/magazine/brand/marks/families/F2-editorial/build-f2.py
  export PATH=/opt/node24/bin:$PATH
  node <스크래치패드>/shotfull.cjs docs/japanology/magazine/brand/marks/families/F2-editorial/card.html docs/japanology/magazine/brand/marks/families/F2-editorial/card.png 1500
  ```
  - 필요 패키지: fontTools, numpy. 서체 캐시는 `TONARI_FONT_CACHE`(기본: 임시 폴더/tonari-f2-fonts)에 둔다. 리포에는 서체 파일을 두지 않는다.
  - 빌드는 약 45초 걸린다(가나 래스터 정리 때문).
  - **결정성**: 두 번 빌드해 SVG 6개·card.html·family.json의 SHA256이 같은 것을 확인했다.
    - F2-TONARI-light `b8ab9c86…a438`
    - F2-tonari-hira-light `85ecbe9e…7f6c`
    - F2-tonari-kata-light `1c6aa142…e40d`

## 가족 원리(숫자) — 단위: 라틴 대문자 높이 H = 750
1. **같은 기둥 130** (= H × 0.173)
   - 라틴 I 기둥 = 가나에서 가장 굵은 세로 획(り 오른 획) = 130.
   - 실측(붓 뒤): I 130.0 · り 129.9 · リ 120.8 · ト 109.0.
   - 가나에서 가장 굵은 획을 기준으로 삼은 이유: 붓 크기를 세 획의 평균에 맞추면 り가 140이 되어 가나가 TONARI보다 검게 읽혔다.
2. **같은 헤어라인 45.5** (가로:세로 = 0.35 = 7:20)
   - T 팔(최소) 45.5 = ナ 가로획(최소) 45.7.
   - 24px 헤더(대문자 높이 ≈ 23px)에서 헤어라인 ≈ 1.4px라 가는 획이 사라지지 않는다.
   - 처음에는 0.30(39)을 시험했다. 가나 가로획을 더 깎아야 해서 붓머리가 상하고, 헤더에서 1.2px로 너무 가늘어 0.35로 정했다.
3. **같은 붓 = 세로 강세**
   - 세로 변은 ax만큼, 가로 변은 ay만큼 민다. 기운 변은 법선 성분 제곱으로 보간한다: d = ax·nx² + ay·ny².
   - 확장량은 손 수치가 아니라 실측에서 계산한다: (목표 − 원래)/2.
     - Bodoni(opsz 6, wght 597): ax −0.05, ay +4.55 — 원래 I 130.1, T 팔 36.4.
     - Zen Old Mincho Bold(배율 0.9746): ax +12.6, ay −5.45 — 원래 り 104.8, ナ 가로 56.4.
   - 즉 명조 가나를 Bodoni의 대비로 다시 칠한다. 세로 획은 굵어지고 가로 획과 곡선의 가로 부분은 가늘어진다.
4. **같은 높이**: 가나 잉크 높이 = H × 1.06(ト 기준), 대문자 높이 가운데에 중심을 맞춘다(위아래 0.03H씩 넘침).
5. **같은 리듬**
   - TONARI는 Bodoni 자체 너비 그대로 짰다(자간 0, 커닝 없음 — 디자이너가 정한 리듬을 기준으로 삼았다).
   - 그 다섯 쌍의 '흰 깊이 평균'을 쟀다. 이웃 윤곽 사이 가로 거리를 80줄로 재고, 상한을 기둥 × 2.0으로 둔 평균이다.
     - TO 235.3 · ON 234.0 · NA 255.7 · AR 250.4 · RI 249.2 → G = 244.9(= 기둥 × 1.88)
   - 가나 쌍도 G = 244.9로 맞췄다. 단 가장 가까운 가로 거리는 기둥 × 0.75(97.5) 이상으로 둔다. 이 하한이 걸린 쌍은 トナ 하나다.
   - 결과: とな 244.9/149.8 · なり 244.9/149.5 · トナ 245.8/97.5 · ナリ 244.9/98.7(평균/최근접).
6. **주홍 = 문장부호 하나**(비글자 악센트, 대비 3.9:1이라 글자 정보를 싣지 않음)
   - 점 지름 = 기둥 × 1.15(150).
   - 구점 고리: 바깥 지름 = 기둥 × 1.9, 고리 굵기 = (기둥 + 헤어라인)/2. 고리 굵기를 기둥과 헤어라인의 중간으로 둔 것도 같은 붓 원리다.
   - 앞 글자와 잉크 거리 = 기둥 × 0.6.
   - 위치: 마침표·구점은 기준선/가나 잉크 바닥, 가운뎃점은 높이 가운데.
   - 단색 인쇄에서는 본체 색으로 바꿔도 문장부호로 읽힌다.

## 가나 붓의 처리(손 수정 대신 규칙으로 고친 것)
점 번호 단위의 손 수정은 없다. 대신 아래 과정을 실측 보며 고쳤고, 모두 `build-f2.py`의 `raster_brush`에 규칙으로 남겼다.

| 단계 | 처음 결과(실측) | 고친 방법 |
|---|---|---|
| 벡터 비등방 오프셋을 서체 윤곽에 바로 적용 | 부호가 섞이면 작은 둥근 붓머리(입필 갈고리)·꼬리에서 가시·고리, 겹친 획 이음매에서 홈 | 가로 팽창 → 세로 침식을 따로 적용한다. 다시 칠할 때 감김 > 0만 잉크로 쳐서 뒤집힌 고리를 버린다 |
| 겹친 획 윤곽 | 이음매 홈 | 먼저 칠해 하나로 합친 윤곽(마칭 스퀘어)에 붓을 적용한다 |
| 곡선 펴기 12조각 | 긴 꼬리(り·リ)에서 8단위 꺾은선이 붓 혹 → 톱니 | 2차 곡선 1개 = 64조각 |
| 래스터에서 딴 윤곽 | 방향 계단 → 톱니 | 덮임 비율 래스터(가로 소수 끝, 세로 4줄 평균), 1단위 간격 재표본 + 평균 6회(σ≈2.8단위), 붓 법선을 ±6점 이웃에서 측정 |
| 마무리 | 붓머리 잔가시, 넓은 법선이 만드는 오목 모서리 곁 홈 | 회색조 열기 5단위·닫기 8단위 → 0.5 등고선 → 다시 평균 → RDP 0.1단위 |

- 가나 SVG는 2차 곡선이 아니라 0.1단위 정밀도의 꺾은선이다(hira 18.7KB, kata 10.8KB). 라틴은 서체 2차 곡선을 그대로 쓴다.
- 기각한 대안:
  - Zen Old Mincho Black: 붓 뒤 결과가 Bold와 거의 같고 획 머리 덩어리가 커서 기각.
  - Regular·Medium(가로획 47·50): 그래도 0.35에 닿지 않는다.
  - Shippori Mincho·Kaisei Tokumin: 가로/세로 0.55~0.6이라 깎을 양이 더 많다.

## 라틴 처리
- Bodoni Moda 가변 서체에서 **opsz 6**(가장 작은 광학 크기 = 헤어라인이 가장 굵은 판)과 **wght 597**(I 기둥이 정확히 130)을 골랐다.
- opsz 11 이상은 헤어라인 19.5라 24px 헤더에서 0.6px로 사라졌다(실측).
- 가로 변만 +4.55씩 굵혔고(헤어라인 36.4 → 45.5), 세로 기둥은 그대로다.

## 모방 점검(대조 이미지 없음, 스크래치패드 밖 반입 없음)
- **고대비 디돈 대문자 패션지 제호류**(VOGUE·Harper's BAZAAR 등)와 장르가 가장 가깝다. 다른 점:
  - 헤어라인 대비가 0.35로 그 제호들(극단적 헤어라인)보다 훨씬 낮다. opsz 6 본문형 Bodoni다.
  - 주홍 마침표가 있다.
  - 가나 두 마크와 한 원리로 묶인다.
  - 글자 꼴도 Bodoni Moda 그대로라 특정 로고의 변형이 아니다.
- **an・an**(가운뎃점 제호) — トナリ・와 닮았는지 따로 확인했다.
  - an・an은 소문자 라틴 두 단어 사이에 점을 둔다. トナリ・는 가타카나 끝에 주홍 점을 둔다.
  - 구성·글자·색이 다르다.
- **&Premium·BRUTUS·POPEYE**(BRIEF 지정) — 해당 없음.
  - 대문자 세리프 + 마침표는 &Premium의 브래킷 세리프 소문자 + 원 안의 &와 다르다.
  - 굵은 산세리프·버블 글자는 쓰지 않았다.
- 결론: 버린 안 없음.

## 스스로 본 약점
- **가나 획 머리의 작은 점**: 입필 갈고리를 열기로 지우고 남은 작은 점이 획 머리에 남아 있다. 붓 닿은 자리처럼 읽히지만 의도해서 그린 형태는 아니다.
- **리듬 차이**: TONARI는 Bodoni 자체 간격이라 시원하고, 가나는 같은 흰 깊이 평균인데도 획이 곡선이라 조금 빽빽해 보인다.
- **대형 인쇄**: 대형 인쇄(가나 높이 1000px 이상)에서는 꺾은선 윤곽의 미세한 평탄부가 보일 수 있다. 표지·웹 크기에서는 보이지 않는다.

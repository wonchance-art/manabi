# 브랜드 마크 패밀리 추가 — 공통 지시 (2026-10-15 KST, 편집장)

오너 요청 「각각 색다른 느낌으로 몇 가지 더 만들어봐」. 기존 패밀리(../NOTES.md, Murecho 출발 굵은 고딕)와 **확연히 다른 성격**의 패밀리를 디자이너 1명당 1개 만든다.

## 역할 (오너 결정)
- TONARI = 국제·보편(우산 브랜드, 일본 외 나라 시리즈, 서비스 대표)
- となり = 일본 국내 시리즈
- トナリ = 하이브리드·경계(일본×다른 나라가 만나는 꼭지)
세 마크가 **한 가족**으로 보여야 한다(같은 획 원리·높이 관계·간격). 원리를 숫자로 적는다.

## 규칙
- 출발 서체는 SIL OFL 1.1 / Apache 2.0만(google/fonts의 OFL.txt·METADATA.pb로 확인, NOTES 표에 URL·열람 시각 KST). 또는 서체 없이 직접 작도.
- 결과는 아웃라인 SVG(<text> 금지), 손 수정 내역 기록, 결정적 재생성(build 스크립트 + 고정 커밋 URL + SHA256).
- 다른 브랜드·잡지 로고 모방 금지(BRUTUS·&Premium·POPEYE·기타 유명 로고). 닮았으면 버리고 다시. 대조 이미지는 스크래치패드에만.
- 색: 밤 #151b2c, 눈 #eef0f4, 주홍 #d4462a(비글자 악센트). 패밀리 성격상 다른 색 하나가 꼭 필요하면 근거 1줄.
- 작은 크기 성립: 웹 헤더 높이 24px, 표지 제호 폭 80%(390px 표지에서 312px)에서 형태가 무너지지 않을 것.

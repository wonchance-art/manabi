# F5 기하·모더니즘 — NOTES (2026-10-15 KST)

**한 줄 콘셉트**: 「이웃」을 자로 그린다. 획·최소 속공간·자간이 모두 1u인 격자에서 원과 직선만으로 작도했다. 주홍은 격자 단위 그 자체인 지름 1u 마침점 하나다.

| 마크 | 역할 | 파일 |
|---|---|---|
| TONARI | 국제·보편(우산) | `svg/F5-up-{light,dark}.svg` |
| となり | 일본 국내 시리즈 | `svg/F5-hira-{light,dark}.svg` |
| トナリ | 하이브리드·경계 | `svg/F5-kata-{light,dark}.svg` |

- `-light`는 밤 글자(밝은 바탕용), `-dark`는 눈 글자(밤 바탕용)다. 주홍 점은 두 판 모두 #d4462a다.
- `-grid`는 작도 격자 설명용(1u·¼u 선, 원호 중심 표시)이다. 마크로 쓰지 않는다.
- 모두 아웃라인 path이고 `<text>`는 없다.

## 가족 원리(숫자 — `build-f5.py` 상수)
| 상수 | 값 | 뜻 |
|---|---|---|
| `W` | 1u | 모든 획 굵기다. 끝은 획 방향에 직각으로 자른다(butt). 사선은 직각 두께가 1u가 되도록 수평 폭을 반복 계산한다. |
| `H` | 5u | 라틴 대문자와 가나가 같은 5u 칸을 쓴다. 가나도 확대하지 않는다. |
| `R_BIG` | 2u | 큰 원호의 중심선 반지름이다. O·A 아치 바깥 지름이 5u = H가 된다. ナ·リ·り 꼬리는 R_BIG + W/2를 쓴다. |
| `R_MID` | 1.5u | と 몸통, り 아치 |
| `R_SMALL` | 1u | R 볼, な 고리. 속공간 지름이 1u = W다(최소 속공간 = 획 굵기). |
| `GAP` | 1u | 기본 자간(잉크 사이)이다. 예외 8쌍은 0.55–0.9u다(`KERN` 표: T-O 0.55, ト-ナ 0.55 …). |
| `DOT`·`DOT_GAP` | 1u·1u | 주홍 점 지름 = W다. 마지막 잉크에서 1u 떨어진 기준선 위에 둔다. |
| `KANA_SLANT` | 22° | ト 짧은 획, な 점 획 |
| `TAIL_SWEEP` | 62° | ナ·リ·り 끝 원호의 회전각이다. 세 글자가 같은 꼬리를 쓴다. |
| `U` | 20 | SVG 단위/1u |

- 세 마크 모두 높이 5u다. 폭은 TONARI 29.0u, となり 17.895u, トナリ 15.126u다.
- 주홍 점을 지우면 단색 마크가 된다(글자 형태는 변하지 않는다).

## 읽힘 판단(작도 중 수정)
- **と**: 둘째 획을 진행각 150°의 사선으로 시작해 R_MID 원호로 돌린 뒤 바닥 수평으로 이었다.
  - 처음에는 진행각 145°에 시작 높이 0.9u였다. 사선이 첫 획 뒤로 숨어 「L+c」로 보였다.
  - 시작 높이를 0.5u로 올리고 사선을 30°로 눕혀 첫 획 오른쪽으로 1.6u 드러냈다.
- **な**: 고리는 원(속공간 1u)이다. 수직은 고리 정수리에 내려앉고, 꼬리는 바닥에서 오른쪽으로 2u 뻗는다.
  - 1차: 수직이 고리 중심까지 내려와 속공간 윗반을 덮었다.
  - 2차: 수직을 고리 오른쪽 띠에 붙였더니 「ta」(라틴 a)로 읽혀 기각했다.
  - 3차(채택): 실제 な처럼 고리 위 가운데에 수직을 두고, 수직은 고리 띠 중심선에서 멈춘다.
  - 점 획과 수직 사이를 0.2u에서 0.5u로 벌렸다. 24px 헤더에서 1px 틈이 뭉쳤기 때문이다.
- **り / リ 구별**: り는 왼쪽 기둥에서 R_MID 아치가 솟아 오른쪽 다리로 이어진다(n자 연결). リ는 두 획이 떨어져 있고 아치가 없다. 꼬리 원호는 둘이 같다.
- **ナ → テ 방지**: 수직이 가로획 위로 1.3u 솟는다(y = 0에서 시작). 가로획은 하나뿐이다.
- **ト**: 기둥(5u)과 −22° 짧은 획(2.9u)이다.
- **꼬리 길이 자동 맞춤**: ナ·リ·り 꼬리는 `fit_bottom()`이 이분법으로 직선 길이를 찾는다. 잉크 맨 아래가 기준선 5u에 정확히 닿는다.
  - 1차에서는 り가 기준선 아래로 0.85u 내려갔다.
- **A**: 지름 5u 원의 윗반 + 두 기둥으로 된 아치 A다. 가로대 윗변 = 원 중심선이라, 위아래 속공간이 1.5u : 1.5u로 같다.
- **R**: 3u 높이 볼(R_SMALL)과 사선 다리다.

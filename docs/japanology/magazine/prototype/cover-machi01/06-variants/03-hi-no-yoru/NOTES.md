# ③ 火の夜 — 제작 노트 (2026-10-15 KST)

**한 줄 콘셉트**: 길은 그리지 않는다 — 양쪽에 늘어선 筍形 大松明의 행렬이 밤 남색 위에 '가장 밝은 길'을 만들고, 그 소실점 위에 「富士吉田」이 선다.

## 주인공의 사실 근거
| 그림 요소 | 원고 문장 | 위치 |
|---|---|---|
| 筍形, 높이:지름 = 3.0:0.9 | 「高さ約3メートル、直径約90センチの筍の形をした大松明が表通りに立てられ、火が点される。」 | `ja/machi-fujiyoshida.md` 72행, 출처표 A45·A47(北口本宮冨士浅間神社, 原文照合 2026-10-15 09:20 KST) |
| 밤 바탕 · 부제 | 「道がいちばん明るくなるのは、8月26日の夜である。」 | 72행(같은 단락 첫 문장) |
| 불빛 색(ember) | 「村の中が真昼のように明るかった」(『甲斐国志』 전언) | 72행, 출처표 A55 |

- 부제는 원고 72행 첫 문장 **그대로**(25자, 「。」 하나, 구체물 「道」). 길 위(두 줄 사이)에 세로 2열, 「道」가 소실점 쪽 맨 위.
- 비례: 1점 투시에서 같은 깊이의 가로·세로 배율이 같으므로 모든 松明이 판면에서도 높이/폭 = 3.33(생성 경로 bbox 실측 3.333–3.335).
- **模式**(크레딧 「大松明の数と並びは模式」): 개수·간격 2.2m·길 양쪽 배치(±3.2m)·반 칸 어긋남·눈높이 7m. 원고에 본수가 없고 취재 D3는 80〜120本으로 갈림 → 앞쪽은 재단 밖으로 잘리고 뒤쪽은 소실점에서 겹쳐 사라져 **셀 수 없게** 했다(생성 path 300개는 겹친 원근 꼬리이며 개수 주장 아님).
- 筍形 윤곽 hw(t) = d/2·(1−t)(1+0.85t) — 배부른 원뿔, 끝 뾰족. 불꽃·연기·불티 등 사실 묘사 없음.

## 색 (바탕 + 2색)
- 바탕 night #151b2c(재단까지), 글자 전부 snow #eef0f4(15.0:1).
- **ember #f2a066** 근거: 『甲斐国志』 「真昼のように明るかった」의 불빛 — 주홍만으로는 밤 바탕에서 빛이 아니라 붉은 물체로 읽힌다. 깊이 5m까지 ember, 60m에서 vermilion으로 로그 깊이 보간(공기 원근). 둘 다 비글자 전용(vermilion/night ≈3.3:1, 비글자 3:1 충족).
- vermilion은 먼 松明과 제호 괄호(mast-dark.svg 무수정)에만.

## 요소 (6개)
제호(mast-dark.svg, (13,13) 16mm) · 호 표기 · 제목(x95–115 가운데 축, 20mm) · 부제 · 松明 판(plate) · 크레딧(왼쪽 아래 고정, 3.4mm).

## 다듬은 내용
1. 한 줄(길 한쪽) 횡 원근 → 가운데가 비고 도표처럼 보임. 위에서 본 대각 한 줄도 공백 과다.
2. 길 양쪽 두 줄 + 가운데 소실점으로 전환 — '길'이 두 줄 사이 어둠으로 생긴다. 제목을 소실점 위 같은 축에, 부제를 길 위에.
3. 눈높이 4→5→7m 비교: 7m에서 아래쪽까지 松明이 내려와 하단 공백 해소, 松明 전부가 지평선 아래라 하늘(위 40%)이 제호·제목 자리로 깨끗.
4. 줄 순서를 바꿔 반 칸 어긋남을 왼줄에 → 가장 큰 松明은 오른쪽 아래 재단으로 잘리고, 왼쪽 아래 크레딧 구역은 비움. 크레딧을 1줄 「大松明の数と並びは模式」로 줄여 좁힘.
5. 筍形 윤곽 총알형(t^1.7) → 원뿔형(c 0.6) → 배부른 원뿔(c 0.85)로 '筍'에 가깝게. 색 보간 시작을 z5m로 옮겨 가까운 것을 순수 ember로(이전엔 탁한 살구색).
6. 판면 밖에 통째로 있는 松明 path 제거(301→300).

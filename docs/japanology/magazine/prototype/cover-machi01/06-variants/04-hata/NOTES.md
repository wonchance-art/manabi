# ④ 機の町 — NOTES (2026-10-15 KST)

**한 줄 콘셉트**: 金鳥居에서 本町二丁目까지, 下吉田의 실제 거리망을 한 길 = 가는 실 6가닥의 띠로 바꿔 경사(富士山 쪽으로 뻗은 길, 흰 실)·위사(가로지르는 길, 주홍 실)가 위아래로 엮인 '원단 한 조각'으로 보인다.

## 주인공의 사실 근거
- 원고 `docs/japanology/magazine/ja/machi-fujiyoshida.md`
  - 50행 「金鳥居の北側、下吉田が「俗なる町」の側にあたる。大正の終わりから昭和の初めにかけて、ここが織物生産の中心だった。」(A23) → 천의 위 끝을 金鳥居 교차로로 잡은 근거.
  - 54행 「今の産地は、細い糸を高い密度で織り上げる…県によれば、国産ネクタイ生地の4割にここの生地が使われている。」(B05·B06) → 부제.
  - 60행 「下吉田の中心を通る富士みちは、通称「本町通り」…正面に富士山が続くように見える」(A21·B99) → 위 = 富士山頂 방위, 本町通り가 세로 경사 한 가닥이 된다(산정 방위와 +1.7°, 04-factcheck §1).
- **부제**: 「国産ネクタイ生地の4割に、ここの生地が使われている。」(26자, 「。」 하나, 구체물 = ネクタイ生地). 원고 54행 문장에서 「県によれば、」를 빼고 쉼표 하나만 더했다. 주의: 원문(B06)의 '여기'는 산지(郡内·富士吉田)이고, 그림은 그중 下吉田의 길이다 — 그림이 4할을 나타내지 않는다(색 비율·가닥 수가 4:6 등 숫자를 암시하지 않음).
- OSM: fy.json(Overpass out geom, osm_base 2026-07-28 11:16 KST). highway = trunk·primary·secondary·tertiary·unclassified·residential·living_street·pedestrian·*_link. 보도·service·track·steps 제외, 12mm(약 90m) 미만 실 생략, 상하행 분리처럼 3.2mm 안에서 60% 이상 겹치는 실은 한 가닥으로(24개 제외).
- 투영: 本町二丁目 교차점(35.4930014,138.8040588) 원점, 위 = 剣ヶ峯(국토지리원 CSV) 방위 205.27°, 1mm = 7.6m(판면 폭 약 1.6km, 천 높이 약 1.26km). 직선화·회전 보정 없음. 북쪽 위 대신 이 방향을 고른 이유: 本町通り가 세로(경사)로 서고, 기존 1안·시리즈와 '위 = 산'이 맞는다.
- 천 범위: 위 y50.5(金鳥居 교차로 위사가 첫 줄) ~ 아래 y216(本町二丁目). 좌우 재단. 위아래 '술'(7·8mm)은 실제로 이어지는 경사만.
- **模式**: 교차부의 위·아래 끊김. T자는 지나가는 길이 위(끝나는 길이 밑으로 숨음), 지나가는 교차는 실마다 위·아래가 번갈아 오도록 전파(평직 흉내, 모순 250곳은 먼저 정해진 쪽 유지). 크레딧 「糸の上下は模式」.

## 다듬은 내용
1. 첫 렌더(단색 굵은 선 2.2mm, 1km 폭): 지도 앱처럼 보임 → 한 길을 가는 실 6가닥 띠(4.6mm)로, 밀도 위해 축척 5→7.6m/mm.
2. 전체 판면을 덮으니 글자와 충돌, 역 주변(宮川·바이패스)이 곡선 덩어리 → 천을 '金鳥居~本町二丁目' 띠로 잘라 원단 견본처럼 두고 위아래에 경사 술. 글자는 위(제호)·아래(부제→제목→크레딧)의 빈 바탕에.
3. 동심 획 방식의 띠는 교차 조각 끝에 이음 자국 → 가닥마다 평행 이동 폴리라인으로 다시 그림. 그러자 겹친 도로가 주홍 덩어리로 뭉침 → 띠 밑 바탕색 깔개 + 중복 실 제거.
4. 가로 위치(ox 105→128): 서쪽 사선 도로 덩어리를 줄이고 격자가 가운데 오게. 부제·제목 겹침(검사 실패 1건) → 제목 245mm로.

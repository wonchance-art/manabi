# ⑥ 活字 — 노트 (2026-10-15 KST)

**콘셉트**: 그림 없이 「富士みち」 네 글자만. 글자를 등비 1.8로 키우며 세로로 쌓아, 위(먼 곳)로 갈수록 작아져 주홍 지평선의 한 점으로 모이게 했다. 글자 자체가 산으로 올라가는 길의 원근이 된다. 「富士」는 800(멀리 있는 산의 덩어리), 「みち」는 500(발밑의 길)이다.

## 주인공의 사실 근거
- 표지어: 원고 `ja/machi-fujiyoshida.md` 18행 「縦の表紙語: **富士みち**」((1)扉).
- 원근의 방향(위 = 富士山 쪽): 원고 46행 「富士山へまっすぐ延びる」(A16)·「富士山に向かってゆるく上っていく」(A18, 코스 전체에 대한 서술). 표지에는 숫자를 쓰지 않는다.
- **부제(편집장 정정 2026-10-15 KST)**: 「富士吉田に入った道は、富士山へまっすぐ延びる。」(23자, 「。」 하나, 구체물 = 富士吉田·富士山). 근거: 원고 46행 「富士吉田に入った富士道は下吉田のあたりで南へ向きを変え、富士山へまっすぐ延びる」 ← 取材 A16 山梨県 「富士道モデルコース④」 「富士山へとまっすぐ伸びています」(1차). 검수 04-factcheck 172행 「道は富士山へまっすぐ延びる」 可(県 표현 유지).
  - 교체 이력: ①「下吉田駅から富士山駅まで、道は約125メートル上る。」→ ②「…高低差は約125メートル。」→ 현행. 125m는 県 산책 코스(약 8km) 전체의 고저차이지 두 역의 표고차(실측 약 56m)가 아니어서 ①②는 모두 사실 오독이었다(편집장 정정). 기본 부제(金鳥居 30m)는 이 안에 金鳥居가 없어 쓰지 않는다. 부제는 「みち」 곁(왼쪽)에 둔다.
- 숫자를 그림으로 보이지 않는다(글자 수 4 = 표지어 글자 수). 지도·略図 없음 → OSM·略図 크레딧 없음. 원근은 조판 구성이며 실측을 주장하지 않는다.

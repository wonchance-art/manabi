# 一つの町 01 富士吉田 표지 — 역할 분담 제작 기록 (2026-10-15 KST)

오너 지시(2026-10-15): 「따로따로 역할 배치해서 각 장면마다 맞춤형 전문가 세워놓고 작업」. 3안 시안(`../cover-variants/`)이 "유명 매거진 작가라면 저렇게 했을까?"에 '아니다'로 판정된 뒤 다시 만들었다.

## 콘셉트
「붉은 길 하나가 올라가 후지산을 향한다」 — OSM 실측 富士みち(下吉田 꺾임점 바깥 → 金鳥居 → 上宿 교차점)를 金鳥居에서 본 富士山頂(剣ヶ峯) 방위가 위가 되도록 투영. 직선화·회전 보정 없음. 산은 略図 능선 한 줄. 金鳥居는 남색 도리이 윤곽(실물이 銅張り라 주홍 금지). 틀·지명·큰 세로 단어 없음.

## 편집장 결정 기록
- 부제 「今の金鳥居は、もとの場所より30メートルほど山に近い。」 — 観光庁 원문 「30メートルほど」(검수 1).
- 선 위 끝 = 上宿(北口本宮 아님, 남남동 약 450m). 아래는 재단에서 자름(검수 2·3).
- 선은 산정 오른쪽(서쪽)으로 비켜 감 — 실측 그대로. 「道が富士山へ向かう」는 가능, 「山頂を指す」는 금지(검수 4).
- 크레딧: OSM 표기 + openstreetmap.org/copyright(인쇄 의무) + 「上は金鳥居から見た富士山頂（剣ヶ峯）の方角・山は略図」.
- 제호 괄호: AD 1.2mm → 0.75mm 겹선(390px에서 뭉침 실증, `03-mast/compare.png`).
- 비평 반영(v2): 막대→남색 도리이(십자 오독), 축척 12.9→11.3m/mm(산-선 공백 68→46mm, 하단 굽음 재단 밖), 제목 20mm, 선 3.0mm·능선 1.4mm.
- 기각: 선을 산정까지 늘려 꼭짓점에 맞추기(독자 제안) — 사실 위반.
- 남은 확인: AD 비평 S1(능선 꼭대기 모서리)·S2(크레딧 무게)·S3(호 표기 공백), 인쇄 PDF 때 웹폰트 임베드 후 재측정, 검수 보류 항목(`04-factcheck.md` §10).

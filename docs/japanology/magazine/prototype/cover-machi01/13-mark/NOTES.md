# 13-mark — 새 마크를 앉힌 표지 4안 (2026-10-16 KST)

**오너 요청**: 「적용시킨 시안 내봐 컨셉 잡고」

**입력**
- 마크: 오너 수렴안을 정밀화한 v1(`../../../brand/ai-gen/refine/v1/`)
  - TONARI 원판
  - となり(정정본, と 첫 획이 이어진 판)
- 문구·지도·단면: 12-hip 판(검수 완료)을 그대로 가져왔다.
  - `一本の線` 판: OSM 실측선 + 略図 능선
  - `断面` 판: GSI 標高, 縦横同縮尺
  - 크레딧도 함께 가져왔다.
- 새로 쓴 문장은 없다.

## 공통
- 서체: 제목은 Zen Old Mincho 700, 읽는 글자는 Zen Kaku Gothic New. 둘 다 SIL OFL 1.1이다.
- 둥근 굵은 마크와 명조 제목을 대비시켰다.
- 검사
  - 4안 모두 `check-cover.cjs`를 통과했다. 글자 겹침 0, 안전선 안, 390px에서 글자 10px 이상(크레딧 6px 이상), 대비.
  - 마크와 글자의 겹침, 마크의 안전선은 `build.mjs`에서 따로 검사했다.
- 마크는 그래픽이다. 주홍 마크(B·D)는 큰 글자 기준으로 대비 3:1 이상이다.

## 하지 않은 것
- 오너 시안 속 AI 생성 사진·일러스트는 쓰지 않았다. 실재하지 않는 인물·풍경이라서다. 그림은 실측 그림만 쓴다.
- 연도·계절 표기는 넣지 않았다. 발행일이 아직 정해지지 않았다.
- 태그라인 "Japan from next door"는 넣지 않았다. 후보로만 둔다.

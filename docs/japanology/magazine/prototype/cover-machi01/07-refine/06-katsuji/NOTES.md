# ⑥ 活字 — 다듬기판 노트 (2026-10-15 KST)

원본은 `../../06-variants/06-katsuji/`에 그대로 두었다. 비평은 `../critic.md`의 ⑥ 절과 §3(시리즈)을 적용했다. 부제는 편집장 결정에 따라 바꾸지 않았다.

**콘셉트**: 그림 없이 「富士みち」 네 글자만 쓴다. 같은 활자(Shippori Mincho 500)를 등비 1.9로 키우며 세로로 쌓았다. 글자는 위로 갈수록 작아져 판면 중심의 주홍 지평선 (105, 72)으로 모이고, 그 원근이 길이 된다. 제목 「富士吉田」는 길의 가까운 끝인 「ち」 곁에 선다.

## 근거
- 표지어: 원고 `ja/machi-fujiyoshida.md` 18행 「縦の表紙語: 富士みち」.
- 부제(유지): 「富士吉田に入った道は、富士山へまっすぐ延びる。」. 원고 46행 ← 取材 A16(山梨県 「富士道モデルコース④」, 1차) ← 04-factcheck 172행 「道は富士山へまっすぐ延びる」 可.
- 지도·略図·숫자 도형이 없으므로 OSM·略図 크레딧도 없다. 원근은 조판 구성이며 실측을 주장하지 않는다.

## 시리즈 규칙과 다른 점 (보고)
- **크레딧 크기를 3.2가 아니라 3.24mm로 두었다.** 3.2mm는 390px에서 5.94px이라 check-cover의 6px 하한에 걸린다(실측 실패). 6px을 넘는 최소값이 3.231mm다. ①⑤에도 같은 문제가 생기므로 §3의 값을 3.24로 고칠 것을 제안한다.

## 측정 (10px/mm 렌더, `ink.cjs`)
- 잉크 면적 **4.61%**(D1 ≤8%), 주홍 0.37%(제호 괄호 포함, D3 ≤1%)
- 요소는 제호·호 표기·지평선·표지어·제목·부제·크레딧의 7개다.

## 검사
- `check-cover.cjs cover.html`: **통과**(겹침 0·안전선 안·최소 글자 크기·대비, 글자 요소 10개)
- 결정성: `node build.mjs`를 2회 실행해 cover.html sha256 `a53f8fef…aa7480f6`로 같았다.
- 재생성: `export PATH=/opt/node24/bin:$PATH; node build.mjs`(배치 값은 `layout.json`). 상자는 `node rects.cjs cover.html`, 잉크는 `node ink.cjs cover.html`로 잰다.

## 남은 약점
- 390px에서 지평선이 1.7px라 가늘다. 수렴 단서가 이 선과 글자 크기 변화 둘뿐이라, 썸네일 크기에서는 원근보다 「큰 ち」가 먼저 읽힌다.

## Q1. 주요 일본 잡지 아트디렉터·디자이너와 확인된 접근법

### Takeaway
확인된 사실 기준으로, 일본 잡지 디자인의 핵심 계보는 "제호(로고)·레터링이 곧 잡지의 얼굴"(堀内誠一, 花森安治), "AD가 내용 기획부터 함께 짠다"(服部一成), "비움·간소(エンプティ)"(原研哉), "다이어그램·시간지도로 정보를 그린다"(杉浦康平)로 요약된다. 사진 없는 manabi에 그대로 옮길 수 있는 것은 레터링·다이어그램·여백·편집 원칙이고, 각자의 시각 정체성(로고·표지 양식)은 옮길 수 없다.

### Inferences
- 堀内·花森의 공통점은 "잡지의 얼굴=문자(제호·레터링)"이다. 사진이 없는 manabi에서 표지 정체성을 만드는 수단도 문자뿐이므로, 이 계보가 가장 직접적인 참조다. 단 그들의 **구체적 로고·레터링 형태는 복제 대상이 아니라** "문자 하나로 얼굴을 만든다"는 원리만 가져온다.
- 服部一成 사례(내용부터 함께 짜는 AD)는 manabi 체제(Claude가 기획+카피+레이아웃을 한 손에)와 구조적으로 같다 — 화면 구성을 원고 확정 후 얹지 말고 장(章) 설계 단계에서 함께 정해야 한다.
- 花森의 「商品テスト」는 사진 없이 "직접 해 본 결과"를 표·도해로 보여주는 형식의 원형으로, manabi의 「해 보기」 꼭지와 정신적으로 맞닿는다(시각 양식은 별개).
- 杉浦의 時間地図는 "거리 대신 시간으로 왜곡한 지도"로, 사진 없는 지도 페이지를 정보 디자인으로 풍부하게 만드는 선례다.

## Q2. 일본 잡지의 레이아웃 문법 (縦横 혼용·위계·여백·罫·ノンブル·柱·扉·目次·특집 장 구성)

### Takeaway
일본어 조판의 용어·요건 정본은 W3C 「日本語組版処理の要件(JLReq)」(JIS X 4051 기반)이며, 縦組/横組 병존, 見出し·図版·注 처리, 版面 설계를 다룬다. 웹에서는 `writing-mode: vertical-rl`과 `text-combine-upright: all`(縦中横)이 2022년 이후 주요 브라우저 Baseline이어서 "짧은 세로 문자 + 가로 본문" 혼용이 기술적으로 안전하다. 잡지 형식 측면에서는 "한 호 한 주제(1冊まるごと特集)"(BRUTUS)와 "직접 체험·결점도 기록·업체 비개입"(d design travel)의 편집 규율이 확인된다.

### Cited Findings
- JLReq는 CSS·SVG·XSL-FO 등에서 구현이 요구되는 일반적 일본어 조판 요건을 기술한 W3C Working Group Note로, 주로 JIS X 4051에 기반하되 그 범위 밖도 다룬다. 제2판에서 版面 설계, 見出し 처리, 図版·表 배치, 注·참조 부호 처리 지침을 확장 — [W3C JLReq](https://www.w3.org/TR/jlreq/); [w3c.github.io/jlreq (ja)](https://w3c.github.io/jlreq/?lang=ja)
- `text-combine-upright`는 세로쓰기에서만 작동하며 일본어 縦中横 효과를 낸다. MDN 기준 2022년 3월 이후 Baseline Widely available. `all` 값은 Chrome/Firefox 48+, Edge 79+, Safari 15.4+ 지원. **`digits <integer>` 값은 어떤 브라우저도 지원하지 않음** → MDN 예시처럼 숫자를 `span`으로 감싸 `all` 적용 — [MDN](https://developer.mozilla.org/docs/Web/CSS/text-combine-upright); [caniuse](https://caniuse.com/mdn-css_properties_text-combine-upright_all)

## manabi 적용 후보 규칙 (각 규칙의 근거 출처 표시)

전제: 사진 없음 · 서버 렌더 · 320px+ · 팔레트 `#994A5A`(일본 트랙)/`#fffdf9`(종이)/`#322e30`(본문). 규칙은 후보이며 UI 변경은 저장소 규약상 텍스트 목업 합의 후 구현한다.

1. **한 호 한 주제, 꼭지 순서 고정** — 8개 특집호 모두 같은 꼭지 순서(표지→편집장의 말→장면→숫자→칼럼→モノ・コト・ヒト→지도→해 보기→한국과 나란히→키워드→더 읽기→출처). 근거: BRUTUS 1冊まるごと特集([KAI-YOU](https://kai-you.net/article/75073)), 매거진 B 한 호 한 브랜드([위키백과](https://ko.wikipedia.org/wiki/%EB%A7%A4%EA%B1%B0%EC%A7%84B)).
2. **판형(그리드)·서체는 시리즈 전체 고정, 호별 변수는 주제어 1개 + 보조색 1개뿐** — 근거: Kissa by Kissa가 판을 거듭해도 B5·단일 본문 서체 유지([Ridgeline 094](https://craigmod.com/ridgeline/094/)).
3. **표지 = 일본어 한 단어 세로쓰기(1–4자) + 나머지 정보는 가로** — `writing-mode: vertical-rl`, 화면 높이의 50~70%를 단어가 차지, 다른 장식 없음. 근거: 제호·레터링이 잡지의 얼굴(堀内 [京都新聞](https://www.kyoto-np.co.jp/articles/-/706178), 花森 레터링 [国立新美術館](https://www.nact.jp/english/artcommons/user/detail/33310)); JLReq 縦組 요건([W3C](https://www.w3.org/TR/jlreq/)).
4. **세로쓰기 사용 한도** — 표지 단어, 장 표지(扉) 제목, 1문장 인용(약 20자 이하)에만. 한국어 본문·캡션·표는 항상 가로. 근거: 모바일 가로 스크롤 회피(추론) + JLReq의 縦横 병존 문법.
5. **縦中横 규칙** — 세로 텍스트 안의 숫자는 2자리 이하만 `<span>` + `text-combine-upright: all`; 3자리 이상은 한자 숫자 또는 가로 줄로 분리. `digits` 값 사용 금지. 근거: [MDN](https://developer.mozilla.org/docs/Web/CSS/text-combine-upright), [caniuse](https://caniuse.com/mdn-css_properties_text-combine-upright_all).
6. **柱·ノンブル의 웹 번역** — 상단 sticky 한 줄 柱 = "일본, 사람의 일생 · 제N호 배우다 · 03 숫자"; 각 장 첫머리에 2자리 장 번호(01–12). 근거: JLReq 版面 요소 용어 체계([W3C](https://www.w3.org/TR/jlreq/)) — 구체 조항은 원문 재확인 필요.
7. **扉(장 표지) = 장 번호 + 세로 소제목 + 한 줄 리드, 한 화면에 그것만** — 근거: 原研哉 「空っぽ」 비움 원리([MUJI](https://www.muji.com/jp/flagship/huaihai755/archive/hara.html)); 服部一成의 "전 페이지 일관 디렉션"([ggg 아카이브](https://scrapbox.io/recruit-art-center/%E7%AC%AC6%E5%9B%9E%E4%BA%80%E5%80%89%E9%9B%84%E7%AD%96%E8%B3%9E%E5%8F%97%E8%B3%9E_%E6%9C%8D%E9%83%A8%E4%B8%80%E6%88%90%E5%B1%95)).
8. **빅넘버 페이지 = "숫자 1개 → 해석 1문장 → 출처 1줄" 단위를 세로로 쌓기**(한 화면 1개, JS 스크롤 연출 없음). 숫자는 본문의 6~8배, 단위는 숫자의 1/3 크기. 근거: The Pudding의 단계형 결과 제시([Storybench](https://www.storybench.org/?p=8613), [Peabody](https://peabodyawards.com/award-profile/the-pudding/)).
9. **지도는 사진 대체가 아니라 정보 도해로** — 실제 지형 대신 "이동 시간·생애 단계" 축으로 단순화한 도식 지도 허용(SVG, 단색+`#994A5A` 1색 강조). 근거: 杉浦康平 時間地図・ダイアグラム([artscape](https://artscape.jp/report/review/10104140_1735.html)).
10. **「해 보기」는 '직접 해 본 결과' 형식** — 절차 + 결과 표 + 실패·주의점 1줄. 근거: 『暮しの手帖』 商品テスト(전시 [artagenda](https://www.artagenda.jp/exhibition/detail/1050)) — 형식 정신만 차용.
11. **「モノ・コト・ヒト」·추천 목록의 편집 윤리** — 필자 직접 경험 또는 1차 출처가 있는 것만; 장점과 함께 한계 1줄; 업체 협찬·광고 문구 금지. 근거: d design travel 편집 방침([D&DEPARTMENT](https://d-department.com/item/DD_TEXT_REPORT_6872.html)), 『暮しの手帖』 무광고([MUJI BOOKS](https://www.muji.com/jp/mujibooks/bookdetail_hanamori.html)).
12. **칼럼 변형으로 '대담' 허용** — 묻는 이 이름 굵게 + 답, 3~6 왕복, 유머 허용. 근거: ジモコロ 대담 형식([ジモコロ](https://www.e-aidem.com/ch/jimocoro/entry/kakijiro28)).
13. **일본어 키워드 칩 = 원어 + 읽기(후리가나/ruby) + 한국어 뜻**, 본문 중 일본어는 칩/ruby로만 표시하고 문단 단위 병기 금지. 근거: d design travel 일·영 병치([Circles](https://shop.circles-jp.com/en/products/d-design-travel-kagoshima)); JLReq 루비 요건([W3C](https://www.w3.org/TR/jlreq/)).
14. **색: 종이색 바탕 + 본문색 + 강조 1색(#994A5A)** — 호별 보조색은 1개, 면적 10% 이하(숫자·장 번호·罫선에만). 근거: 原研哉 비움 원리([MUJI](https://www.muji.com/jp/flagship/huaihai755/archive/hara.html)) — 수치는 추론.
15. **罫선(괘선)으로 꼭지 구분** — 이미지 대신 1px 가는 괘 + 장 번호로 리듬을 만든다. 근거: 사진 없는 지면에서 문자·선만으로 일관 디렉션을 만든 服部一成·花森 계보(추론, 위 출처).
16. **PD 이미지 사용 규칙** — 허용 출처는 Met CC0 / ColBase / NDL 「インターネット公開(保護期間満了)」 셋. 캡션 형식 통일: "작품명 · 작가 · 연도 / 출처: ○○ (URL) / 가공: 일부 잘라냄". ColBase는 가공 표기 필수, NDL은 공개 범위가 「保護期間満了」인 것만. 로고·상표가 보이는 PD 이미지(근대 광고·포스터 등)는 배제. 근거: [Met](https://www.metmuseum.org/hubs/open-access), [ColBase](https://colbase.nich.go.jp/pages/term), [NDL](https://ndl.go.jp/jp/use/reproduction/index.html). 원문 재확인 후 채택.
17. **PD 이미지는 호당 0~2장, '장식'이 아닌 '자료'로** — 캡션에 그 그림이 무엇을 보여주는지 1문장 필수. 근거: 사진 없는 형식 유지(Q5 추론) + Kissa by Kissa처럼 이미지 수를 통제한 구성(128쪽에 사진 40장, [Tracy Durnell](https://tracydurnell.com/2020/10/30/watched-kissa-by-kissa-design-qa/)).
18. **캡션·출처 서체** — 본문보다 2단계 작게, 본문색 70% 톤, 숫자·출처는 같은 위치(아래 왼쪽)에 고정. 근거: JLReq 図版·注 처리 요건([W3C](https://www.w3.org/TR/jlreq/)) — 수치는 추론.

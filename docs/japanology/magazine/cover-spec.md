# 『となり』 표지 규격 v0 (초안, 2026-10-15 KST)

결정: **표지는 실제 잡지 판형에 맞춰 만든다**(오너 2026-10-15 KST, 「실제 매거진 사이즈 맞춰서 진행하는 걸 기본으로 한다」).
근거·선례: 표지 선례 조사(Gentlewoman·暮しの手帖·New Yorker·BRUTUS·Monocle·Kinfolk, PR #1458 대화 2026-10-15 KST) — 고정 틀 하나, 호마다 바뀌는 것은 하나, 제호는 설계된 글자.
상태: 초안. 富士吉田·霜降·창간호 세 표지에 적용해 본 뒤 고친다. 측정 가능한 항목(§6)은 자동 검사로 옮긴다.

## 3. 바뀌는 요소(호마다 하나)

- **시각 구역**: 왼쪽 약 2/3, 위 45–215mm. 들어가는 것은 셋 중 하나다. ⑴ 그 장소를 그린 PD 그림(Met CC0·ColBase·NDL 만료분만) ⑵ 자체 지도 ⑶ 활자 구성(그림·지도가 없을 때).
- **색 2개**: 주제에서 뽑는다(예: 富士吉田 = 火祭의 밤 남색 + 丹塗り 鳥居의 주홍). 뽑은 근거를 표지 파일 머리에 1줄로 적는다. 크림 바탕·가는 괘선 같은 기본값은 쓰지 않는다.

## 4. 글자 크기 — 인쇄와 휴대전화를 함께 만족

A4에서 읽히는 크기와 휴대전화(폭 390px)에서 읽히는 크기는 다르다. 휴대전화에서 10px 이상이 되려면 A4 기준 약 5.4mm(약 15pt) 이상이어야 한다. 그래서 **표지에는 15pt 이상인 요소만 둔다.** 작은 설명(지도의 보조 설명 등)은 표지가 아니라 본문 지도·목차 페이지로 옮긴다.

| 단계 | A4 기준 | 390px 화면 환산 | 용도 |
|---|---|---|---|
| 세로 표지 단어 | 90–110pt | 약 59–72px | 한 단어 |
| 제호 | 40pt 안팎 | 약 26px | 『となり』 |
| 부제 | 16–18pt | 약 10.5–12px | 한 문장 |
| 시각 구역 안 이름 | 15pt 이상 | 10px 이상 | 지점 이름 등(설명 줄은 넣지 않음) |
| 크레딧 | 9pt 이상(예외) | 약 6px | 인쇄 전용 정보. 같은 내용을 목차 페이지에 반드시 반복 |

## 5. 색 대비

- 글자와 바탕의 대비 4.5:1 이상(본문 크기), 큰 글자(세로 단어·제호)는 3:1 이상.
- 틀·지도 선 같은 비글자 요소는 바탕과 3:1 이상.

## 6. 자동 검사(계약 후보)

렌더링 때 브라우저로 재서 실패하면 표지를 내지 않는다. 검사 스크립트: `prototype/check-cover.cjs <html> [선택자]`(Playwright, 폭 390px). 1–4는 구현됨, 5는 후속.

구현 메모: 표지의 mm 단위는 `100cqw/210`으로 잡는다. `cqi`는 세로쓰기 요소에서 세로 축을 따라가 세로 표지 단어가 2배 넘게 커진다(첫 시안의 버그, 검사 스크립트가 발견).
1. 글자 상자끼리 겹침 0
2. 모든 글자가 안전선 안
3. 390px 폭에서 글자 크기 ≥ 10px(크레딧만 예외, ≥ 6px)
4. 대비 §5 충족
5. 고정 요소(틀·제호·호 표기·세로 단어·부제·크레딧)가 모두 있고 §2 위치 허용 오차 ±2mm 안

# manabi 매거진 「일본, 사람의 일생」 — 설계 초안과 편집 기법 조사

- 상태: **설계 초안 — 권고안 승인, 제호 선택 대기**(2026-10-14 KST). 구현·콘텐츠 저작 전. 결정이 나면 #1077에 박제한다.
- 경위(같은 날 오너 대화 3단계):
  1. 일본 역사·교육·문화·예술(미술·음악·만화·애니·출판)·지리·유행을 **인간의 삶이라는 보편 가치**로 읽는 심층 자료 요청 → 학습자 상황 우선 설계로 전환.
  2. 학습자 우선순위 확정: **(a) 입문 여행 성인 > (c) 유학·취업 중급 > (b) 만화·애니·J-pop 팬 > (d) 수업 학생**.
  3. "교재·학술서보다 감각을 끌어올린 **매거진**" 방향 → 일본 잡지 시각 조사 → 카피·편집 디자인·조판·작문·AI 스킬 조사(이 폴더).

## 설계 요지

**뼈대 — 같은 질문, 다른 조건.** 보편 질문 → 일본의 조건(지리·제도·역사) → 일본의 답 → 한국과 나란히 → 일본어로 한 걸음.
고유성을 국민성(본질)이 아니라 조건의 산물로 설명한다(일본인론·『국화와 칼』식 서술 배제).

**특집호 구성(발행 순 = 학습자 우선순위)**

| 순 | 호 | 요청 주제 | 1차 대상 |
|---|---|---|---|
| 1 | 0 창간사 — 같은 질문, 다른 조건 / 1 땅과 동네 | 지리·지역 | a |
| 2 | 2 배우다 | 교육 | c·a |
| 3 | 3 일하다 | 역사·제도 | c |
| 4 | 4 태어나고 가족이 되다 | 문화·역사 | a·c |
| 5 | 5 늙고 떠나고 기억하다 | 문화·신앙 | a·c |
| 6 | 6 이야기하고 그리다 | 만화·애니·출판·미술 | b |
| 7 | 7 노래하다 | 음악 | b |
| 8 | 8 유행을 따르다 | 유행 | b·a |

**한 호의 흐름(텍스트 목업)** — 세로쓰기 일본어 한 단어 표지 → 편집자의 말 → 01 첫 장면(재구성 장면 표기)
→ 02 숫자로 보기 → 03 짧은 꼭지 3편 → 04 モノ・コト・ヒト → 05 지도(기존 지도 핀·게임 노드 재사용)
→ 06 살게 된다면(c) → 07 한국과 나란히 + 이야기해 봐요(d) → 08 해 보기 → 이 호의 일본어(키워드 칩)
→ 더 읽고 보기 → 출처·검증 노트.

**채택한 잡지 시각** — 暮しの手帖(생활자의 눈·해 보기) · BRUTUS(1호 1특집·패키지·호를 건너는 키워드 아카이브)
· d design travel(선정 기준 공개·이중언어) · TRANSIT(감각 축) · &Premium(モノ・コト・ヒト) · ソトコト(관계인구 관점)
· ほぼ日(웹 매거진 선례, 가짜 인터뷰 금지). 시각 정체성(로고·판형·표지 구조) 모방은 금지.

**학습 순환 이음새** — 키워드 칩은 링크만(S0): 다른 호 · N5 교재 해당 과 · 아오조라 정본 문학책으로 이어지고, 단어 저장은
그쪽의 기존 `save_vocabulary_context` 경로(출처 종류 textbook/reading/pdf)를 탄다. /studies 화면은 서버 렌더(JS 0) 유지.
출처 종류 `studies` 신설(S2)은 사용 실측 후 재검토.

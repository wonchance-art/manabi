# 새 책장·연속 읽기와 기존 교재 관리자 보관함

사용자 요청: 승인한 manabi 시안을 실제 사이트에 적용하고 기존 교재를 관리자 안으로 이동한다. 공개 웹을 우선하며 새 음성 제작과 PDF 변경은 제외한다.

## 구현

- `/lessons`: 읽던 곳을 먼저 보여 주는 책장, 네 언어 시리즈. 일본어 `#994A5A`, 중국어 `#2A7657`, 영어 `#906021`, 프랑스어 `#3A68A2`. 다른 세 언어는 준비 중으로 표시하며 없는 교재를 약속하지 않는다.
- `/books/japanese-n5`: 기존 iframe 대신 웹에서 직접 읽는 42과. 책 홈·현재 파트/전체 목차·과 안 목차·연속 본문·집중 읽기·예문 저장·문화/찾아보기. 원문의 루비·단계적 한자·예문 박스·문제·해설을 보존한다.
- 발행 판본 `7f572327dc67893e9453246c`의 원고/자산은 변경하지 않았다. 검증한 HTML의 웹 기사 413개를 읽기 섹션으로 제공한다. PDF 인쇄 페이지 수와 웹 섹션 수는 서로 다른 단위다.
- 과/문단 출처 주소와 구판 판본 URL을 유지한다. 기존 복습/개인 자료는 삭제하지 않는다.
- 읽기 위치·학습 완료·답안은 판본/계정별 브라우저 저장이다. 서버 진도 동기화라고 표시하지 않는다. 예문은 기존 `save_vocabulary_context` 경로로 저장하며 기존 FSRS 일정을 유지한다.
- `/books/japanese-n5/review`: 실제 저장된 이 책의 문맥을 계정별로 조회한다. 기존 FSRS 복습으로 연결한다. `/books/japanese-n5/materials`: 문화 글 4개와 과별 개인 자료 연결.
- `/admin/legacy-textbooks`: 기존 네 언어 교재 목록·문법·어휘·문형을 보존하는 관리자 보관함. 예전 공개 URL은 보관함으로 이동한다. 미들웨어와 서버 페이지 모두 실제 인증/DB 역할을 확인한다. 기존 원고 편집은 `/admin/textbooks`, 새 책 원고는 `/admin/books/japanese-n5`.
- 기존 교재의 자료 연결 목록/새 연결/새 발췌 저장도 관리자 역할을 확인한다. 일반 회원의 기존 단어 카드와 개인 자료는 유지한다. 홈의 옛 교재 이어 읽기 버튼은 일반 회원에게 새 책을 안내한다.
- DB 스키마 변경 없음. 병합/강제 푸시 없음.

- 실동작: 전체 목차, 직접 출처 위치, 집중 읽기 복귀, 객관식/서술 답안 새로고침 복원, 과 완료, 문화 글, 찾아보기, 게스트 관리자/API 접근 차단. 폰트 로딩 후 위치와 React 재렌더 시 입력/저장 버튼 초기화를 수정했다.
- 새 계약 테스트: 전체 원문/예문/문제 보존, 개인 저장 키 분리, 공개 판본/원고·자산 해시 확인, 미발행 판본 차단, 관리자/회원 역할, 개인 복습 소유권 필터, 관리자 기존 예문·어휘 검증과 자료 연결.

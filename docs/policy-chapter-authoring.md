**뼈+살**: 콘텐츠 1편 = 표현 뼈 1~2(레벨 정의·필수·또렷) + 살(장소·문화·오감 — 몰입·선택). **표현을 먼저 확정하고 맥락을 입힌다.** 뼈를 덮는 어려운 살(단어)은 빼거나 선택으로 표기한다.

## 1. 원칙 12개조

### 1부 — 배열·정합 (오너 4원칙)

- **P1 순서 배열**: 레벨 내 챕터의 order는 유일·연속이고, 배열 근거를 커리큘럼 RFC에 기록한다.
- **P2 선행 보장**: 분석 대상 문법은 선행 챕터에서 도입된 것만 쓴다. 미도입 문법이 등장하면 formulaic(고정구) 표지 + 분석 챕터 예고가 필수이며, prerequisites는 실제 문법 의존을 반영한다. 학습자가 방황하는 "갑툭튀 문법"은 결함이다.
- **P3 레벨 적합성**: 문형·어휘·과업이 해당 레벨 Can-do 범위 안이어야 한다. 저작 전 레벨 기준표(P10) 대조, 저작 후 감사에서 확인한다.
- **P4 레벨 자원 활용**: 해당 레벨 문형·어휘 팩 항목을 적극 재사용한다. 신규 어휘는 최소화하고, 뼈를 덮는 어려운 어휘는 뺀다(살 원칙).

### 2부 — 소스·정직성

- **P5 소스 등급**: 대화·본문의 출처를 ㉮ 실재 검증(출처 확인됨) / ㉯ 실자료 각색 / ㉰ 자체 저작으로 구분해 기록한다(현재는 본 문서 §5 대장, 스키마 필드는 P11 게이트와 함께 도입). 신규 저작은 ㉮㉯ 비중을 늘려가는 것이 목표다(실자료·오디오 연결은 owner-gate).
- **P6 카피 정직성**: 미배선 기능을 전제로 한 카피 금지 — 오디오가 없으면 "들어 보세요"라고 쓰지 않는다(중립 동사: 만나다·읽다·보다). duration은 단계 합산 실측 규칙(훅1′+어휘3′+문형8~10′+재노출3′+산출3′)으로 산출하고, 구조가 바뀌면 갱신한다.

### 3부 — 학습 설계 (뼈+살·5블록)

- **P7 훅·재노출 분리**: ①훅은 최소 노출(핵심 대화 1개, 짧게, 몰입 프레이밍). ④재노출의 변형 대화는 훅에 없던 자료로 처음 공개한다. 훅에 자료를 몰아 넣으면 재노출의 신선함이 죽는다.
- **P8 뼈 상한**: 신규 문형(뼈) ≤2/챕터, 핵심 표현 5~7개(발음·뜻 정확은 필수). "이 편의 뼈가 무엇인가"에 한 문장으로 답할 수 없으면 결함이다. 체계를 이루는 문형 가족(부정 변형 4형·관계사 3형 등)은 세트 = 뼈 1개로 센다(P12 감사 권고로 명문화, 2026-07-26).
- **P9 살 요건**: 문화 한 스푼 ≥1, 오감·장면 묘사(맥락 고정), 자가 체크 ≥3 + 산출 연습(쓰기·말하기) ≥1. 살은 선택 표기 가능 — 학습자가 뼈만 가져가도 성공이다.

### 4부 — 커버리지

- **P10 레벨 기준표**: 레벨별 뼈대 맵(문형·어휘·Can-do 체크리스트)을 두고 커버리지를 측정한다. 갭 목록이 저작 우선순위가 된다. fr A1·A2 기준표는 후속 몫(`docs/curriculum-fr-a1a2.md` 예정) — 그 전까지는 기존 fr 문법·어휘 팩이 잠정 기준.

### 5부 — 검증·루프

- **P11 자동 게이트**: (a) order 유일·연속 (b) prerequisites 실존·비순환 (c) 선행 문법 커버 (d) 레벨 어휘 대조 (e) 소스 등급 존재. 구현 전에는 감사 체크리스트로 수동 검사한다(시스템 구현은 codex 발주 가능).
- **P12 저작 루프**: 뼈 확정 → 살 선택 → 5단 저작(AI 초안) → 자동 게이트 → 독립 감사 → 수리 → **오너 감수**(신규는 전수, 전환·수리는 표본 — 발음·자연성·감각은 양도 불가 영역) → 정본. 신규든 수정이든 동일 루프를 탄다.

## 2. A등급 판정 기준 (실험 종료 게이트)

1. 감사 규격 치명·중요 지적 0
2. 이용 가능 선 충족: 5단 완비 · 핵심 표현 5~7 정확 · 문화 한 스푼 · 자가 체크 3+산출 1 · 오너 감수 (영상·오디오 슬롯은 배선 전까지 텍스트 오감 묘사로 대체)
3. P1~P9 전 챕터 준수 + P10 커버리지 갭 문서화
4. 자연성 표본 통과

## 3. 저작 표준 절차 (한 챕터)

1. **뼈 확정**: 레벨 기준표에서 문형 1~2 선택, 목표를 Can-do 문장으로 기술
2. **살 선택**: 그 표현이 실제 쓰이는 장소·장면·문화 한 스푼
3. **5단 저작**: ①훅(짧게) → ②어휘 5~7 → ③문형(뼈) → ④재노출(훅에 없던 변형) → ⑤산출
4. 게이트 → 감사 → 수리 → 오너 감수 → 정본

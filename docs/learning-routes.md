# 학습루트 — 현행 구조 (2026-08-10)

> 재설계 11탄(#898~#934) 반영. 원칙: **정문은 하나 — 복습 탭의 [오늘 학습 시작]. 나머지는 보조 문이거나 자료 공급로.**

## 축 구조 — 하단 네비 4탭의 시제

| 탭 | 시제 | 역할 |
|---|---|---|
| 홈 | 과거(기록) | 스트릭·망각 예보·이어서 제안 — 보기만, 여기서 학습하지 않는다 |
| 교재 | 미래(전진) | 참고서. 새 문법을 "찾아보는" 곳 — 정독 대상이 아니다 |
| 복습 | 현재(기억) | 매일 여는 곳. 오늘 할 일 + 단어장 + 서재·작문 입구 |
| 자료 | 자산 | 올린 읽을거리 보관함(공용/내 자료/PDF) |

카드·문 추가 기준: **"같은 목적지의 문이 이미 있나"** — 있으면 만들지 않는다.

## 주 루트 — 하루 루프 (6~8분)

```
복습 탭 → [오늘 학습 시작] → /study
   이야기 한 편에 자동 조립:
   워밍업 2문항(즉시 시작·레이턴시 은폐) → 복습 단어 ≤4 + 복습 문법 ≤2
   + 새 챕터 1(첫 미통과 — 패턴 설명+문항 ≤3) + 독해(현 레벨 문형)
   + 격일 산출 1문장(공동 작가: ≥2점이면 내일 이야기에 반영)
        ↓ 채점(오답은 세션 끝 1회 재출제 — 첫 시도만 기록)
   단어 FSRS 전진 · 문법 재스케줄 · 챕터 통과 판정 · review_events 적재
        ↓
   review_events가 다음 세션을 조정
   (난이도 다이얼 EWMA · 워밍업 오답 우선 · 작문 약점 태그 · 읽기 신호)
```

막히면 문항의 "자세히" 링크가 교재 해당 페이지로 — 교재는 이 루프의 각주다.

## 보조 루트 4개

1. **순수 복습** — 복습 히어로 보조 링크 "단어만 N개"(카드 3방식) · "문법만 N개"(/review/grammar). 새 내용 없음.
2. **교재 정독** — 이어서 카드 → 챕터: 읽기 → 드릴(SRS 자동 편입 — drillSrs 단일 경로) → 써 보기 →
   패턴 체크 관문 통과 → 그룹 n/m·오늘 학습 "새 챕터" 후보에서 제외. 문형·어휘 사전 병행.
3. **자료 읽기** — 자료실 → 뷰어: 단어 클릭 저장 → 노란 due 표시·그 자리 평가(읽기가 곧 복습 처리) →
   완독 → 퀴즈·리딩 테스트(정오 → review_events)·회화(신호 없음 — 자유 발화). "이 자료로 오늘 학습 만들기"로 주 루프 합류.
4. **산출·회고** — 복습 "서재와 작문" 카드: 서재(어시스트 없는 재독 + 내 글감 → /study) ·
   작문(프롬프트 → AI 첨삭 → 재작문, 오류 → review_events 약점 데이터).

## 게스트 루트

교재·드릴·써 보기 전부 가능(localStorage) → 드릴 복습은 게스트 큐(/api/review/drills) → 로그인 시 서버 이관.
자료실 공용 열람. 저장 시점에만 로그인 권유 + /auth·오늘 학습 signedOut에 "로그인 없이 교재 둘러보기" 탈출구.

## 데이터 순환 요약

- **FSRS(기억)**: user_vocabulary — 드릴·오늘 학습·뷰어 인라인 평가·공부 세션 정답이 전진시킴. snake_case 페이로드 계약(#907).
- **문법 SRS**: grammar_review — 챕터 단위 정답률로 재스케줄.
- **review_events(신호)**: 채점형 전부(source: vocab/grammar/reading/writing…) — 다이얼·워밍업·주간 회고·약점.
  ui/dict는 계측 전용(다이얼 제외). 회화는 정오 신호가 없어 미적재(의도).

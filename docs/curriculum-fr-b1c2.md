# fr B1~C2 기준표 — DELF B1/B2·DALF C1/C2 표준 대조 (2026-08-02)

A안(fr 완성 라운드) Phase 1 산출물. A1~A2 기준표(docs/curriculum-fr-a1a2.md)와 같은 방법론 —
챕터 인벤토리를 시험 표준 문법 요목과 대조해 갭 큐를 확정한다. 오너 방침: 타 트랙 확산은
본 라운드 완료·고평가 검증 후 **오너 별도 요청**으로만.

## 1. 인벤토리 × 표준 대조 (30챕터)

### B1 (9) — DELF B1 요목 대비
| 챕터 | 표준 요목 | 판정 |
|---|---|---|
| b1-01 conditionnel présent | 조건법 현재(공손·조언·가정) | ✓ |
| b1-02 subjonctif 입문 | 접속법 현재 + **의견 동사 긍/부정 대비** | ✓ (je ne pense pas 확인 — 깊이는 감사에서) |
| b1-03 plus-que-parfait | 대과거 | ✓ |
| b1-04 dont·où·lequel | 복합 관계대명사 | ✓ |
| b1-05 gérondif | 제롱디프 | ✓ |
| b1-06 passive | 수동태 | ✓ |
| b1-07 discours indirect | 간접화법·시제 후퇴 | ✓ |
| b1-08 celui·le mien | 지시·소유대명사 | ✓ |
| b1-09 pour que·puisque·dès que | 목적·원인·시간 접속 | ✓ |
| (A2-06에 최상급 12개소 기확인) | superlatif·meilleur/mieux | ✓ 기존 커버 |

### B2 (10) — DELF B2 요목 대비
| 챕터 | 표준 요목 | 판정 |
|---|---|---|
| b2-01~10 | 접속법 과거·si 3형·현재분사·논리 연결·동사+전치사·강조·명사화·인과·부정 확장·무인칭 | ✓ 전항 |
| — | **futur antérieur + 시제 일치(concordance) 종합** | ❌ **확정 갭 → 신규 b2-11** |

### C1 (6) / C2 (5) — DALF 요목 대비
| 챕터 | 판정 |

| c1-03 논증 | ⚠ **담화 결속(reprise·anaphore) 보강 섹션** 필요 |
| c2-01~05 (문어 접속법·수사법·프랑코포니·문화 코드·한불 번역) | ✓ 전항 — subjonctif imparfait는 C2 배치 수용(DALF C1은 인지 수준) |

**총평: 뼈대 커버율 30/31 — 갭 신규 1·보강 1·검수 2.** A1~A2 초기(갭 5)보다 완성도 높은 출발.

## 2. 라운드 플랜 (사이클 단위)

| Phase | 내용 | 규모 |
|---|---|---|
| 2 | 갭 해소: 신규 b2-11(futur antérieur·concordance) + c1-03 담화 결속 섹션 + 검수 2건 판정 | 1 사이클 |
| 3 | **드릴 30(+1)챕터**: 챕터당 6~8문항(fill·choice·order·dictation) — 비중복 3중·시점 게이트 그대로 | 2 사이클 |
| 4 | **써 보기 확산**: B1~C2 전 챕터 — B1·B2는 DELF 과제형(에세이·형식 편지 150~250단어), C1·C2는 논증·번역 과제 | 1~2 사이클 |
| 5 | 감사 R 시리즈(표준 대조·표본 품질·접지 규격) → **A0~C2 종합 재평가** → 고평가 검증 시 오너에 타 트랙 확산 여부 문의 | 1 사이클 |

주: 인터리브 원칙은 B1+에도 적용 검토(장면성 챕터가 적어 A1~A2만큼의 재배치는 불필요 — Phase 5 감사에서 판정).

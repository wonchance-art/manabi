# 설명판의 표현·필기 부분 가져오기 설계

2026-09-16 KST · 오너 승인 설계 · #1318 기반 부분 선택 재사용

## 결정

지난 설명판에서 필요한 표현과 필기만 골라 현재 판에 놓는다. 교사는 수업 날짜나 교재를 옮겨 다니지 않는다. 첫 구현은 같은 교사·같은 팀의 지난 설명판을 대상으로 한다.

핵심 흐름은 `전체 메뉴 → 지난 설명판 → 날짜의 가져오기 → 페이지의 부분 고르기 → 선택 → 현재 판에 놓기`다. 이미 구현한 페이지 전체 복사는 그대로 둔다. 페이지 전체를 가져온 이력이 있어도 부분 고르기는 사용할 수 있다.

가져오는 것은 독립 사본이다. 이후 원본 수정이 현재 판에 자동 반영되지 않는다. 화면 선택은 원본 내용을 수정하지 않으며, 확정 전에는 현재 판도 바뀌지 않는다.

## 수업 장면

1. 교사가 오늘 판에서 `觉得`를 설명하다 지난 수업의 `认为` 비교 설명을 다시 쓰고 싶어진다.
2. 지난 판의 해당 페이지에서 `觉得`, `认为`, 두 단어 사이의 화살표와 직접 쓴 주석을 선택한다.
3. 하단에는 `표현 2개 · 필기 포함`과 `현재 판에 놓기`만 강조된다.
4. 누르면 원래 수업으로 돌아와 기존 내용과 겹치지 않는 자리에 선택한 내용을 놓는다. 새로 놓인 요소들은 선택 상태여서 바로 옮길 수 있다.
5. 추가 필기로 이어 설명한다. 학생에게 남길 표현은 기존 `수업에 남기기`로 저장한다. 가져오기만으로 학생 기록이나 개인 복습 일정을 만들지 않는다.

## 화면과 조작

태블릿·데스크톱: 설명판 영역을 채우는 선택 화면. 원래 페이지 URL과 날짜는 유지하고 배경의 편집·단축키를 잠근다. 위쪽 한 줄은 날짜·페이지·닫기, 중앙은 최대 크기 원본 미리보기, 아래는 한 줄 도구와 확정 동작이다.

```text
‹ 페이지 목록        9월 9일 · 2번 판                   ×
──────────────────────────────────────────────────────
                                                      
              지난 설명판 크게 보기                    
                                                      
          觉得 ── 직접 쓴 비교 설명 ── 认为             
                                                      
──────────────────────────────────────────────────────
[영역 선택] [이동] [전체 보기]       표현 2개 · 필기 포함
                                     [현재 판에 놓기 ▾]
```

- 추가 목적지는 버튼의 펼침 메뉴에 `새 페이지에 놓기` 한 가지. 기본은 현재 판이다.
- 아이콘 도구에는 접근성 이름과 툴팁을 붙이고 선택한 도구만 짧은 이름을 표시한다. 확정 버튼은 아이콘으로 줄이지 않는다.
- 폰: 같은 선택 화면을 전체 높이로 열고 하단 안전 영역을 확보한다. 표현은 탭으로 쉽게 고르고, 필기는 확대 후 영역 선택한다. 옆 패널이나 중첩 바텀시트는 만들지 않는다.
- 기본 도구는 사각 영역 선택. 표현 탭은 추가/해제, 여러 번 영역 지정은 선택 누적. 마지막 영역 추가를 취소하는 동작과 전체 선택 해제 제공.
- 화면 이동은 손 도구, 터치 확대·이동은 두 손가락. 제스처 전환 시 진행 중 영역 선택을 취소해 잘못된 확정을 막는다.
- 자유곡선 올가미는 이번 범위에 넣지 않는다. 설치된 Excalidraw의 기존 공개 도구로 가능한 사각 선택·범위 계산부터 사용한다.
- 키보드는 표현/요소 목록 대체 경로로 선택할 수 있다. Tab 이동·Space 선택·Escape 선택 화면 닫기·열었던 버튼으로 초점 복귀를 보장한다.
- 미선택 요소는 읽을 수 있는 대비를 유지한다. 선택은 언어별 강조색 윤곽과 표시로 구별한다. 선택 표시를 복사된 내용에 저장하지 않는다.

## 무엇을 한 덩어리로 고르는가

| 대상 | 규칙 |
|---|---|
| manabi 표현 | 글자·병음/후리가나·훈음·오른쪽 뜻·투명 앵커를 하나의 의미 단위로 취급. 어느 부분을 고르든 전체 요소를 함께 선택 |
| 꺼둔 독음·훈음·뜻 | 보이지 않아도 데이터와 표시 설정은 함께 복사. 가져온 뒤 다시 켤 수 있음 |
| 필기 | 획 전체를 선택. 사각 영역에 완전히 들어오는 획을 선택하고 경계에 걸친 획은 추가 선택으로 보정. 획을 잘라내지 않음 |
| 일반 텍스트·도형 | 직접 선택. 도형에 결합된 텍스트는 함께 포함 |
| 화살표 | 직접 고른 화살표만 포함. 양쪽 대상이 함께 복사되면 연결 유지. 빠진 대상에 대한 연결은 해제하되 화살표 모양 유지 |
| 사용자 묶음 | 범위에 들어온 요소만 복사할 수 있음. 구성원 전체가 선택된 묶음은 보존, 일부만 선택된 바깥 묶음은 해제. 표현 내부 묶음은 항상 보존 |
| 프레임 | 프레임 자체를 선택하면 안의 요소를 함께 포함. 내용만 선택했다면 빠진 프레임 참조는 제거 |
| 삭제된 요소 | 가져오지 않음 |

인접한 필기를 의미상 관련 있다고 추정해 자동으로 가져오지 않는다. 교사가 고른 내용과 결합 관계상 필요한 구성요소만 포함한다. 필기만 선택하거나 화살표만 선택하는 것도 허용한다.

## 배치와 되돌리기

- 원본의 상대 위치·글자 크기·회전·선 두께·숨김 상태·표현 출처를 유지하고 위치만 함께 이동한다.
- 기존 판의 내용은 이동·축소·재정렬하지 않는다.
- 현재 보이는 영역에 들어갈 빈 곳을 찾고, 없으면 기존 내용 바깥의 빈 곳에 놓은 뒤 그 위치를 보여준다. 큰 묶음도 임의로 축소하지 않는다.
- 회전한 요소와 긴 화살표의 실제 외곽은 Excalidraw의 공개 bounds 계산을 재사용한다. 기존 단순 x/y/width/height 배치 함수에 그대로 넘기는 것으로 끝내지 않는다.
- 가져오기 한 번은 한 번의 undo로 없애고 redo로 복원한다. 주변 기존 필기는 영향받지 않아야 한다.
- 삽입 후 새 요소 전체를 선택한다. 영구적인 바깥 그룹은 추가하지 않아 각 표현을 곧바로 수정할 수 있게 한다. 필요하면 기존 묶기 기능 사용.
- 새 페이지는 내용 삽입 성공 때만 만들고 연다. 삽입 되돌리기는 내용을 제거하고 빈 페이지는 유지한다. 현재 페이지 관리와 일관되게 페이지 생성 자체의 undo를 약속하지 않는다.

## 중복·원본 변경·저장

- 빠른 더블 탭은 한 번만 실행한다.
- 같은 원본 페이지에서 동일한 요소·동일한 내용을 다시 선택했다면 `이미 가져온 내용 보기`를 우선 제공하고, 의도적인 재복제를 위한 `다시 복사`는 보조 동작으로 제공한다.
- 동일 여부는 단어 문자열로 판정하지 않는다. 같은 단어의 다른 뜻·다른 필기·다른 수업 설명은 독립 내용이다.
- 이전에 복사한 요소가 모두 삭제/undo된 상태라면 다시 가져올 수 있다. 일부만 남았거나 선택 범위가 겹치면 `일부 내용은 이 판에 이미 있어요`를 표시하고 전체 선택을 다시 복사할지 명시적으로 판단하게 한다. 자동으로 일부만 빼서 설명 구조를 바꾸지 않는다.
- 페이지 전체 가져오기 기록과 부분 가져오기 기록을 구분한다. 이전 판본에 부분 출처가 없는 경우에는 추측으로 중복을 차단하지 않는다.
- 미리보기를 연 시점의 저장본을 선택 대상으로 고정한다. 소스가 수정되면 최신 저장본으로 바꾸는 동작을 제공하고, 바꿀 때 이전 선택은 해제한다. 소스에 재접근 권한이 없으면 새 복사를 중단한다.
- 대상 날짜·페이지를 선택 화면 진입 시 고정하고 확정 시 재확인한다. 확정 때 대상의 최신 필기를 읽는다. 다른 날짜/페이지로 바뀐 상태에 조용히 붙이지 않는다.
- 다른 기기와 충돌 중이면 기존 복구 동선으로 안내한다. 계정 저장 실패와 복사 실패를 구분해, 로컬에 이미 놓인 내용을 재시도 과정에서 중복 삽입하지 않는다.
- 전체 6MiB·20페이지·페이지당 5,000요소 한도를 삽입 전에 검사한다. 삭제 표식도 기존 검증 방식대로 용량과 개수에 포함한다. 한도 초과 시 부분 삽입은 하지 않는다.
- 온라인에서 소스 내용을 받기 전 연결이 끊기면 재시도 안내. 이미 받은 소스에서 만든 사본은 기존 기기 초안 경로로 보존하고, 재연결 때 기존 계정 저장·충돌 규칙을 적용한다.

## 기술 구성 제안

현재 #1318의 세 부품을 확장한다.

1. `BoardReusePanel`: 기존 페이지 전체 선택은 유지하고 각 페이지에 부분 고르기 진입 추가. checkbox label 안에 새 버튼을 중첩하지 않도록 페이지 카드 구조를 분리.
2. 선택 전용 `BoardFragmentPicker`: 원본 스냅샷과 임시 selected IDs만 보유. Excalidraw exportToSvg와 공개 bounds/좌표 변환을 재사용한 미리보기 + 선택층을 우선 검증. 외부 링크 클릭·원본 수정·자동 저장은 연결하지 않는다. 기존 판과 두 개의 편집 엔진을 동시에 활성화하지 않는다.
3. 순수 선택/복제 모델: 표현 구성원 보완, 범위 선택, 컨테이너/프레임/사용자 묶음 처리, ID 재발급, 상대 위치 이동, 출처와 중복 판정. #1318의 cloneBoardElements를 재사용하되 부분 묶음 처리와 반환 ID 대응표를 확장.
4. `TeachingBoardCanvas`: 최신 대상 내용과 용량 확인 → 단일 undo 변경으로 삽입 → 새 요소 선택·화면 이동 → 기존 저장 훅.

첫 구현 단계에서 회전한 표현·겹친 화살표·긴 필기·핀치 확대 좌표를 합성 장면으로 검증한다. 공개 범위 계산으로 정확한 선택 경험이 나오는지 확인하고, 안 되면 필기 편집기를 새로 만드는 대신 선택 미리보기 구현을 조정한다. API가 완성된 선택 전용 모드를 제공한다고 가정하지 않는다.

새 DB 테이블·환경 변수·AI 호출은 계획하지 않는다. 추가 메타데이터는 기존 요소 customData에 크기를 제한한 부분 출처로 저장한다. 원본 board/page와 선택 내용 fingerprint, 원본 요소 식별자를 기록하되 원문 전체를 중복 넣지 않는다. 기존 페이지 전체 reusedFrom 의미는 바꾸지 않는다. cloud pack/unpack에서 출처가 살아 있고 구형 판도 그대로 열리는지 검사한다.

기존 수업 권한 검사·소스 접근 확인·수업 기록 중복 처리·개인 복습 저장 경로를 재사용한다. 개인 노트와 다른 팀의 판을 한 목록으로 합치지 않는다.

- 원본 불변·기존 대상 필기 불변·필요한 출처 유지·학생 기록/개인 복습 자동 생성 0.
- 한 번의 undo/redo, 중복 클릭·다시 가져오기·undo 후 재가져오기·새로고침 후 중복 안내.

# 수업용 뷰어 — 태블릿 입력과 조작

2026-09-11 KST. 오너가 승인한 태블릿 실사용 설계 A/B의 구현 명세.

교재를 연 채 단어를 누르거나 표현을 입력하고, 뜻을 확인·수정한 뒤 확대해서 보여주고 기록한다. 작성 중 과를 바꾸거나 새로 열어도 이 기기의 초안을 다시 열 수 있다. 개인 단어 저장과 수업 기록은 별개로 유지한다.

## 화면

- 상단: 수업·과 맥락, 찾기, 접기. 키보드가 열린 짧은 화면에서는 현재 표현 요약을 표시한다.
- 가운데: 현재 단어의 표기·독음·뜻과 기존 일본어 대응/상세 기능. 이 영역만 스크롤한다. 직접 검색할 때는 이전 교재 단어의 주의점을 감춘다.
- 하단: 교재 선택은 `크게 보여주기 / 수업 노트에 추가 +`, 직접 입력은 `크게 보여주기 / 보여주고 기록`. `기록만 하기 / 한 번 더 추가 / 초안 비우기`는 추가 동작에 둔다.
- 오늘 표현 목록은 접힌 요약으로 시작한다. 전송 실패는 접어 숨기지 않고 확인·재시도 경로를 표시한다.
- 교재의 같은 단어를 다시 눌러도 직접 검색에서 교재 상세로 돌아온다. 사전 응답으로 선택 객체가 갱신되는 것과 명시적 선택은 기존 viewer open signal로 구분한다.
- 기존 중국어 세이지·언어 테마와 개인 단어 저장/FSRS, 주의점 자동 재등장, 확대 화면을 재사용한다.

## 기기 초안

`classroomOutbox`의 IndexedDB `entries`를 재사용하며 DB 버전이나 서버 스키마를 추가하지 않는다. `kind: draft, category: reader`로 수업 진행 화면의 기존 초안 및 전송 요청과 구분한다.

| 식별 요소 | 범위 |
|---|---|
| scope | 계정 / 팀 / 수업일 / 자료 ID를 JSON 배열로 직렬화 |
| context | 직접 입력 한 칸 또는 기존 `studySelectionKey`의 교재 위치 |
| writer | 현재 패널 작성 세션의 UUID |
| revision | 매 편집의 UUID; 소비 시 일치 여부 검사 |
| value | 검색 입력, 선택 표현, 출처, 독음, 수업용 뜻만 |

검색 입력 300자, 표현 5,000 UTF-16 단위, 독음/뜻 각각500 단위로 제한한다. 전체 교재나 사전 응답을 새로 복제하지 않는다. 기존 서버 전송 제한과 교재 주의점 제한은 바꾸지 않는다.

초안은 편집 중 직렬 보관한다. 초기 보관소 읽기가 늦게 끝나더라도 이미 입력한 내용이 우선한다. 같은 자료를 두 탭에서 편집하면 다른 writer의 행을 덮지 않는다. 표시할 때는 같은 context의 최신 행을 선택한다.

기록/비우기는 클릭 시점의 revision만 비교 후 소비한다. 저장 중 새로 쓴 뜻과 다른 탭의 편집은 지우지 않는다. 보관 초안을 이어 작성한 경우 원래 행도 캡처한 revision일 때만 소비한다. 전송 대기 요청은 초안 비우기로 삭제하지 않는다.

초안 복원은 학생용 기록을 만들지 않는다. 교재 원문이 달라 출처를 확인할 수 없으면 내용은 유지하되 교재 출처로 기록할 수 없게 하고, 사용자가 명시적으로 직접 입력으로 전환할 수 있게 한다. 다른 기기 동기화나 브라우저 저장소 삭제 후 복구는 제공하지 않는다.

## 입력·전송·확대

- 중국어/일본어 조합 중 Enter 및 keyCode229를 차단한다. 조합 종료와 Enter 기본 submit의 순서가 겹쳐도 조회하지 않는다.
- 사전 요청 번호와 편집 revision을 확인한다. 이전 검색 응답이나 조회 중 도착한 뜻이 사용자가 적은 뜻을 덮지 않는다.
- 확대 화면은 눌렀을 때의 표기·독음·뜻·출처를 고정한다. 확대 중 뜻이 갱신돼도 다른 내용을 기록하지 않는다.
- 명시적 기록은 기존 `useClassroomSession`과 outbox를 사용한다. 오프라인은 기기 대기, 서버 응답 후에만 기록 확인으로 표시한다. 기록 조회 실패를 빈 대기열로 오인해 확인 완료라 하지 않는다.
- online/focus와 함께 앱이 다시 보이는 `visibilitychange`에서 조회 및 기존 대기열 전송을 재개한다.

## 표시 영역

기존 `useReaderLayout`의 VisualViewport와 `readerVisibleBounds`를 확장한다. 일반 inspector와 수업 패널을 같은 기준으로 계산하며, 수업 패널 활성 시 기존 단일 단어 자동 스크롤과 경쟁하지 않게 한다.

단어·선택 범위의 시작과 끝을 고려한다. 범위가 가용 높이보다 크면 시작 구간을 노출한다. 사용자의 본문 스크롤/터치/키보드 이동이 후속 자동 이동보다 우선한다. 패널 안의 입력 초점은 본문 대신 패널을 움직여 노출한다.

넓은 화면은 기존 오른쪽350px 패널, 좁은 화면은 하단 패널을 유지한다. 입력 글자는16px이며 44px 조작 높이를 유지한다. 키보드가 뜨면 과 선택/수업 범위/지난 기록 등 부수 영역을 숨겨 현재 입력과 주동작 공간을 확보한다.
